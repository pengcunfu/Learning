### 1. 什么是守护进程

守护进程是运行在后台的、独立于终端会话的特殊进程，生命周期长，通常负责系统级的任务（如日志收集、服务监控），不受用户登录 / 退出影响，Linux 下典型的如`sshd`、`crond`。

### 2. 什么是对象存储，与块存储和文件存储有什么区别

- **对象存储**：以 “对象”（数据 + 元数据 + 唯一 ID）为单位存储，扁平结构，适合海量非结构化数据（图片 / 视频），如 OSS/S3；
- **块存储**：将存储划分为固定大小块，裸设备级访问，低延迟、高性能，适合数据库（如 SAN、云盘）；
- **文件存储**：按目录 / 文件树结构组织，支持共享访问，适合文件共享场景（如 NFS、SMB）。

### 3. SIGINT SIGTERM SIGKILL 有什么区别

均为 Linux 信号，用于进程控制：

- `SIGINT`（2）：中断信号，终端按下`Ctrl+C`触发，进程可捕获并优雅退出；
- `SIGTERM`（15）：终止信号，默认`kill`命令发送，进程可捕获 / 忽略，用于优雅终止；
- `SIGKILL`（9）：强制杀死信号，进程无法捕获 / 忽略，直接终止（易导致数据丢失）。

### 4. 有没有使用过 oss，对象存储相比块存储和文件存储有什么优缺点

**优点**：海量存储、高可用、按使用付费、元数据丰富、易扩展；**缺点**：读写延迟高于块存储，不支持文件系统的随机读写 / 锁机制，不适合低延迟 IO 场景（如数据库）。

### 5. 什么是 IO 多路复用

一种 IO 模型，允许单个进程 / 线程同时监听多个文件描述符（FD），当某个 FD 就绪（可读 / 可写）时再触发 IO 操作，避免阻塞等待，提升并发效率，典型实现：select/poll/epoll（Linux）、kqueue（BSD）。

### 6. 文件系统中 mtime、ctime 和 atime 指什么，都有什么不同

- `atime`（访问时间）：文件内容最后被读取的时间；
- `mtime`（修改时间）：文件内容最后被修改的时间；
- `ctime`（变更时间）：文件元数据（权限、所有者、大小）或内容修改的时间（由系统维护，不可手动改）。

### 7. 如何监控文件的变动

- 系统级：Linux `inotify`（监控文件增删改）、Windows `ReadDirectoryChangesW`；
- 工具级：`inotifywait`、`fswatch`；
- 编程级：Python `watchdog`、Node.js `chokidar`（封装底层 API）。

### 8. 一个守护进程的创建步骤是什么，如何用 C 语言创建

**创建步骤**：

1. `fork()`创建子进程，父进程退出（脱离终端）；
2. `setsid()`创建新会话，成为会话首进程（脱离控制终端）；
3. 再次`fork()`（避免意外获取终端）；
4. 切换工作目录（如`/`）、清空文件掩码（`umask(0)`）；
5. 关闭无关文件描述符（0/1/2）；
6. 重定向标准输入 / 输出 / 错误（如指向`/dev/null`）。
    

```c
#include <unistd.h>
#include <sys/stat.h>
#include <fcntl.h>
int main() {
    pid_t pid = fork();
    if (pid > 0) exit(0); // 父进程退出
    setsid(); // 创建新会话
    pid = fork();
    if (pid > 0) exit(0);
    chdir("/"); // 切换目录
    umask(0); // 清空掩码
    close(STDIN_FILENO); close(STDOUT_FILENO); close(STDERR_FILENO);
    open("/dev/null", O_RDWR); dup(0); dup(0); // 重定向FD
    // 守护进程核心逻辑
    while(1) { sleep(1); }
    return 0;
}
```

### 9. Node 中 cluster 的原理是什么

Node.js 单线程，`cluster`模块利用多进程充分利用多核 CPU：

1. 主进程（master）通过`fork()`创建子进程（worker）；
2. 基于`IPC`实现主 / 子进程通信；
3. 端口共享：主进程监听端口，将连接分发到子进程（Linux 下用`SO_REUSEPORT`，Windows 下主进程转发）；
4. 子进程退出时，主进程可重启（实现故障恢复）。

### 10. 什么是文件描述符 (file descriptor)

简称 FD，是 Linux/UNIX 中内核为进程维护的 “打开文件” 的索引（非负整数，如 0 = 标准输入、1 = 标准输出、2 = 标准错误），进程通过 FD 操作文件、网络套接字等 I/O 资源。

### 11. 进程与线程的区别是什么

|维度|进程|线程|
|---|---|---|
|资源分配|独立地址空间、内存、文件 FD|共享进程资源，仅私有栈 / 寄存器|
|调度|操作系统调度的基本单位|CPU 调度的基本单位|
|开销|创建 / 切换开销大|创建 / 切换开销小|
|通信|需 IPC（管道 / 套接字等）|直接读写共享内存|
|独立性|独立运行，一个崩溃不影响其他|线程崩溃可能导致整个进程退出|

### 12. 如何创建一个进程

- Linux/UNIX：
    - 编程：C 语言`fork()`（复制当前进程）、`exec()`（替换进程映像）、`system()`（执行系统命令）；
    - 命令行：`./xxx`、`fork`、`spawn`等；
- Windows：`CreateProcess()` API；
- 高级语言：Python `subprocess`、Node.js `child_process`。

### 13. 什么是 exit code

进程退出时返回给操作系统的整数（0~255）：

- `0`：正常退出；
- 非 0：异常退出（如 1 = 通用错误、2 = 用法错误）；
- 父进程可通过`wait()`/`waitpid()`获取子进程的 exit code。

### 14. 什么是 coredump，如何配置与分析

- **coredump**：进程异常崩溃时，内核将进程内存快照写入核心转储文件（core 文件），用于事后调试；
- **配置**：
    1. 解除大小限制：`ulimit -c unlimited`；
    2. 配置存储路径：`echo "/core-%e-%p" > /proc/sys/kernel/core_pattern`；
- **分析**：用`gdb 可执行文件 core文件`，通过`bt`查看调用栈，定位崩溃原因。

### 15. 同一进程的线程共享那些资源

共享：地址空间（代码 / 数据段）、文件描述符表、信号处理函数、进程 ID / 组 ID、内存（堆 / 全局变量）、环境变量、打开的文件；私有：线程 ID、程序计数器、栈空间、寄存器、errno、信号掩码。

### 16. 什么是原码、补码与反码

均为二进制数的表示方式（以 8 位为例）：

- **原码**：最高位为符号位（0 正 1 负），其余位为数值位，如`+5=00000101`、`-5=10000101`；
- **反码**：正数反码 = 原码，负数反码 = 原码符号位不变，数值位取反，如`-5=11111010`；
- **补码**：正数补码 = 原码，负数补码 = 反码 + 1，如`-5=11111011`；
    
    **作用**：补码统一了加减法运算（减法转加法），是计算机存储整数的标准方式。
