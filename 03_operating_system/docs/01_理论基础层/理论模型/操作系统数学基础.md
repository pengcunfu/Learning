# 操作系统数学基础

## 5.1 排队论在操作系统中的应用

### 5.1.1 基本排队模型

**排队系统的组成**：

排队系统可表示为 A/B/c/K/N/Z，其中：
- A：到达过程（Arrival Process）
- B：服务时间分布（Service Time Distribution）
- c：服务台数量（Number of Servers）
- K：系统容量（System Capacity）
- N：顾客源（Population Size）
- Z：服务规则（Service Discipline）

**常用符号**：
- M：指数分布（Markovian）
- D：确定性分布（Deterministic）
- G：一般分布（General）

**经典排队模型**：

#### M/M/1 排队系统

**假设**：
- 到达过程：泊松过程，参数 λ
- 服务时间：指数分布，参数 μ
- 单服务台，容量无限

**稳态概率**：
```
P(n) = (1 - ρ) × ρⁿ
其中：ρ = λ/μ（利用率）
约束：ρ < 1（稳定性条件）
```

**性能指标**：

1. **平均队长**（L）：
```
L = ρ / (1 - ρ) = λ / (μ - λ)
```

2. **平均等待时间**（W）：
```
W = L / λ = 1 / (μ - λ)
```

3. **平均逗留时间**（W_q）：
```
W_q = W + 1/μ = 1 / (μ - λ) + 1/μ
```

4. **平均等待顾客数**（L_q）：
```
L_q = λ × W = λ / (μ - λ)
```

**操作系统实例**：

CPU调度队列分析：
```python
# 假设进程到达率 λ = 4 processes/s
# CPU服务率 μ = 5 processes/s
# 利用率 ρ = 4/5 = 0.8

lambda_val = 4  # 到达率
mu = 5          # 服务率
rho = lambda_val / mu  # 利用率

L = rho / (1 - rho)     # 平均队长 = 4个进程
W = 1 / (mu - lambda_val)  # 平均等待时间 = 1s

print(f"CPU利用率: {rho:.2f}")
print(f"平均队列长度: {L:.2f} 个进程")
print(f"平均等待时间: {W:.2f} 秒")
```

#### M/M/c 排队系统

**假设**：c个相同的服务台，并行服务

**利用率**：
```
ρ = λ / (c × μ)
稳定性条件：ρ < 1
```

**稳态概率**：
```
P₀ = [Σ(n=0 to c-1) (cρ)ⁿ/n! + (cρ)ᶜ/(c!(1-ρ))]⁻¹
Pₙ = P₀ × (cρ)ⁿ/n!  (n < c)
Pₙ = P₀ × cᶜ × ρⁿ/c!  (n ≥ c)
```

**等待概率**（C公式）：
```
P(wait) = P₀ × (cρ)ᶜ / (c!(1-ρ))
```

**多核CPU调度分析**：
```python
def multi_core_queue_analysis(lambda_val, mu, c):
    """
    多核CPU队列分析
    lambda_val: 进程到达率
    mu: 单个CPU服务率
    c: CPU核心数
    """
    rho = lambda_val / (c * mu)  # 系统利用率

    if rho >= 1:
        return None  # 系统不稳定

    # 计算等待概率（简化公式）
    # P(wait) = P₀ × (cρ)ᶜ / (c!(1-ρ))
    # 这里使用近似计算

    # 利用率
    utilization = rho

    # 平均等待时间（近似）
    W = 1 / (c * mu - lambda_val)

    # 平均队列长度
    L = lambda_val * W

    return {
        'utilization': utilization,
        'avg_queue_length': L,
        'avg_wait_time': W
    }

# 示例：4核CPU系统
result = multi_core_queue_analysis(lambda_val=8, mu=3, c=4)
print(f"系统利用率: {result['utilization']:.2f}")
print(f"平均队列长度: {result['avg_queue_length']:.2f}")
```

### 5.1.2 到达过程理论

**泊松过程**（Poisson Process）：

**定义**：计数过程 {N(t), t ≥ 0} 称为泊松过程，如果满足：
1. N(0) = 0
2. 独立增量性
3. 平稳增量性
4. P(N(h) = 1) = λh + o(h)
5. P(N(h) ≥ 2) = o(h)

**性质**：
```
1. 到达间隔时间服从指数分布：f(t) = λe^(-λt)
2. E[N(t)] = λt（期望值）
3. Var[N(t)] = λt（方差）
```

**进程到达建模**：

```python
import numpy as np

def simulate_poisson_arrivals(lambda_val, T):
    """
    模拟泊松到达过程
    lambda_val: 到达率
    T: 模拟时间长度
    返回: 到达时间序列
    """
    arrivals = []
    t = 0

    while t < T:
        # 生成指数分布的间隔时间
        inter_arrival = np.random.exponential(1/lambda_val)
        t += inter_arrival

        if t < T:
            arrivals.append(t)

    return arrivals

# 示例：模拟进程到达
arrivals = simulate_poisson_arrivals(lambda_val=5, T=100)
print(f"总到达数: {len(arrivals)}")
print(f"理论期望: {5 * 100}")
```

### 5.1.3 Little定律

**定理陈述**：
```
L = λ × W
```
其中：
- L：系统中的平均顾客数
- λ：到达率
- W：平均逗留时间

**应用实例**：

#### 进程调度分析
```python
def process_queue_analysis(arrival_rate, avg_service_time):
    """
    进程队列分析
    arrival_rate: 进程到达率
    avg_service_time: 平均服务时间
    """
    lambda_val = arrival_rate
    W = avg_service_time  # 假设等待时间忽略不计

    L = lambda_val * W  # 平均进程数

    return L

# 示例
L = process_queue_analysis(arrival_rate=10, avg_service_time=0.1)
print(f"系统中的平均进程数: {L}")
```

### 5.1.4 排队网络

**开放排队网络**（Jackson Network）：

**假设**：
1. 网络有K个节点
2. 外部到达为泊松过程
3. 服务时间指数分布
4. 路由概率矩阵 P = [pᵢⱼ]

**稳态概率**：
```
π(n₁, n₂, ..., n_K) = Π(k=1 to K) πₖ(nₖ)
```

其中每个节点的到达率：
```
λₖ = λ₀ₖ + Σ(i=1 to K) λᵢ × pᵢₖ
```

**计算机系统建模**：

```python
def computer_system_queue_network():
    """
    计算机系统排队网络模型
    节点：CPU、磁盘1、磁盘2
    """
    # 路由概率矩阵
    P = {
        'CPU': {'CPU': 0.2, 'Disk1': 0.5, 'Disk2': 0.3},
        'Disk1': {'CPU': 1.0},
        'Disk2': {'CPU': 1.0}
    }

    # 外部到达率
    external_arrival = {'CPU': 10}

    # 服务率
    service_rate = {'CPU': 20, 'Disk1': 15, 'Disk2': 15}

    # 计算每个节点的到达率
    # λ_CPU = λ_ext_CPU + λ_Disk1 × 1.0 + λ_Disk2 × 1.0
    # λ_Disk1 = λ_CPU × 0.5
    # λ_Disk2 = λ_CPU × 0.3

    lambda_cpu = 10  # 外部到达
    lambda_disk1 = lambda_cpu * 0.5
    lambda_disk2 = lambda_cpu * 0.3

    # 计算利用率
    rho_cpu = lambda_cpu / service_rate['CPU']
    rho_disk1 = lambda_disk1 / service_rate['Disk1']
    rho_disk2 = lambda_disk2 / service_rate['Disk2']

    print(f"CPU利用率: {rho_cpu:.2f}")
    print(f"磁盘1利用率: {rho_disk1:.2f}")
    print(f"磁盘2利用率: {rho_disk2:.2f}")

computer_system_queue_network()
```

## 5.2 马尔可夫过程与系统状态建模

### 5.2.1 离散时间马尔可夫链

**定义**：

随机序列 {Xₙ, n ≥ 0} 称为马尔可夫链，如果满足：
```
P(Xₙ₊₁ = j | Xₙ = iₙ, Xₙ₋₁ = iₙ₋₁, ..., X₀ = i₀)
= P(Xₙ₊₁ = j | Xₙ = iₙ)
```

**转移概率矩阵**：

```
P = [pᵢⱼ]，其中 pᵢⱼ = P(Xₙ₊₁ = j | Xₙ = i)
```

**性质**：
1. pᵢⱼ ≥ 0
2. Σⱼ pᵢⱼ = 1

### 5.2.2 连续时间马尔可夫链

**定义**：

状态空间 S 的连续时间随机过程 {X(t), t ≥ 0} 称为CTMC，如果满足：
```
P(X(t+s) = j | X(t) = i, X(u), u < t) = P(X(t+s) = j | X(t) = i)
```

**生成矩阵**（Q矩阵）：

```
Q = [qᵢⱼ]，其中：
qᵢⱼ = lim(Δt→0) P(X(t+Δt) = j | X(t) = i) / Δt, i ≠ j
qᵢᵢ = -Σ(j≠i) qᵢⱼ
```

**稳态概率**：

```
πQ = 0
Σ πᵢ = 1
```

### 5.2.3 进程状态转移的马尔可夫模型

**三状态进程模型**：

状态：{运行, 就绪, 阻塞}

```python
import numpy as np

def process_state_markov_model():
    """
    进程状态转移的马尔可夫模型
    状态：0=就绪, 1=运行, 2=阻塞
    """
    # 转移率矩阵（Q矩阵）
    Q = np.array([
        [-4, 4, 0],      # 就绪状态：只能转到运行
        [1, -3, 2],      # 运行状态：可转到就绪或阻塞
        [3, 0, -3]       # 阻塞状态：只能转到就绪
    ])

    # 计算稳态概率：πQ = 0
    # 求解线性方程组
    n = Q.shape[0]
    A = np.vstack([Q.T, np.ones(n)])
    b = np.zeros(n)
    b[-1] = 1

    pi = np.linalg.lstsq(A, b, rcond=None)[0]

    print("稳态概率:")
    print(f"就绪状态: {pi[0]:.3f}")
    print(f"运行状态: {pi[1]:.3f}")
    print(f"阻塞状态: {pi[2]:.3f}")

    return pi

process_state_markov_model()
```

### 5.2.4 内存页面的马尔可夫模型

**页面引用模型**：

假设进程有n个页面，页面引用可建模为马尔可夫链。

```python
def page_reference_markov_model():
    """
    页面引用的马尔可夫模型
    """
    # 转移概率矩阵（3个页面）
    P = np.array([
        [0.7, 0.2, 0.1],  # 页面0的转移概率
        [0.3, 0.5, 0.2],  # 页面1的转移概率
        [0.1, 0.3, 0.6]   # 页面2的转移概率
    ])

    # 计算稳态分布
    eigenvalues, eigenvectors = np.linalg.eig(P.T)
    stationary = eigenvectors[:, np.isclose(eigenvalues, 1)].real
    stationary = stationary / stationary.sum()

    print("页面稳态分布:")
    for i, prob in enumerate(stationary):
        print(f"页面{i}: {prob:.3f}")

    return stationary

page_reference_markov_model()
```

## 5.3 性能评估的数学模型

### 5.3.1 阿姆达尔定律（Amdahl's Law）

**定律陈述**：

系统优化后的加速比：
```
S = 1 / ((1 - P) + P/N)
```
其中：
- P：可优化部分的比例
- N：优化部分的加速比

**理论意义**：

展示了系统性能提升的上限：
```
lim(N→∞) S = 1 / (1 - P)
```

**操作系统实例**：

```python
def amdahl_speedup(P, N):
    """
    计算阿姆达尔加速比
    P: 可优化部分比例
    N: 优化部分加速比
    """
    return 1 / ((1 - P) + P/N)

# 示例：多核CPU加速
for cores in [2, 4, 8, 16, 32]:
    speedup = amdahl_speedup(P=0.8, N=cores)
    print(f"{cores}核加速比: {speedup:.2f}x")

# 理论最大加速比
max_speedup = amdahl_speedup(P=0.8, N=float('inf'))
print(f"理论最大加速比: {max_speedup:.2f}x")
```

U = B × T

### 5.3.4 服务时间定律（Service Time Law）

**定律陈述**：
```
R = N/X - Z
```
其中：
- R：平均响应时间
- N：平均用户数
- X：吞吐量
- Z：平均思考时间

**交互式系统分析**：
```python
def interactive_system_analysis(N, Z, S):
    """
    交互式系统分析
    N: 用户数
    Z: 思考时间
    S: 服务时间
    """
    # 迭代求解吞吐量
    X = 0.01  # 初始猜测
    for _ in range(100):
        R = N / X - Z
        X_new = 1 / (R + S)
        if abs(X_new - X) < 1e-6:
            break
        X = X_new

    R = N / X - Z

    print(f"系统吞吐量: {X:.2f} transactions/s")
    print(f"平均响应时间: {R:.2f} s")

interactive_system_analysis(N=20, Z=10, S=2)
```

## 5.4 可靠性理论

### 5.4.1 可靠性函数

**定义**：

系统可靠性函数 R(t) = P(T > t)，其中T为失效时间。

**指数分布模型**：
```
R(t) = e^(-λt)
f(t) = λe^(-λt)  （失效密度函数）
```

**平均无故障时间**（MTTF）：
```
MTTF = E[T] = ∫(0 to ∞) R(t)dt = 1/λ
```

### 5.4.2 串联系统可靠性

**模型**：n个组件串联

**可靠性**：
```
R_system(t) = Π(i=1 to n) Rᵢ(t)
```

**实例**：
```python
def series_system_reliability():
    """
    串联系统可靠性分析
    """
    # 组件失效率
    lambda_CPU = 0.001
    lambda_Memory = 0.0005
    lambda_Disk = 0.002

    # 系统失效率
    lambda_system = lambda_CPU + lambda_Memory + lambda_Disk

    # 可靠性函数
    def R(t):
        return np.exp(-lambda_system * t)

    # MTTF
    MTTF = 1 / lambda_system

    print(f"系统失效率: {lambda_system:.6f} /小时")
    print(f"系统MTTF: {MTTF:.0f} 小时")
    print(f"24小时可靠性: {R(24):.4f}")
    print(f"一年可靠性: {R(8760):.4f}")

series_system_reliability()
```

### 5.4.3 并联系统可靠性

**模型**：n个组件并联

**可靠性**：
```
R_system(t) = 1 - Π(i=1 to n) (1 - Rᵢ(t))
```

**实例**：
```python
def parallel_system_reliability():
    """
    并联系统可靠性分析（双机热备）
    """
    lambda_component = 0.001

    # 单组件可靠性
    def R_component(t):
        return np.exp(-lambda_component * t)

    # 并联系统可靠性
    def R_system(t):
        return 1 - (1 - R_component(t))**2

    # MTTF
    MTTF_component = 1 / lambda_component
    MTTF_system = 1.5 / lambda_component  # 双并联系统

    print(f"单组件MTTF: {MTTF_component:.0f} 小时")
    print(f"双并联系统MTTF: {MTTF_system:.0f} 小时")
    print(f"可靠性提升: {MTTF_system/MTTF_component:.2f}x")

parallel_system_reliability()
```

### 5.4.4 RAID系统的可靠性分析

**RAID 1（镜像）**：
```python
def raid1_reliability(lambda_disk, n=2):
    """
    RAID 1 可靠性分析
    lambda_disk: 单个磁盘的失效率
    n: 磁盘数量
    """
    # RAID 1 只要有一个磁盘正常工作即可
    # R_system = 1 - (1 - R_disk)^n

    def R(t):
        R_disk = np.exp(-lambda_disk * t)
        return 1 - (1 - R_disk)**n

    # MTTF
    MTTF = sum(1/(i*lambda_disk) for i in range(1, n+1))

    return R, MTTF

# 示例
R, MTTF = raid1_reliability(lambda_disk=0.001, n=2)
print(f"RAID 1 MTTF: {MTTF:.0f} 小时")
print(f"一年可靠性: {R(8760):.6f}")
```

**RAID 5（分布式奇偶校验）**：
```python
def raid5_reliability(lambda_disk, n=4):
    """
    RAID 5 可靠性分析
    n: 磁盘数量（允许1个磁盘失效）
    """
    def R(t):
        R_disk = np.exp(-lambda_disk * t)
        # RAID 5 允许1个磁盘失效，即至少n-1个磁盘正常
        # 使用二项分布计算
        from scipy.stats import binom
        reliability = sum(binom.pmf(k, n, R_disk) for k in range(n-1, n+1))
        return reliability

    return R

# 示例
R_raid5 = raid5_reliability(lambda_disk=0.001, n=4)
print(f"RAID 5 一年可靠性: {R_raid5(8760):.6f}")
```

## 5.5 性能优化理论

### 5.5.1 缓存理论

**缓存命中率模型**：

设缓存容量为C，访问序列为A，缓存策略为S：

命中率 H(C, A, S) = |{a ∈ A : a in cache when accessed}| / |A|

**独立引用模型**：

假设页面引用独立，引用概率为 pᵢ：

```python
def independent_reference_model(cache_size, page_probabilities):
    """
    独立引用模型的缓存分析
    cache_size: 缓存大小
    page_probabilities: 页面引用概率字典
    """
    # 按概率排序，缓存高概率页面
    sorted_pages = sorted(page_probabilities.items(),
                         key=lambda x: x[1], reverse=True)

    # 命中率
    hit_rate = sum(prob for _, prob in sorted_pages[:cache_size])

    return hit_rate

# 示例：80-20法则
page_probs = {i: 0.8/(20) if i < 20 else 0.2/(80) for i in range(100)}
hit_rate = independent_reference_model(cache_size=20, page_probabilities=page_probs)
print(f"缓存命中率: {hit_rate:.2%}")
```

### 5.5.2 局部性原理的数学描述

**时间局部性**：
```
P(Xₜ₊₁ = x | Xₜ = x) > P(Xₜ₊₁ = x)
```
即：刚访问过的页面很快会再次被访问

**空间局部性**：
```
P(Xₜ₊₁ ∈ N(x) | Xₜ = x) > P(Xₜ₊₁ ∈ N(x))
```
其中N(x)是x的邻域

**工作集模型**：

工作集 W(t, Δ) = {页面 : 在时间窗口(t-Δ, t]内被引用}

**工作集大小**：
```
|W(t, Δ)| ∝ Δ^α
```
其中α是工作集系数（0 < α < 1）

### 5.5.3 负载均衡理论

**最优负载分配**：

设系统有n个服务器，负载分配比例为 w₁, w₂, ..., wₙ：

最小化响应时间：
```
min Σ(i=1 to n) wᵢ / μᵢ
subject to: Σ wᵢ = 1, wᵢ ≥ 0
```

**最优解**：
```
wᵢ ∝ μᵢ
```

即：负载应按服务能力分配

```python
def optimal_load_distribution(service_rates):
    """
    最优负载分配
    service_rates: 各服务器服务率列表
    """
    total_rate = sum(service_rates)
    weights = [rate / total_rate for rate in service_rates]

    return weights

# 示例
rates = [10, 15, 20]
weights = optimal_load_distribution(rates)
for i, weight in enumerate(weights):
    print(f"服务器{i}负载分配: {weight:.2%}")
```
