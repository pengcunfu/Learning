## Linux

- **Ubuntu**（22.04 LTS / 24.04 LTS）
- **Debian**（12 "Bookworm"）
- **Fedora**（40，2024）
- **CentOS**（7 / Stream 版本）
- **Arch Linux**（滚动更新）
- **Linux Mint**（基于 Ubuntu）
- **openSUSE**（Tumbleweed / Leap）
- **Gentoo**（高度定制化）
- **Slackware**（历史最悠久的发行版之一）

## 移动端

- **HarmonyOS**（华为鸿蒙，兼容安卓）
- **KaiOS**（基于 Firefox OS，用于功能机）
- **Tizen**（三星智能手表/电视）



## 服务器

- Linux 服务器版
  - Ubuntu Server
  - Red Hat Enterprise Linux（RHEL）
  - SUSE Linux Enterprise
  - Rocky Linux / AlmaLinux（替代 CentOS）
- **Windows Server**（2022 / 2019）
- **FreeBSD / OpenBSD**（类 Unix，高安全性）
- **Oracle Linux**（基于 RHEL）

## 嵌入式

- **Embedded Linux**（如 OpenWRT、Yocto）
- **FreeRTOS**（实时操作系统，用于微控制器）
- **RT-Thread**（中国开源嵌入式 OS）
- **VxWorks**（工业级实时系统）
- **QNX**（黑莓旗下，用于汽车/医疗设备）



## 其他

- **ChromeOS**（Google，基于 Linux，用于 Chromebook）
- **Solaris**（Oracle，原 Sun Microsystems）
- **UNIX 商业版**（AIX（IBM）、HP-UX（惠普））
- **MS-DOS**（微软早期命令行系统）
- **ReactOS**（开源 Windows 兼容系统）
- **Haiku OS**（继承 BeOS）



## 国产

- **统信 UOS**（基于 Debian）
- **麒麟 OS**（银河麒麟、中标麒麟）
- **Deepin**（深度，基于 Debian）
- **OpenEuler**（华为开源服务器 OS）
