# 缓存理论与内存层次结构

## 7.1 内存层次结构的理论基础

### 7.1.1 层次结构的数学模型

**n层内存系统**：

第i层存储器具有以下特征：
- **容量**：Sᵢ
- **访问时间**：Tᵢ
- **每字节成本**：Cᵢ

**层次原则**：
```
∀i < j: Sᵢ < Sⱼ, Tᵢ < Tⱼ, Cᵢ > Cⱼ
```

**平均访问时间**（Average Memory Access Time, AMAT）：

```
AMAT = T₁ + H₁ × T₂ + H₁ × H₂ × T₃ + ...
     = T₁ + Σ(i=2 to n) [Tᵢ × Π(j=1 to i-1) Hⱼ]
```

其中 Hᵢ 是第i层的命中率。

**理想情况**（完美缓存）：
```
H₁ = 1 → AMAT = T₁
```

**最坏情况**（完全失效）：
```
H₁ = 0, H₂ = 0, ... → AMAT = Σ Tᵢ
```

### 7.1.2 局部性原理的数学表达

**时间局部性**（Temporal Locality）：

```
P(Xₜ₊ₖ = x | Xₜ = x) > P(Xₜ₊ₖ = x)
```
对于小的 k，这个概率显著大于基线概率。

**空间局部性**（Spatial Locality）：

```
P(Xₜ₊ₖ ∈ N(x) | Xₜ = x) > P(Xₜ₊ₖ ∈ N(x))
```
其中 N(x) 是 x 的邻域（如同一缓存行）。

**局部性度量**：

**栈距离**（Stack Distance）：
```
Stack_Distance(x) = |{distinct accesses since x was last accessed}|
```

**重用距离**（Reuse Distance）：
```
Reuse_Distance(x) = Stack_Distance(x)
```

### 7.1.3 Amdahl定律在内存系统中的应用

**内存系统优化分析**：

设：
- 原始AMAT = T_original
- 优化后的AMAT = T_optimized
- 优化部分的加速比 = S

**整体加速比**：
```
Speedup = 1 / ((1 - F) + F/S)
```
其中 F 是受优化影响的比例。

**实例分析**：
```python
def memory_optimization_analysis():
    """
    内存优化分析
    """
    # 原始系统
    T_cache = 1e-9    # 1ns (L1缓存)
    T_memory = 100e-9 # 100ns (主存)
    H_cache = 0.9     # 90%命中率

    AMAT_original = T_cache + (1 - H_cache) * T_memory

    # 优化方案1：提高命中率到95%
    H_cache_opt1 = 0.95
    AMAT_opt1 = T_cache + (1 - H_cache_opt1) * T_memory

    # 优化方案2：降低主存访问时间到80ns
    T_memory_opt2 = 80e-9
    AMAT_opt2 = T_cache + (1 - H_cache) * T_memory_opt2

    print(f"原始AMAT: {AMAT_original*1e9:.2f} ns")
    print(f"优化1AMAT: {AMAT_opt1*1e9:.2f} ns (加速比: {AMAT_original/AMAT_opt1:.2f}x)")
    print(f"优化2AMAT: {AMAT_opt2*1e9:.2f} ns (加速比: {AMAT_original/AMAT_opt2:.2f}x)")

memory_optimization_analysis()
```

## 7.2 缓存性能模型

### 7.2.1 缓存命中率的数学模型

**独立引用模型**（Independent Reference Model）：

假设有 N 个页面，页面 i 的引用概率为 pᵢ，缓存容量为 C：

**最优命中率**：
```
H* = Σ(i=1 to C) pᵢ  （假设 pᵢ 按降序排列）
```

**LRU 命中率**（近似）：
```
H_LRU ≈ H* × α
```
其中 α 是 LRU 效率因子（0 < α ≤ 1）。

**实例计算**：
```python
def cache_hit_rate_analysis(cache_size, page_probabilities):
    """
    缓存命中率分析
    """
    # 按概率排序（模拟LRU）
    sorted_pages = sorted(page_probabilities.items(),
                         key=lambda x: x[1], reverse=True)

    # 理论最优命中率
    optimal_hit_rate = sum(prob for _, prob in sorted_pages[:cache_size])

    # 模拟LRU命中率（考虑效率损失）
    lru_efficiency = 0.9
    lru_hit_rate = optimal_hit_rate * lru_efficiency

    return {
        'optimal': optimal_hit_rate,
        'lru': lru_hit_rate
    }

# 80-20法则示例
num_pages = 100
hot_pages = 20
page_probs = {}

# 热页面：80%的访问
for i in range(hot_pages):
    page_probs[i] = 0.8 / hot_pages

# 冷页面：20%的访问
for i in range(hot_pages, num_pages):
    page_probs[i] = 0.2 / (num_pages - hot_pages)

results = cache_hit_rate_analysis(cache_size=20, page_probabilities=page_probs)
print(f"最优命中率: {results['optimal']:.2%}")
print(f"LRU命中率: {results['lru']:.2%}")
```

### 7.2.2 缓存容量的数学分析

**堆栈距离模型**（Stack Distance Model）：

设 H(C) 为容量为 C 时的命中率，则：
```
H(C) = Σ(d=1 to ∞) f(d) × I(C ≥ d)
```
其中：
- f(d)：栈距离为 d 的访问频率
- I(·)：指示函数

**工作集模型**（Working Set Model）：

工作集 W(t, w)：
```
W(t, w) = {pages accessed in time window (t-w, t]}
```

**工作集大小**：
```
|W(t, w)| ∝ w^α
```
其中 α 是工作集系数（0 < α < 1）。

**缓存容量需求**：
```
C_min = max_t |W(t, w)|
```

**实例**：
```python
def working_set_analysis(trace, window_size):
    """
    工作集分析
    trace: 访问序列
    window_size: 时间窗口大小
    """
    working_sets = []

    for t in range(window_size, len(trace)):
        window = trace[t-window_size:t]
        working_set = set(window)
        working_sets.append(len(working_set))

    max_working_set = max(working_sets)
    avg_working_set = sum(working_sets) / len(working_sets)

    return {
        'max': max_working_set,
        'avg': avg_working_set
    }

# 生成模拟访问序列
import random
trace = [random.randint(0, 99) for _ in range(10000)]

analysis = working_set_analysis(trace, window_size=1000)
print(f"最大工作集大小: {analysis['max']}")
print(f"平均工作集大小: {analysis['avg']:.1f}")
```

### 7.2.3 缓存关联度的理论分析

**全相联缓存**（Fully Associative）：

**优点**：
- 命中率最高
- 灵活性最大

**缺点**：
- 比较电路复杂：O(C)
- 访问时间长

**直接映射缓存**（Direct Mapped）：

**优点**：
- 实现简单：O(1)
- 访问时间短

**缺点**：
- 冲突失效多
- 命中率低

**组相联缓存**（Set Associative）：

**权衡**：
```
关联度 ↑ → 命中率 ↑, 访问时间 ↑, 面积 ↑, 功耗 ↑
```

**最优关联度分析**：

```python
def set_associativity_analysis(cache_size, line_size, num_sets):
    """
    组相联度分析
    """
    # 不同关联度的性能参数
    associativities = [1, 2, 4, 8, 16]

    results = []
    for assoc in associativities:
        # 简化模型：命中率随关联度增加（边际递减）
        hit_rate = 1 - (1 - 0.9) / (assoc ** 0.3)

        # 访问时间随关联度增加
        access_time = 1 + assoc * 0.1

        # 平均访问时间
        amat = hit_rate * 1 + (1 - hit_rate) * 100

        results.append({
            'associativity': assoc,
            'hit_rate': hit_rate,
            'access_time': access_time,
            'amat': amat
        })

    # 找到最优关联度
    optimal = min(results, key=lambda x: x['amat'])

    print("关联度分析:")
    for r in results:
        print(f"路数{r['associativity']:2d}: "
              f"命中率={r['hit_rate']:.3f}, "
              f"AMAT={r['amat']:.2f}ns")

    print(f"\n最优关联度: {optimal['associativity']}路")

set_associativity_analysis(cache_size=32*1024, line_size=64, num_sets=512)
```

## 7.3 缓存替换策略的理论分析

### 7.3.1 替换策略的分类

**堆栈型算法**（Stack Algorithm）：

定义：包含性原则（Inclusion Property）
```
Cache(C₁) ⊆ Cache(C₂) 当 C₁ < C₂
```

**堆栈型算法**：LRU、LFU、RAND
**非堆栈型算法**：FIFO

### 7.3.2 LRU的理论性质

**最优性**：

在独立引用模型下，LRU 是最优的堆栈型算法。

**实现复杂度**：

- 理想LRU：O(1) 查找，O(1) 更新（需要特殊硬件）
- 软件实现：O(log n)（使用平衡树）
- 近似LRU：O(1)（如Clock算法）

**LRU的近似算法**：

**Clock算法**：
```python
class ClockAlgorithm:
    def __init__(self, cache_size):
        self.cache_size = cache_size
        self.cache = {}  # page -> (data, reference_bit)
        self.clock_hand = 0
        self.pages = []  # 维护页面顺序

    def access(self, page):
        if page in self.cache:
            # 命中：设置引用位
            self.cache[page] = (self.cache[page][0], 1)
        else:
            # 失效：需要替换
            if len(self.cache) >= self.cache_size:
                self._replace()
            self.cache[page] = (None, 1)
            self.pages.append(page)

    def _replace(self):
        """Clock算法的替换逻辑"""
        while True:
            page = self.pages[self.clock_hand]
            data, ref_bit = self.cache[page]

            if ref_bit == 0:
                # 找到替换目标
                del self.cache[page]
                self.pages.pop(self.clock_hand)
                break
            else:
                # 清除引用位，继续
                self.cache[page] = (data, 0)
                self.clock_hand = (self.clock_hand + 1) % len(self.pages)
```

### 7.3.3 Belady算法与MIN算法

**MIN算法**（最优替换）：

替换最久不会被使用的页面。

**理论性质**：
```
H_MIN ≥ H_ALGORITHM  (对于任何算法ALGORITHM)
```

**实现**（需要预知未来）：
```python
def optimal_replacement(trace, cache_size):
    """
    最优替换算法（Belady算法）
    trace: 访问序列
    cache_size: 缓存容量
    """
    cache = set()
    hits = 0

    for i, page in enumerate(trace):
        if page in cache:
            hits += 1
        else:
            if len(cache) < cache_size:
                cache.add(page)
            else:
                # 找出最远使用的页面
                farthest = -1
                victim = None

                for cached_page in cache:
                    # 查找下次使用位置
                    next_use = float('inf')
                    for j in range(i+1, len(trace)):
                        if trace[j] == cached_page:
                            next_use = j
                            break

                    if next_use > farthest:
                        farthest = next_use
                        victim = cached_page

                cache.remove(victim)
                cache.add(page)

    return hits / len(trace)
```

### 7.3.4 替换策略的性能比较

```python
def replacement_policy_comparison():
    """
    替换策略性能比较
    """
    import random

    # 生成访问序列
    num_pages = 100
    trace_length = 10000
    trace = [random.randint(0, num_pages-1) for _ in range(trace_length)]

    cache_sizes = [10, 20, 50, 100]

    for cache_size in cache_sizes:
        print(f"\n缓存大小: {cache_size}")

        # 最优策略
        hit_rate_opt = optimal_replacement(trace, cache_size)
        print(f"最优策略: {hit_rate_opt:.3f}")

        # LRU (模拟)
        hit_rate_lru = simulate_lru(trace, cache_size)
        print(f"LRU:      {hit_rate_lru:.3f}")

        # FIFO (模拟)
        hit_rate_fifo = simulate_fifo(trace, cache_size)
        print(f"FIFO:     {hit_rate_fifo:.3f}")

        # 随机替换 (模拟)
        hit_rate_random = simulate_random(trace, cache_size)
        print(f"随机:     {hit_rate_random:.3f}")

def simulate_lru(trace, cache_size):
    """模拟LRU"""
    cache = []
    hits = 0

    for page in trace:
        if page in cache:
            hits += 1
            cache.remove(page)
            cache.append(page)
        else:
            if len(cache) >= cache_size:
                cache.pop(0)
            cache.append(page)

    return hits / len(trace)

def simulate_fifo(trace, cache_size):
    """模拟FIFO"""
    from collections import deque
    cache = deque()
    hits = 0

    for page in trace:
        if page in cache:
            hits += 1
        else:
            if len(cache) >= cache_size:
                cache.popleft()
            cache.append(page)

    return hits / len(trace)

def simulate_random(trace, cache_size):
    """模拟随机替换"""
    import random
    cache = set()
    hits = 0

    for page in trace:
        if page in cache:
            hits += 1
        else:
            if len(cache) >= cache_size:
                victim = random.choice(list(cache))
                cache.remove(victim)
            cache.add(page)

    return hits / len(trace)

replacement_policy_comparison()
```

## 7.4 写策略与一致性

### 7.4.1 写策略的理论分析

**写回**（Write-Back）：
```
仅在替换时写入主存
优点：减少内存写入
缺点：实现复杂，一致性问题
```

**写通**（Write-Through）：
```
每次都写入主存
优点：实现简单，一致性好
缺点：内存带宽浪费
```

**性能对比**：

设读比例为 r，写比例为 w = 1 - r：
```
Write_Back:  Traffic = r × Read_Miss + w × Write_Miss
Write_Through: Traffic = (r + w) × Read_Miss + w × All_Writes
```

### 7.4.2 缓存一致性的理论基础

**一致性模型**：

**严格一致性**（Strict Consistency）：
```
任何读取都能获得最近的写入
```

**顺序一致性**（Sequential Consistency）：
```
所有处理器看到相同的操作顺序
```

**弱一致性**（Weak Consistency）：
```
同步操作保证一致性
```

**缓存一致性协议**：

**监听协议**（Snooping Protocol）：
```
总线广播：所有处理器监听总线
状态：Modified, Exclusive, Shared, Invalid (MESI)
```

**目录协议**（Directory Protocol）：
```
中心目录：跟踪缓存状态
扩展性好：适合多处理器系统
```

## 7.5 TLB（Translation Lookaside Buffer）

### 7.5.1 TLB性能模型

**TLB命中率的数学模型**：

假设程序有良好的空间局部性：
```
TLB_Hit_Rate ≈ 1 - (Working_Set_Size / TLB_Entries)
```

**有效内存访问时间**：
```
EAT = TLB_Hit × (Cache_Access) +
      TLB_Miss × (Page_Table_Access + Cache_Access)
```

### 7.5.2 TLB优化策略

**大页支持**：

```
Page_Size ↑ → TLB_Coverage ↑ → TLB_Miss_Rate ↓
```

**实例分析**：

## 7.6 预取技术

### 7.6.1 预取的理论基础

**预取的收益分析**：

设预取距离为 d，预取精度为 p：

**收益**：
```
Benefit = p × d × (Memory_Latency - Prefetch_Latency)
```

**代价**：
```
Cost = (1 - p) × d × Memory_Bandwidth
```

**净收益**：
```
Net_Benefit = Benefit - Cost
```

### 7.6.2 预取策略

**顺序预取**（Sequential Prefetching）：
```
检测到顺序访问模式后，预取后续页面
```

**指针预取**（Pointer Prefetching）：
```
跟随指针预取数据结构
```

**自适应预取**：
```python
class AdaptivePrefetcher:
    def __init__(self):
        self.access_patterns = {}
        self.prefetch_degree = 1

    def record_access(self, address):
        """记录访问并分析模式"""
        page = address >> 12  # 假设4KB页

        if page in self.access_patterns:
            last_access, count = self.access_patterns[page]
            delta = page - last_access

            if delta == 1:  # 检测到顺序访问
                self.prefetch_degree = min(self.prefetch_degree + 1, 8)

        self.access_patterns[page] = (page, self.access_patterns.get(page, (0, 0))[1] + 1)

    def get_prefetch_addresses(self, current_address):
        """生成预取地址"""
        page = current_address >> 12
        prefetch_pages = []

        for i in range(1, self.prefetch_degree + 1):
            prefetch_pages.append((page + i) << 12)

        return prefetch_pages
```
