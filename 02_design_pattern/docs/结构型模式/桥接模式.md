# 桥接模式




桥接模式是一种结构型设计模式，通过**将抽象与实现分离**，使它们可以独立变化。它使用**组合代替继承**来解决多维度的类爆炸问题，特别适用于多个独立变化维度的系统设计。

---

### **桥接模式核心结构**
1. **Abstraction（抽象化角色）**：定义抽象接口，维护对实现化对象的引用
2. **Refined Abstraction（扩展抽象化）**：扩展抽象接口的变体
3. **Implementor（实现化角色）**：定义实现类的接口
4. **Concrete Implementor（具体实现化）**：实现实现化接口的具体类

---

### **Java实现示例：图形渲染系统**
我们以不同形状（圆形、方形）和不同渲染方式（矢量、光栅）的组合为例，演示如何避免创建`形状×渲染方式`的笛卡尔积类。

```java
// 1. 实现化接口（渲染器）
interface Renderer {
    void renderCircle(double radius);
    void renderSquare(double side);
}

// 2. 具体实现化
class VectorRenderer implements Renderer {
    @Override
    public void renderCircle(double radius) {
        System.out.printf("绘制矢量圆形，半径：%.1f%n", radius);
    }

    @Override
    public void renderSquare(double side) {
        System.out.printf("绘制矢量方形，边长：%.1f%n", side);
    }
}

class RasterRenderer implements Renderer {
    @Override
    public void renderCircle(double radius) {
        System.out.printf("渲染光栅圆形，半径：%.1f%n", radius);
    }

    @Override
    public void renderSquare(double side) {
        System.out.printf("渲染光栅方形，边长：%.1f%n", side);
    }
}

// 3. 抽象化角色（形状）
abstract class Shape {
    protected Renderer renderer; // 桥接关键点

    public Shape(Renderer renderer) {
        this.renderer = renderer;
    }

    public abstract void draw();
}

// 4. 扩展抽象化
class Circle extends Shape {
    private double radius;

    public Circle(Renderer renderer, double radius) {
        super(renderer);
        this.radius = radius;
    }

    @Override
    public void draw() {
        renderer.renderCircle(radius);
    }
}

class Square extends Shape {
    private double side;

    public Square(Renderer renderer, double side) {
        super(renderer);
        this.side = side;
    }

    @Override
    public void draw() {
        renderer.renderSquare(side);
    }
}

// 5. 客户端使用
public class BridgePatternDemo {
    public static void main(String[] args) {
        // 创建不同渲染器
        Renderer vector = new VectorRenderer();
        Renderer raster = new RasterRenderer();

        // 组合形状与渲染方式
        Shape circle1 = new Circle(vector, 5.0);
        Shape circle2 = new Circle(raster, 3.0);
        Shape square = new Square(vector, 4.5);

        circle1.draw(); // 矢量圆形
        circle2.draw(); // 光栅圆形
        square.draw();  // 矢量方形

        // 动态切换渲染方式
        square = new Square(raster, 4.5);
        square.draw();  // 光栅方形
    }
}
```

---

### **代码解析**
| 组件             | 作用说明                               |
| ---------------- | -------------------------------------- |
| `Renderer`       | 定义渲染行为的实现接口（桥接的实现端） |
| `VectorRenderer` | 实现矢量渲染逻辑                       |
| `RasterRenderer` | 实现光栅渲染逻辑                       |
| `Shape`          | 形状的抽象基类（桥接的抽象端）         |
| `Circle/Square`  | 具体形状实现，组合使用渲染器           |

---

### **运行结果**
```
绘制矢量圆形，半径：5.0
渲染光栅圆形，半径：3.0
绘制矢量方形，边长：4.5
渲染光栅方形，边长：4.5
```

---

### **桥接模式优势**
1. **解耦抽象与实现**：允许独立修改形状和渲染逻辑
2. **避免类爆炸**：M个形状×N个渲染器只需M+N个类（而非M*N）
3. **运行时绑定**：可动态切换渲染方式
4. **单一职责原则**：形状类专注几何属性，渲染器专注绘制逻辑
5. **开闭原则**：新增形状或渲染器无需修改现有代码

---

### **应用场景**
1. GUI开发中的跨平台控件（控件抽象 + 平台实现）
2. 数据库驱动程序（JDBC是经典桥接案例）
3. 设备与遥控器（不同设备支持相同遥控逻辑）
4. 文件格式转换器（转换算法 × 输入输出格式）
5. 支付系统（支付方式 × 支付渠道）

---

### **模式对比**
| 模式       | 核心目标       | 实现方式             |
| ---------- | -------------- | -------------------- |
| 桥接模式   | 分离抽象与实现 | 组合代替继承         |
| 适配器模式 | 接口转换       | 包装已有接口         |
| 策略模式   | 算法互换       | 封装可替换的策略对象 |
| 抽象工厂   | 创建产品族     | 工厂方法的多层次实现 |

桥接模式通过组合建立两个独立变化的维度之间的连接桥，是处理多维扩展问题的经典解决方案。当系统需要在抽象化和具体实现之间建立更灵活的关联时，桥接模式是最佳选择。

### Implementation

RemoteControl 表示遥控器，指代 Abstraction。

TV 表示电视，指代 Implementor。

桥接模式将遥控器和电视分离开来，从而可以独立改变遥控器或者电视的实现。

```java
public abstract class TV {
    public abstract void on();

    public abstract void off();

    public abstract void tuneChannel();
}
```

```java
public class Sony extends TV {
    @Override
    public void on() {
        System.out.println("Sony.on()");
    }

    @Override
    public void off() {
        System.out.println("Sony.off()");
    }

    @Override
    public void tuneChannel() {
        System.out.println("Sony.tuneChannel()");
    }
}
```

```java
public abstract class RemoteControl {
    protected TV tv;

    public RemoteControl(TV tv) {
        this.tv = tv;
    }

    public abstract void on();

    public abstract void off();

    public abstract void tuneChannel();
}
```

```java
public class ConcreteRemoteControl1 extends RemoteControl {
    public ConcreteRemoteControl1(TV tv) {
        super(tv);
    }

    @Override
    public void on() {
        System.out.println("ConcreteRemoteControl1.on()");
        tv.on();
    }

    @Override
    public void off() {
        System.out.println("ConcreteRemoteControl1.off()");
        tv.off();
    }

    @Override
    public void tuneChannel() {
        System.out.println("ConcreteRemoteControl1.tuneChannel()");
        tv.tuneChannel();
    }
}
```
