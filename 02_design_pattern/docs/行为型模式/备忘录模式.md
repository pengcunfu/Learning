# 备忘录模式

备忘录模式（Memento Pattern）是一种行为设计模式，它的目的是在不暴露对象内部结构的情况下，保存和恢复对象的状态。通常用于需要保存对象历史状态，便于恢复到某个特定状态的场景。备忘录模式常见的应用场景包括撤销操作、游戏中的存档功能、文本编辑器的撤回操作等。

### 1. 备忘录模式的定义和组成

备忘录模式有三个主要的角色：

- **Originator（发起人）**：负责创建一个备忘录来记录自身的状态，并可通过备忘录恢复其状态。
- **Memento（备忘录）**：负责存储发起人对象的内部状态，但不允许直接修改这些状态。
- **Caretaker（管理者）**：负责管理备忘录的保存和恢复，通常不操作备忘录的内容。

备忘录模式的核心思想就是将对象的状态（如数据）保存到一个备忘录中，而不暴露对象的内部结构，然后根据需要恢复到之前的状态。

### 2. 备忘录模式的 UML 图

```

        |                                    |
        +------------------------------------+
```

### 3. 备忘录模式的流程

1. **创建备忘录（Memento）**：
   - 发起人（Originator）保存当前状态并将其放入备忘录中。
2. **保存备忘录**：
   - 管理者（Caretaker）保存备忘录对象。管理者可能会保存多个备忘录对象，供后续恢复使用。
3. **恢复状态**：
   - 发起人可以通过备忘录对象恢复之前的状态。

### 4. 备忘录模式的 Java 实现

我们通过一个简单的例子来实现备忘录模式，假设我们有一个 `TextEditor`（文本编辑器），它的状态可以保存为备忘录，当用户需要撤销操作时，我们可以从备忘录中恢复。

#### 4.1. 定义备忘录（Memento）

```java
public class Memento {
    private final String text;

    public Memento(String text) {
        this.text = text;
    }

    public String getText() {
        return text;
    }
}
```

#### 4.2. 定义发起人（Originator）

```java
public class TextEditor {
    private String text;

    public void setText(String text) {
        this.text = text;
    }

    public String getText() {
        return text;
    }

    // 创建一个备忘录，保存当前状态
    public Memento createMemento() {
        return new Memento(text);
    }

    // 恢复状态
    public void restore(Memento memento) {
        this.text = memento.getText();
    }
}
```

#### 4.3. 定义管理者（Caretaker）

```java
import java.util.Stack;

public class Caretaker {
    private final Stack<Memento> history = new Stack<>();

    // 保存备忘录
    public void saveMemento(Memento memento) {
        history.push(memento);
    }

    // 获取最近的备忘录
    public Memento getMemento() {
        if (!history.isEmpty()) {
            return history.pop();
        }
        return null;
    }
}
```

#### 4.4. 使用示例

```java
public class MementoPatternDemo {
    public static void main(String[] args) {
        // 创建发起人和管理者
        TextEditor editor = new TextEditor();
        Caretaker caretaker = new Caretaker();

        // 编辑器的操作
        editor.setText("Hello");
        caretaker.saveMemento(editor.createMemento());

        editor.setText("Hello, world!");
        caretaker.saveMemento(editor.createMemento());

        editor.setText("Hello, world! How are you?");
        caretaker.saveMemento(editor.createMemento());

        // 显示当前状态
        System.out.println("Current Text: " + editor.getText());

        // 撤销操作
        editor.restore(caretaker.getMemento());
        System.out.println("After undo: " + editor.getText());

        // 再次撤销
        editor.restore(caretaker.getMemento());
        System.out.println("After second undo: " + editor.getText());
    }
}
```

#### 4.5. 输出

```
Current Text: Hello, world! How are you?
After undo: Hello, world!
After second undo: Hello
```

### 5. 现成的库实现备忘录模式

在 Java 中，一些库已经实现了类似的备忘录模式，或者提供了与对象状态管理相关的功能。这些库包括：

- **Java Serialization**：Java 提供了内建的序列化机制，尽管它并不完全符合备忘录模式的设计理念，但它能将对象的状态序列化到文件或内存中，并可恢复对象状态。可以利用 `ObjectOutputStream` 和 `ObjectInputStream` 来实现类似的功能。
- **Apache Commons Lang**：Apache Commons Lang 提供了许多常用的工具类，其中的 `SerializationUtils` 类可以用来快速实现对象的深度复制，间接实现备忘录模式。

#### 示例：使用 `SerializationUtils` 实现备忘录模式

```java
import org.apache.commons.lang3.SerializationUtils;

public class MementoPatternWithCommonsLang {
    public static void main(String[] args) {
        // 创建发起人
        TextEditor editor = new TextEditor();
        Caretaker caretaker = new Caretaker();

        editor.setText("Hello");
        caretaker.saveMemento(editor.createMemento());

        editor.setText("Hello, world!");
        caretaker.saveMemento(editor.createMemento());

        editor.setText("Hello, world! How are you?");
        caretaker.saveMemento(editor.createMemento());

        // 使用 SerializationUtils 进行深拷贝（模拟备忘录）
        Memento memento1 = SerializationUtils.clone(editor.createMemento());
        Memento memento2 = SerializationUtils.clone(editor.createMemento());

        System.out.println("Current Text: " + editor.getText());
        
        // 恢复状态
        editor.restore(memento1);
        System.out.println("After undo: " + editor.getText());

        editor.restore(memento2);
        System.out.println("After second undo: " + editor.getText());
    }
}
```

在这个例子中，我们用 `SerializationUtils.clone()` 来代替手动创建备忘录。深拷贝机制在一定程度上简化了备忘录的创建过程。

### 6. 备忘录模式的优缺点

#### 优点：

1. **封装性**：备忘录模式能够将对象的状态保存在不暴露对象内部结构的情况下，确保数据的封装性。
2. **实现撤销功能**：常用于实现撤销功能，特别是在文本编辑器或图形编辑器中。
3. **历史记录管理**：便于管理对象的历史状态，可以根据需要恢复任何状态。

#### 缺点：

1. **内存消耗大**：如果对象的状态非常大，频繁保存状态可能导致内存消耗增大。
2. **复杂性**：在一些情况下，管理备忘录可能会增加代码的复杂性，特别是在状态较多的情况下。

### 7. 备忘录模式的应用场景

- **文本编辑器**：撤销和重做功能。
- **游戏**：保存和恢复玩家的状态或游戏进度。
- **图形编辑器**：撤销图形绘制或编辑操作。
- **数据库**：记录操作历史，便于回滚。
- **软件中的撤回操作**：任何需要支持“撤回”功能的软件都可能使用备忘录模式。

### 8. 总结

备忘录模式是一种简单但非常实用的设计模式，它帮助我们在不暴露对象的内部结构的情况下，保存和恢复对象的状态。通过设计发起人、备忘录和管理者三个角色，备忘录模式能够实现高效的状态保存和恢复功能。我们通过 Java 代码示例演示了如何实现备忘录模式，并通过介绍一些现成的库，进一步提高了备忘录模式的应用灵活性和便捷性。


## 备忘录（Memento）

### Intent

在不违反封装的情况下获得对象的内部状态，从而在需要时可以将对象恢复到最初状态。

### Class Diagram

- Originator：原始对象
- Caretaker：负责保存好备忘录
- Memento：备忘录，存储原始对象的状态。备忘录实际上有两个接口，一个是提供给 Caretaker 的窄接口：它只能将备忘录传递给其它对象；一个是提供给 Originator 的宽接口，允许它访问到先前状态所需的所有数据。理想情况是只允许 Originator 访问本备忘录的内部状态。

### Implementation

以下实现了一个简单计算器程序，可以输入两个值，然后计算这两个值的和。备忘录模式允许将这两个值存储起来，然后在某个时刻用存储的状态进行恢复。

实现参考：[Memento Pattern - Calculator Example - Java Sourcecode](https://www.oodesign.com/memento-pattern-calculator-example-java-sourcecode.html)

```java
/**
 * Originator Interface
 */
public interface Calculator {

    // Create Memento
    PreviousCalculationToCareTaker backupLastCalculation();

    // setMemento
    void restorePreviousCalculation(PreviousCalculationToCareTaker memento);

    int getCalculationResult();

    void setFirstNumber(int firstNumber);

    void setSecondNumber(int secondNumber);
}
```

```java
/**
 * Originator Implementation
 */
public class CalculatorImp implements Calculator {

    private int firstNumber;
    private int secondNumber;

    @Override
    public PreviousCalculationToCareTaker backupLastCalculation() {
        // create a memento object used for restoring two numbers
        return new PreviousCalculationImp(firstNumber, secondNumber);
    }

    @Override
    public void restorePreviousCalculation(PreviousCalculationToCareTaker memento) {
        this.firstNumber = ((PreviousCalculationToOriginator) memento).getFirstNumber();
        this.secondNumber = ((PreviousCalculationToOriginator) memento).getSecondNumber();
    }

    @Override
    public int getCalculationResult() {
        // result is adding two numbers
        return firstNumber + secondNumber;
    }

    @Override
    public void setFirstNumber(int firstNumber) {
        this.firstNumber = firstNumber;
    }

    @Override
    public void setSecondNumber(int secondNumber) {
        this.secondNumber = secondNumber;
    }
}
```

```java
/**
```
```java
 * Memento Object Implementation
 * <p>
 * Note that this object implements both interfaces to Originator and CareTaker
 */
public class PreviousCalculationImp implements PreviousCalculationToCareTaker,
        PreviousCalculationToOriginator {

    private int firstNumber;
    private int secondNumber;

    public PreviousCalculationImp(int firstNumber, int secondNumber) {
        this.firstNumber = firstNumber;
        this.secondNumber = secondNumber;
    }

    @Override
    public int getFirstNumber() {
        return firstNumber;
    }

    @Override
    public int getSecondNumber() {
        return secondNumber;
    }
}
```

```java
/**
 * CareTaker object
 */
public class Client {

    public static void main(String[] args) {
        // program starts
        Calculator calculator = new CalculatorImp();

        // assume user enters two numbers
        calculator.setFirstNumber(10);
        calculator.setSecondNumber(100);

        // find result
        System.out.println(calculator.getCalculationResult());

        // Store result of this calculation in case of error
        PreviousCalculationToCareTaker memento = calculator.backupLastCalculation();

        // user enters a number
        calculator.setFirstNumber(17);

        // user enters a wrong second number and calculates result
        calculator.setSecondNumber(-290);

        // calculate result
        System.out.println(calculator.getCalculationResult());

        // user hits CTRL + Z to undo last operation and see last result
        calculator.restorePreviousCalculation(memento);

        // result restored
        System.out.println(calculator.getCalculationResult());
    }
}
```
