# 状态模式




状态模式是一种行为设计模式，允许对象在其内部状态改变时改变它的行为，使对象看起来像是修改了它的类。该模式通过将**状态相关的行为抽取到独立的状态类**中，并允许上下文对象在状态改变时切换行为，从而消除复杂的条件判断。

---

### **状态模式核心结构**
1. **Context（上下文）**：维护当前状态，并将行为委托给状态对象
2. **State（状态接口）**：声明状态特定的方法
3. **ConcreteState（具体状态）**：实现状态接口，定义当前状态的行为和状态转换逻辑

---

### **Java实现示例：电梯控制系统**
我们以电梯的不同运行状态（停止、运行、维护）为例，实现状态模式。

```java
// 1. 定义电梯状态接口
interface ElevatorState {
    void openDoors();
    void closeDoors();
    void run();
    void stop();
    void maintenance();
}

// 2. 具体状态实现
class StoppedState implements ElevatorState {
    private final ElevatorContext context;

    public StoppedState(ElevatorContext context) {
        this.context = context;
    }

    @Override
    public void openDoors() {
        System.out.println("开门成功 → 进入停止状态");
    }

    @Override
    public void closeDoors() {
        System.out.println("门已关闭");
    }

    @Override
    public void run() {
        System.out.println("电梯启动 → 转换到运行状态");
        context.setState(context.getRunningState());
    }

    @Override
    public void stop() {
        System.out.println("电梯已是停止状态");
    }

    @Override
    public void maintenance() {
        System.out.println("进入维护模式");
        context.setState(context.getMaintenanceState());
    }
}

class RunningState implements ElevatorState {
    private final ElevatorContext context;

    public RunningState(ElevatorContext context) {
        this.context = context;
    }

    @Override
    public void openDoors() {
        System.out.println("❌ 运行中禁止开门");
    }

    @Override
    public void closeDoors() {
        System.out.println("门已关闭");
    }

    @Override
    public void run() {
        System.out.println("电梯已在运行状态");
    }

    @Override
    public void stop() {
        System.out.println("电梯停止 → 转换到停止状态");
        context.setState(context.getStoppedState());
    }

    @Override
    public void maintenance() {
        System.out.println("❌ 运行中不可维护");
    }
}

class MaintenanceState implements ElevatorState {
    private final ElevatorContext context;

    public MaintenanceState(ElevatorContext context) {
        this.context = context;
    }

    @Override
    public void openDoors() {
        System.out.println("维护模式自动开门");
    }

    @Override
    public void closeDoors() {
        System.out.println("维护模式禁止关门");
    }

    @Override
    public void run() {
        System.out.println("退出维护模式 → 返回停止状态");
        context.setState(context.getStoppedState());
    }

    @Override
    public void stop() {
        System.out.println("已是维护状态");
    }

    @Override
    public void maintenance() {
        System.out.println("已在维护状态");
    }
}

// 3. 上下文类
class ElevatorContext {
    private ElevatorState currentState;
    private final ElevatorState stoppedState;
    private final ElevatorState runningState;
    private final ElevatorState maintenanceState;

    public ElevatorContext() {
        this.stoppedState = new StoppedState(this);
        this.runningState = new RunningState(this);
        this.maintenanceState = new MaintenanceState(this);
        this.currentState = stoppedState;  // 初始状态
    }

    // 委托方法给当前状态
    public void openDoors() { currentState.openDoors(); }
    public void closeDoors() { currentState.closeDoors(); }
    public void run() { currentState.run(); }
    public void stop() { currentState.stop(); }
    public void maintenance() { currentState.maintenance(); }

    // 状态获取器
    public ElevatorState getStoppedState() { return stoppedState; }
    public ElevatorState getRunningState() { return runningState; }
    public ElevatorState getMaintenanceState() { return maintenanceState; }
    public void setState(ElevatorState state) { this.currentState = state; }
}

// 4. 客户端使用
public class StatePatternDemo {
    public static void main(String[] args) {
        ElevatorContext elevator = new ElevatorContext();
        
        elevator.openDoors();  // 停止状态可开门
        elevator.run();       // 启动电梯
        elevator.openDoors(); // 运行中禁止开门
        elevator.stop();      // 停止电梯
        elevator.maintenance();// 进入维护
        elevator.run();       // 退出维护
    }
}
```

---

### **代码解析**
| 组件               | 作用说明                               |
| ------------------ | -------------------------------------- |
| `ElevatorState`    | 定义电梯状态的行为规范                 |
| `StoppedState`     | 处理停止状态逻辑，允许开门/启动/维护   |
| `RunningState`     | 处理运行状态逻辑，仅允许停止操作       |
| `MaintenanceState` | 处理维护状态逻辑，特殊控制门状态       |
| `ElevatorContext`  | 维护当前状态，将操作委托给具体状态对象 |

---

### **运行结果**
```
开门成功 → 进入停止状态
电梯启动 → 转换到运行状态
❌ 运行中禁止开门
电梯停止 → 转换到停止状态
进入维护模式
退出维护模式 → 返回停止状态
```

---

### **状态模式优势**
1. **消除条件判断**：将状态相关行为局部化到独立类中
2. **单一职责原则**：每个状态类只关注自身行为
3. **开闭原则**：新增状态无需修改现有代码
4. **明确状态转换**：状态转换逻辑集中在状态类中
5. **上下文简化**：上下文无需关注具体状态实现

---

### **应用场景**
1. 订单状态管理（待付款/已发货/已完成）
2. 游戏角色状态（正常/中毒/眩晕）
3. 工作流引擎状态转换
4. UI组件状态（启用/禁用/加载中）
5. 网络连接状态（连接中/已连接/断开）

---

### **模式对比**
| 模式       | 核心思想           | 状态管理方式           |
| ---------- | ------------------ | ---------------------- |
| 状态模式   | 行为随内部状态改变 | 通过状态对象委托       |
| 策略模式   | 算法可互换         | 主动设置策略对象       |
| 命令模式   | 封装操作为对象     | 命令对象存储执行参数   |
| 责任链模式 | 请求沿处理链传递   | 多个处理器依次尝试处理 |

状态模式特别适合处理**状态驱动的行为变化**，当对象需要根据状态改变行为且状态数量较多时，能显著提升代码的可维护性。

```java
public interface State {
    /**
     * 投入 25 分钱
     */
    void insertQuarter();

    /**
     * 退回 25 分钱
     */
    void ejectQuarter();

    /**
     * 转动曲柄
     */
    void turnCrank();

    /**
     * 发放糖果
     */

}
```

```java
public class HasQuarterState implements State {

    private GumballMachine gumballMachine;

    public HasQuarterState(GumballMachine gumballMachine) {
        this.gumballMachine = gumballMachine;
    }

    @Override
    public void insertQuarter() {
        System.out.println("You can't insert another quarter");
    }

    @Override
    public void ejectQuarter() {
        System.out.println("Quarter returned");
        gumballMachine.setState(gumballMachine.getNoQuarterState());
    }

    @Override
    public void turnCrank() {
        System.out.println("You turned...");
        gumballMachine.setState(gumballMachine.getSoldState());
    }

    @Override
    public void dispense() {
        System.out.println("No gumball dispensed");
    }
}
```

```java
public class SoldState implements State {

    GumballMachine gumballMachine;

    public SoldState(GumballMachine gumballMachine) {
        this.gumballMachine = gumballMachine;
    }

    @Override
    public void insertQuarter() {
        System.out.println("Please wait, we're already giving you a gumball");
    }

    @Override
    public void ejectQuarter() {
        System.out.println("Sorry, you already turned the crank");
    }

    @Override
    public void turnCrank() {
        System.out.println("Turning twice doesn't get you another gumball!");
    }

    @Override
    public void dispense() {
        gumballMachine.releaseBall();
        if (gumballMachine.getCount() > 0) {
            gumballMachine.setState(gumballMachine.getNoQuarterState());
        } else {
            System.out.println("Oops, out of gumballs");
            gumballMachine.setState(gumballMachine.getSoldOutState());
        }
    }
}
```

```java
public class GumballMachine {

    private State soldOutState;
    private State noQuarterState;
    private State hasQuarterState;
    private State soldState;

    private State state;
    private int count = 0;

    public GumballMachine(int numberGumballs) {
        count = numberGumballs;
        soldOutState = new SoldOutState(this);
        noQuarterState = new NoQuarterState(this);
        hasQuarterState = new HasQuarterState(this);
        soldState = new SoldState(this);

        if (numberGumballs > 0) {
            state = noQuarterState;
        } else {
            state = soldOutState;
        }
    }

    public void insertQuarter() {
        state.insertQuarter();
    }

    public void ejectQuarter() {
        state.ejectQuarter();
    }

    public void turnCrank() {
        state.turnCrank();
        state.dispense();
    }

    public void setState(State state) {
        this.state = state;
    }

    public void releaseBall() {
        System.out.println("A gumball comes rolling out the slot...");
        if (count != 0) {
            count -= 1;
        }
    }

    public State getSoldOutState() {
        return soldOutState;
    }

    public State getNoQuarterState() {
        return noQuarterState;
    }

    public State getHasQuarterState() {
        return hasQuarterState;
    }

    public State getSoldState() {
        return soldState;
    }

    public int getCount() {
        return count;
    }
}
```
