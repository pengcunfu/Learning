# 数据结构与算法

## 概述

数据结构和算法是计算机科学的两个核心分支，它们研究如何有效地存储、组织和处理数据。数据结构决定了数据的存储方式和组织形式，算法则是解决问题的步骤和方法。两者相辅相成：优秀的数据结构设计能够简化算法实现，而高效的算法往往需要特定的数据结构支撑。

## 学习路径

```
基础数据结构 → 树形结构 → 图论 → 算法设计 → 实战应用
     ↓              ↓          ↓         ↓          ↓
  线性结构        层次结构    网络结构   算法思想    题目练习
```

## 复杂度分析速查

### 时间复杂度

| 复杂度 | 名称 | 示例 |
|--------|------|------|
| O(1) | 常数 | 数组访问、哈希查找 |
| O(log n) | 对数 | 二分查找、树操作 |
| O(n) | 线性 | 遍历数组、链表 |
| O(n log n) | 线性对数 | 归并排序、快速排序 |
| O(n²) | 平方 | 冒泡排序、嵌套循环 |
| O(2ⁿ) | 指数 | 递归求斐波那契 |
| O(n!) | 阶乘 | 全排列 |

### 空间复杂度

| 复杂度 | 示例 |
|--------|------|
| O(1) | 原地排序、简单变量 |
| O(n) | 数组复制、递归深度 |
| O(n²) | 二维数组、图邻接矩阵 |

## 学习建议

### 学习顺序

```
1. 基础数据结构（数组、链表、栈、队列）
2. 树形结构（二叉树、BST、平衡树）
3. 基础算法（排序、查找）
4. 图论基础（图的表示、DFS、BFS）
5. 算法思想（分治、贪心、动态规划）
6. 高级算法（图算法、字符串算法）
7. 实战练习（LeetCode、剑指Offer）
```

### 实践建议

1. **理论结合实践**
   - 理解数据结构的原理和适用场景
   - 动手实现核心操作
   - 分析时间和空间复杂度

2. **循序渐进**
   - 从简单数据结构开始
   - 逐步过渡到复杂结构
   - 先掌握基础再学习优化

3. **刷题巩固**
   - LeetCode按tag刷题
   - 注重思路而非代码
   - 总结解题模式

4. **应用导向**
   - 思考实际应用场景
   - 理解为什么用这个结构
   - 比较不同方案的优劣
