# 强连通分量（Strongly Connected Components）

## 一、基本概念

### 1.1 强连通的定义

**强连通（Strongly Connected）：**
> 在有向图中，如果两个顶点v和u，存在从v到u的路径，也存在从u到v的路径，则称v和u是强连通的。

**强连通分量（SCC）：**
> 有向图的极大强连通子图称为强连通分量

**直观理解：**
```
强连通：A ↔ B（互相可达）

不强连通：A → B（单向可达）
```

### 1.2 强连通分量的应用

**实际应用：**
- 社交网络分析（朋友圈检测）
- 程序分析（模块依赖）
- 网页链接分析
- 推荐系统

## 二、Tarjan算法

**核心思想：**
> 使用DFS，利用DFS树和lowlink值识别强连通分量

**关键概念：**
- **dfn[u]**：顶点u被发现的时间戳
- **low[u]**：u能回溯到的最早节点的dfn值

**算法步骤：**
1. 对每个未访问节点进行DFS
2. 维护dfn和low数组
3. 如果dfn[u] == low[u]，u是SCC的根
4. 栈中保存u到当前SCC的所有节点

## 三、Kosaraju算法

**核心思想：**
> 两次DFS，第二次在反转图中进行

**算法步骤：**
1. 第一次DFS：记录完成顺序
2. 反转图中所有边
3. 第二次DFS：按完成顺序的逆序
4. 每次DFS访问的节点构成一个SCC

## 四、算法对比

| 特性 | Tarjan | Kosaraju |
|------|--------|-----------|
| **DFS次数** | 1次 | 2次 |
| **实现复杂度** | 较复杂 | 较简单 |
| **空间复杂度** | O(V) | O(V) |
| **时间复杂度** | O(V+E) | O(V+E) |
| **适用性** | 通用 | 需要反转图 |
