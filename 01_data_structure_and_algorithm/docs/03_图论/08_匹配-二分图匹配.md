# 二分图匹配（Bipartite Matching）

## 一、基本概念

### 1.1 二分图的定义

**二分图（Bipartite Graph）：**
> 如果图的顶点集可以划分为两个不相交的子集U和V，使得每条边都连接U中的一个顶点和V中的一个顶点，则该图为二分图。

**判断方法：**
- 染色法：用两种颜色给顶点染色
- 如果相邻顶点颜色不同，则为二分图

### 1.2 匹配的定义

**匹配（Matching）：**
> 边的集合，其中任意两条边没有公共顶点

**最大匹配（Maximum Matching）：**
> 包含边数最多的匹配

**完美匹配（Perfect Matching）：**
> 所有顶点都被匹配（|U| = |V|）

## 二、匈牙利算法

### 2.1 增广路径

**增广路径（Augmenting Path）：**
> 从未匹配顶点开始，交替经过未匹配边和匹配边，到达另一个未匹配顶点的路径

**增广路径性质：**
- 路径长度为奇数
- 起点和终点都未匹配
- 可以通过反转路径上的匹配状态增加匹配数

### 2.2 匈牙利算法流程

**算法步骤：**
```
1. 初始化：所有顶点未匹配
2. 对于U中的每个未匹配顶点u：
   a. 寻找从u出发的增广路径
   b. 如果找到增广路径，反转路径上的匹配状态
   c. 匹配数+1
3. 重复直到无法找到增广路径
```

**寻找增广路径（DFS）：**
```
对于U中的顶点u：
1. 尝试匹配u到V中的顶点v
2. 如果v未匹配，直接匹配
3. 如果v已匹配，尝试为v的原配找新配
4. 递归搜索
```

## 三、应用场景

### 3.1 工作分配

**问题：**
- 工人与任务的匹配
- 最大化分配数量

**解决方案：**
- 工人作为U集合
- 任务作为V集合
- 匈牙利算法求最大匹配

### 3.2 婚姻匹配

**稳定婚姻问题（Stable Marriage）：**
- 男性和女性的偏好
- 寻找稳定匹配方案
- Gale-Shapley算法

### 3.3 资源分配

**应用：**
- 服务器分配
- 课程安排
- 人员调度

## 四、复杂度分析

**时间复杂度：**
- 邻接矩阵：O(V³)
- 邻接表：O(VE)

**空间复杂度：**
- O(V + E)

## 五、总结

**二分图匹配是组合优化的经典问题，匈牙利算法是求解最大匹配的高效算法。**
