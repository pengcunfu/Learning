## 图的基本概念

**图的定义**

> 数据结构和算法是计算机科学的两个重要分支，它们研究的是如何有效地存储、组织和处理数据。数据结构是指数据的逻辑结构和物理结构，以及对数据的基本操作。算法是指解决特定问题的一系列有限的步骤，以及对算法的正确性和效率的分析。数据结构和算法是相互依赖的，数据结构决定了算法的设计，算法反过来影响了数据结构的选择和优化。



1. **顶点（Vertex）**：
   - 图中的基本元素，每个顶点代表一个对象。
   - 顶点通常用 V 表示，图中顶点的集合表示为 V = {v1, v2, ..., vn}。
2. **边（Edge）**：
   - 顶点之间的连接关系。
   - 无向边（Undirected Edge）：连接两个顶点，没有方向性。用 (vi, vj) 表示。
   - 有向边（Directed Edge）：连接两个顶点，有方向性。用 <vi, vj> 表示。
3. **度（Degree）**：
   - 顶点的度是连接到该顶点的边的数量。
   - 无向图中，顶点的度是连接到该顶点的边的数量。
   - 有向图中，顶点的入度（In-Degree）是指指向该顶点的边的数量，出度（Out-Degree）是指从该顶点出发的边的数量。







# 图的方法

图是一种非线性的数据结构，它由一组顶点和一组边组成，边可以表示顶点之间的关系。图有很多种类，如无向图、有向图、带权图、连通图、树、二分图等。图有很多种操作，如：

- 创建图：根据给定的顶点和边的信息，构造图的存储结构，如邻接矩阵、邻接表、十字链表等。
- 遍历图：按照一定的顺序访问图中的所有顶点，如深度优先遍历、广度优先遍历等。
- 查找图：在图中查找满足一定条件的顶点或边，如查找某个顶点的度、查找两个顶点之间是否存在路径等。
- 插入图：在图中增加一个顶点或一条边，如插入一个孤立的顶点、插入一条连接两个顶点的边等。
- 删除图：在图中删除一个顶点或一条边，如删除一个度为零的顶点、删除一条连接两个顶点的边等。
- 应用图：利用图的特性和算法解决实际问题，如求最短路径、最小生成树、拓扑排序、关键路径等。







# 图的类型

1. **无向图（Undirected Graph）**：
   - 边没有方向性，即 (vi, vj) 与 (vj, vi) 表示同一条边。
2. **有向图（Directed Graph）**：
   - 边有方向性，即 <vi, vj> 表示从 vi 到 vj 的一条边，不等同于 <vj, vi>。
3. **加权图（Weighted Graph）**：
   - 边带有权重，用于表示边的代价、距离或容量等。
4. **无权图（Unweighted Graph）**：
   - 边没有权重，所有边的权重可以看作相等。







# 图的存储结构

图的表示：

1. **邻接矩阵（Adjacency Matrix）**：
   - 用一个 n x n 的矩阵表示图，其中 n 是顶点的数量。
   - 如果顶点 vi 和 vj 之间有边，则矩阵 A[i][j] 为 1（有向图）或相应的权重（加权图），否则为 0。
2. **邻接表（Adjacency List）**：
   - 用一个数组表示图中的顶点，每个顶点有一个链表，链表中存储与该顶点相邻的顶点。
   - 更适合稀疏图，即边的数量远小于顶点的数量平方。

# 图的最短路径算法

Bellman-Floyd

**迪杰斯特拉算法**（Dijkstra's Algorithm）是一种用于计算单源最短路径的算法，可以用于找出从图中某一源点到所有其他顶点的最短路径。该算法是 **贪心算法** 的典型应用之一，它在许多最短路径问题中被广泛使用，尤其是当图的边权非负时。

### 算法原理

1. **初始化**：将源点的距离初始化为0，其他所有点的距离初始化为无穷大。
2. **选择未处理节点**：选择当前最短的未处理节点，计算从该节点出发的所有边的最短路径，更新它们的距离。
3. **更新距离**：对于每个邻接节点，若经过当前节点的路径比原有的路径更短，则更新该邻接节点的距离。
4. **重复**：直到所有节点都被处理完成。

### 算法步骤

1. 初始化一个最短路径数组 `dist[]`，其中 `dist[s] = 0`（源点的距离为0），其他节点的 `dist[]` 为无穷大。
2. 创建一个集合 `S`，用于存储已确定最短路径的节点，初始时为空。
3. 从未处理的节点中选取 `dist[]` 最小的节点加入集合 `S`。
4. 对该节点的每个邻接节点进行松弛操作：如果通过当前节点到某个邻接节点的路径更短，则更新该节点的 `dist[]` 值。
5. 重复步骤 3 和 4，直到所有节点都被加入到集合 `S`。

### 算法的实现

我们可以使用 **邻接矩阵** 或 **邻接表** 来表示图。为了高效地选择当前最短的节点，可以使用 **优先队列**（通常使用 **最小堆**）来存储待处理的节点。

#### 基于优先队列的迪杰斯特拉算法实现

```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <climits>
using namespace std;

#define INF INT_MAX  // 无穷大

class Graph {
public:
    int V;  // 顶点数
    vector<vector<pair<int, int>>> adjList;  // 邻接表：pair<邻接节点, 权重>

    // 构造函数，初始化图的顶点数
    Graph(int V) : V(V) {
        adjList.resize(V);
    }

    // 添加边
    void addEdge(int u, int v, int weight) {
        adjList[u].push_back({v, weight});
        adjList[v].push_back({u, weight});  // 因为是无向图
    }

    // 迪杰斯特拉算法
    void dijkstra(int source) {
        vector<int> dist(V, INF);  // 存储源点到其他所有顶点的最短路径
        dist[source] = 0;

        // 优先队列（最小堆），存储当前节点及其到源点的距离
        priority_queue<pair<int, int>, vector<pair<int, int>>, greater<pair<int, int>>> pq;
        pq.push({0, source});  // 源点的距离为0

        while (!pq.empty()) {
            int u = pq.top().second;  // 当前节点
            int d = pq.top().first;   // 当前节点的距离
            pq.pop();

            // 如果当前节点的距离已经大于已知最短距离，则跳过
            if (d > dist[u]) continue;

            // 遍历当前节点的邻接点
            for (auto& edge : adjList[u]) {
                int v = edge.first;
                int weight = edge.second;

                // 松弛操作
                if (dist[u] + weight < dist[v]) {
                    dist[v] = dist[u] + weight;
                    pq.push({dist[v], v});
                }
            }
        }

        // 输出从源点到每个顶点的最短距离
        cout << "源点 " << source << " 到各顶点的最短距离:\n";
        for (int i = 0; i < V; ++i) {
            if (dist[i] == INF)
                cout << "顶点 " << i << ": 无路径\n";
            else
                cout << "顶点 " << i << ": " << dist[i] << endl;
        }
    }
};

int main() {
    Graph g(6);  // 创建一个有6个顶点的图

    // 添加边：图是无向图，使用邻接表表示
    g.addEdge(0, 1, 5);
    g.addEdge(0, 2, 3);
    g.addEdge(1, 2, 2);
    g.addEdge(1, 3, 6);
    g.addEdge(2, 3, 7);
    g.addEdge(2, 4, 4);
    g.addEdge(3, 4, 1);
    g.addEdge(3, 5, 2);
    g.addEdge(4, 5, 5);

    // 执行迪杰斯特拉算法，从源点0开始
    g.dijkstra(0);

    return 0;
}
```

### 代码解释

1. **图的表示**：
   - 使用邻接表来表示图，`adjList[u]` 存储从顶点 `u` 出发的所有边的邻接节点和边的权值。
   - `pair` 中，`first` 表示邻接节点，`second` 表示边的权重。
2. **优先队列**：
   - 使用 `priority_queue, vector>, greater>>` 来维护当前最短的节点，其中 `pair.first` 为距离，`pair.second` 为节点。
   - `greater>` 是为了让队列中的元素按距离从小到大排列（最小堆）。
3. **松弛操作**：
   - 对每个节点的邻接点进行松弛操作，如果通过当前节点到邻接点的路径更短，则更新邻接点的距离，并将其加入优先队列。
4. **输出**：
   - 输出从源点到所有其他顶点的最短路径。如果某个顶点不可达，则输出 "无路径"。

### 输出示例

```
源点 0 到各顶点的最短距离:
顶点 0: 0
顶点 1: 5
顶点 2: 3
顶点 3: 8
顶点 4: 7
顶点 5: 10
```

### 时间复杂度

- 时间复杂度： 

  - 使用优先队列时，每次提取最小元素和更新距离的操作都是 O(log?V)O(\log V)。
- 对每条边进行一次松弛操作，因此总的时间复杂度是 O(Elog?V)O(E \log V)，其中 EE 是边数，VV 是顶点数。

- 空间复杂度： 

  - 需要存储图的邻接表，空间复杂度为 O(V+E)O(V + E)。
- 还需要存储距离数组 `dist[]` 和优先队列，空间复杂度为 O(V)O(V)。

### 总结

迪杰斯特拉算法是一种高效的算法，能够在带权无向图中找到源点到其他所有顶点的最短路径。通过使用优先队列（最小堆），可以有效地选择当前最短的未处理节点，保证每次更新最短路径的操作都能以最小的代价完成。该算法适用于图中的所有边权为非负数的情况。

### C++ 数据结构图的定义与实现：链表实现

图（Graph）是一种重要的数据结构，用于表示对象之间的关系。在计算机科学中，图广泛应用于各类问题的解决，比如网络路由、社交网络、推荐系统、地图路径规划等。

### 1. 图的基本概念

图是由一组**顶点**（Vertex）和一组**边**（Edge）构成的结构。每条边连接两个顶点，并表示它们之间的关系。

- **顶点（Vertex）**：图中的每一个元素，表示图中的一个节点。
- **边（Edge）**：连接两个顶点的线，表示它们之间的关系。每条边可能有方向（有向图）或无方向（无向图）。

#### 图的分类

1. **有向图（Directed Graph）**：边具有方向，表示从一个顶点指向另一个顶点。
2. **无向图（Undirected Graph）**：边没有方向，表示两个顶点之间存在相互关系。
3. **加权图（Weighted Graph）**：边上具有权重，用来表示连接两个顶点之间的代价、距离等。
4. **非加权图（Unweighted Graph）**：边没有权重，通常表示连接关系。

#### 图的表示方法

图可以通过多种方式表示，最常见的有：

- **邻接矩阵（Adjacency Matrix）**：通过二维矩阵来表示图，矩阵的元素表示顶点之间是否存在边。
- **邻接表（Adjacency List）**：通过链表的形式来表示每个顶点及其所有邻接的顶点。

由于链表具有动态内存管理的优势，邻接表常被用于实现图的存储。

### 2. 基于链表实现的图结构

在这篇博客中，我们将基于**链表**实现一个简单的图结构，重点关注如何在 C++ 中使用链表（`Linked List`）存储图的邻接表。

#### 2.1 图的基本类设计

图的实现需要考虑以下几个方面：

- **顶点的存储**：通常，图的顶点可以用一个整数来表示，或者使用其他数据类型。
- **边的存储**：在无向图中，边是对称的，因此每条边会被存储两次；而在有向图中，每条边只会被存储一次。
- **图的邻接表**：每个顶点会有一个链表，存储与该顶点相邻的其他顶点。

我们将定义一个图类 `Graph`，并使用链表来表示图的邻接表。

#### 2.2 C++ 代码实现

##### 2.2.1 图的顶点和边的定义

我们首先定义链表节点类 `AdjListNode`，该类表示邻接表中的一个节点，其中存储相邻顶点的索引和边的权重。然后定义 `Graph` 类，包含图的结构和基本操作。

```cpp
#include <iostream>
#include <vector>
#include <list>
#include <iterator>

// 定义邻接表中的节点
class AdjListNode {
public:
    int dest;  // 目标顶点
    int weight;  // 边的权重

    // 构造函数
    AdjListNode(int d, int w) : dest(d), weight(w) {}
};

// 定义图类
class Graph {
public:
    int V;  // 图的顶点数
    std::vector<std::list<AdjListNode>> adjList;  // 邻接表

    // 构造函数
    Graph(int vertices) : V(vertices) {
        adjList.resize(vertices);  // 根据顶点数初始化邻接表
    }

    // 添加边的方法（无向图）
    void addEdge(int src, int dest, int weight) {
        adjList[src].push_back(AdjListNode(dest, weight));  // 从src到dest的边
        adjList[dest].push_back(AdjListNode(src, weight));  // 无向图，从dest到src的边
    }

    // 打印图的邻接表
    void printGraph() {
        for (int i = 0; i < V; i++) {
            std::cout << "顶点 " << i << ": ";
            for (auto& node : adjList[i]) {
                std::cout << "(" << node.dest << ", " << node.weight << ") ";
            }
            std::cout << std::endl;
        }
    }
};
```

**解释：**

1. `AdjListNode` 类：
   - `dest`：邻接顶点的索引。
   - `weight`：边的权重（如果是无权图，这个值可以省略）。
2. `Graph` 类：
   - `V`：顶点的数量。
   - `adjList`：一个向量，每个元素是一个链表，表示每个顶点的邻接节点。

#### 2.2.2 操作示例

接下来，我们通过创建一个图实例，添加一些边，并打印邻接表。

```cpp

    g.addEdge(0, 1, 10);
    g.addEdge(0, 4, 20);
    g.addEdge(1, 2, 30);
    g.addEdge(1, 3, 40);
    g.addEdge(2, 4, 50);

    // 打印图的邻接表

    return 0;
}
```

**输出：**

```

顶点 1: (0, 10) (2, 30) (3, 40) 
顶点 2: (1, 30) (4, 50) 
顶点 3: (1, 40) 
顶点 4: (0, 20) (2, 50) 
```

**解释：**

- 我们创建了一个有 5 个顶点的无向图。
- 调用了 `addEdge` 方法来添加边，其中每条边的第一个参数是源顶点，第二个参数是目标顶点，第三个参数是边的权重。
- 使用 `printGraph` 方法输出图的邻接表，显示每个顶点及其相邻顶点和权重。

### 3. 图的遍历：深度优先搜索（DFS）与广度优先搜索（BFS）

图的遍历是图操作中常见的任务。通过遍历图，可以查找某些路径、查找连通分量等。

#### 3.1 深度优先搜索（DFS）

DFS 是从一个起始顶点开始，尽可能深入到每个顶点，直到到达一个没有未被访问的邻接顶点的顶点，然后回溯到上一个顶点，继续遍历。

**DFS 代码实现：**

```cpp
#include <stack>

void DFS(int start) {
    std::vector<bool> visited(V, false);  // 记录顶点是否已被访问
    std::stack<int> stack;

    // 从起始顶点开始
    stack.push(start);
    visited[start] = true;

    while (!stack.empty()) {
        int vertex = stack.top();
        stack.pop();

        std::cout << "访问顶点 " << vertex << std::endl;

        // 遍历当前顶点的所有邻接节点 
        for (auto& node : adjList[vertex]) { 
        if (!visited[node.dest]) { stack.push(node.dest); 				visited[node.dest] = true; 
        } 
        }
    }
}
```

#### 3.2 广度优先搜索（BFS）

BFS 是从一个起始顶点开始，首先访问该顶点的所有邻接顶点，然后再访问这些邻接顶点的邻接顶点。

**BFS 代码实现：**

```cpp
#include <queue>

void BFS(int start) {
    std::vector<bool> visited(V, false);  // 记录顶点是否已被访问
    std::queue<int> queue;

    // 从起始顶点开始
    queue.push(start);
    visited[start] = true;
    
    while (!queue.empty()) {
        int vertex = queue.front();
        queue.pop();
    
        std::cout << "访问顶点 " << vertex << std::endl;
    
        // 遍历当前顶点的所有邻接节点
        for (auto& node : adjList[vertex]) {
            if (!visited[node.dest]) {
                queue.push(node.dest);
                visited[node.dest] = true;
            }
        }
    }
}
```
