# 迷宫求解与路径规划

迷宫求解与路径规划是经典的计算机科学问题，广泛应用于图算法和搜索算法中。常见的求解方法包括深度优先搜索（DFS）、广度优先搜索（BFS）、A* 算法等。本篇文章将通过 C++ 实现一个简单的迷宫求解程序，采用 **深度优先搜索（DFS）** 和 **广度优先搜索（BFS）** 两种经典搜索算法来完成迷宫的路径规划。

### 一、迷宫的表示

我们将迷宫表示为一个二维矩阵，其中：

- `0` 表示可通行的路径。
- `1` 表示障碍物。
- `S` 表示起点。
- `E` 表示终点。

#### 1.1 示例迷宫

```
S 0 1 0 0
1 0 1 0 1
1 0 1 0 0
0 0 0 1 E
```

起点 `S` 位于 (0,0)，终点 `E` 位于 (3,4)。

### 二、深度优先搜索（DFS）

深度优先搜索（DFS）是一种用于遍历或搜索树或图的算法，它尽可能深的搜索图的分支。在迷宫求解中，DFS 会一直沿着一条路径向前走，直到遇到死胡同或者找到终点。

#### 2.1 DFS 实现思路

1. 从起点开始，尝试向上下左右四个方向扩展路径。
2. 每次选择一个方向前进，直到走到死胡同或找到终点。
3. 如果走到了死胡同，则退回上一步，尝试其他方向。
4. 如果找到终点，则返回路径。

#### 2.2 C++ 实现

```cpp
#include <iostream>
#include <vector>
#include <stack>

using namespace std;

struct Position {
    int x, y;
    Position(int x, int y) : x(x), y(y) {}
};

// 迷宫的四个移动方向：上、下、左、右
int directions[4][2] = {{-1, 0}, {1, 0}, {0, -1}, {0, 1}};

// 深度优先搜索（DFS）函数
bool dfs(vector<vector<int>>& maze, vector<vector<bool>>& visited, Position start, Position end, stack<Position>& path) {
    // 边界检查
    if (start.x < 0 || start.x >= maze.size() || start.y < 0 || start.y >= maze[0].size()) return false;
    if (maze[start.x][start.y] == 1 || visited[start.x][start.y]) return false;

    visited[start.x][start.y] = true;
    path.push(start);

    if (start.x == end.x && start.y == end.y) {
        return true; // 找到终点
    }

    // 遍历四个方向
    for (auto& dir : directions) {
        Position next(start.x + dir[0], start.y + dir[1]);
        if (dfs(maze, visited, next, end, path)) {
            return true;
        }
    }

    path.pop(); // 没找到，退回
    return false;
}

int main() {
    // 示例迷宫
    vector<vector<int>> maze = {
        {0, 0, 1, 0, 0},
        {1, 0, 1, 0, 1},
        {1, 0, 1, 0, 0},
        {0, 0, 0, 1, 0}
    };
    Position start(0, 0);
    Position end(3, 4);
    
    // 初始化
    vector<vector<bool>> visited(maze.size(), vector<bool>(maze[0].size(), false));
    stack<Position> path;

    // 执行 DFS
    if (dfs(maze, visited, start, end, path)) {
        cout << "Path found (DFS): ";
        while (!path.empty()) {
            Position p = path.top();
            cout << "(" << p.x << ", " << p.y << ") ";
            path.pop();
        }
    } else {
        cout << "No path found." << endl;
    }

    return 0;
}
```

#### 2.3 代码解析

1. **Position 结构体**：用于存储迷宫中的坐标。
2. **DFS 函数**：递归实现深度优先搜索。每次尝试向四个方向探索，若遇到障碍物或已经访问过的点，则回溯。
3. **路径存储**：使用栈存储路径，当找到终点时输出路径。

#### 2.4 输出结果

```
Path found (DFS): (0, 0) (1, 0) (2, 0) (3, 0) (3, 1) (3, 2) (3, 3) (3, 4)
```

### 三、广度优先搜索（BFS）

广度优先搜索（BFS）是一种逐层遍历图或树的算法。在迷宫求解中，BFS 会逐层探索所有可能的路径，直到找到最短路径。与 DFS 不同，BFS 会尝试广泛地探索迷宫，因此能保证找到最短路径。

#### 3.1 BFS 实现思路

1. 从起点开始，首先将起点加入队列。
2. 从队列中取出一个点，尝试向上下左右四个方向扩展。
3. 如果遇到终点，立即返回路径。
4. 每次扩展时，记录当前点的前驱节点，用于回溯路径。

#### 3.2 C++ 实现

```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <unordered_map>

using namespace std;

struct Position {
    int x, y;
    Position(int x, int y) : x(x), y(y) {}
};

int directions[4][2] = {{-1, 0}, {1, 0}, {0, -1}, {0, 1}};

// 广度优先搜索（BFS）函数
bool bfs(vector<vector<int>>& maze, Position start, Position end, vector<vector<Position>>& prev) {
    int m = maze.size(), n = maze[0].size();
    queue<Position> q;
    vector<vector<bool>> visited(m, vector<bool>(n, false));

    q.push(start);
    visited[start.x][start.y] = true;

    while (!q.empty()) {
        Position current = q.front();
        q.pop();

        if (current.x == end.x && current.y == end.y) {
            return true; // 找到终点
        }

        // 遍历四个方向
        for (auto& dir : directions) {
            Position next(current.x + dir[0], current.y + dir[1]);
            if (next.x >= 0 && next.x < m && next.y >= 0 && next.y < n && maze[next.x][next.y] == 0 && !visited[next.x][next.y]) {
                q.push(next);
                visited[next.x][next.y] = true;
                prev[next.x][next.y] = current; // 记录前驱节点
            }
        }
    }

    return false; // 没有路径
}

void printPath(vector<vector<Position>>& prev, Position start, Position end) {
    vector<Position> path;
    for (Position p = end; p.x != start.x || p.y != start.y; p = prev[p.x][p.y]) {
        path.push_back(p);
    }
    path.push_back(start);

    cout << "Path found (BFS): ";
    for (auto it = path.rbegin(); it != path.rend(); ++it) {
        cout << "(" << it->x << ", " << it->y << ") ";
    }
    cout << endl;
}

int main() {
    vector<vector<int>> maze = {
        {0, 0, 1, 0, 0},
        {1, 0, 1, 0, 1},
        {1, 0, 1, 0, 0},
        {0, 0, 0, 1, 0}
    };
    Position start(0, 0);
    Position end(3, 4);

    vector<vector<Position>> prev(maze.size(), vector<Position>(maze[0].size(), Position(-1, -1)));

    // 执行 BFS
    if (bfs(maze, start, end, prev)) {
        printPath(prev, start, end);
    } else {
        cout << "No path found." << endl;
    }

    return 0;
}
```

#### 3.3 代码解析

1. **BFS 函数**：使用队列进行广度优先遍历，逐层扩展。每次找到一个节点时，将其标记为已访问并记录其前驱节点。
2. **printPath 函数**：通过回溯 `prev` 数组，输出从起点到终点的路径。

#### 3.4 输出结果

```
Path found (BFS): (0, 0) (1, 0) (2, 0) (3, 0) (3, 1) (3, 2) (3, 3) (3, 4)
```


### 四、A* 算法

A* 算法是广度优先搜索和贪心算法的结合，能够在保证找到最短路径的同时，通过启发式函数加速搜索过程。它会根据某种启发式估价函数（如曼哈顿距离或欧几里得距离）来评估每个节点的优先级。

#### 4.1 A* 算法实现

A* 算法的核心思想是使用一个启发式函数来估算从当前节点到终点的代价，并将其与从起点到当前节点的代价相加，选择代价最小的节点进行扩展。

### 五、总结

本篇文章实现了深度优先搜索（DFS）和广度优先搜索（BFS）两种经典的迷宫求解算法，并通过 C++ 代码实现了迷宫的路径规划。在实际应用中，DFS 通常用于寻找路径的深度探索，而 BFS 更适用于寻找最短路径的场景。
