# Kruskal算法（克鲁斯卡尔算法）

## 一、算法概述

### 1.1 算法简介

**Kruskal算法**是求解**最小生成树（MST）**的经典贪心算法，由Joseph Kruskal在1956年提出。

**核心思想：**
> 按边的权值从小到大选择，每次选择不形成环的最小边，直到连通所有顶点

**与Prim算法的区别：**
- Prim：逐步扩展树
- Kruskal：逐步合并森林

### 1.2 算法特点

**优点：**
- 适合**稀疏图**
- 实现简单
- 易于并行化
- 不需要优先队列

**缺点：**
- 需要排序所有边
- 不适合稠密图

## 二、算法原理

### 2.1 核心思想

**贪心策略：**
```
1. 将所有边按权值排序
2. 从小到大依次选择边
3. 如果边的两个端点不在同一集合，
   则选择该边（合并集合）
4. 重复直到所有顶点连通
```

### 2.2 关键数据结构：并查集

**并查集（Union-Find）的作用：**
- 判断两个顶点是否在同一集合
- 合并两个集合

**基本操作：**
```
Find(x)：查找x所属集合的代表
Union(x, y)：合并x和 y所属的集合
```

## 三、算法步骤

### 3.1 详细步骤

**初始化：**
```
1. 记录图的顶点数V和边数E
2. 将所有边按权值排序
3. 初始化并查集，每个顶点独立
```

**主循环：**
```
for 每条边 (u, v, w) in 排序后的边列表：
    if Find(u) != Find(v):  // u和v不在同一集合
        选择边(u, v)
        Union(u, v)        // 合并集合
        边数++
        if 边数 == V-1:      // 已选够V-1条边
            break
```

### 3.2 示例

**给定图：**
```
    A---4---B
    |\       |
    | 1     2
    |       |
    D---8---C
```

**边排序：**
```
(A,D)=1, (B,C)=2, (A,B)=4, (A,C)=7, (D,C)=8
```

**执行过程：**
```
初始：每个顶点独立

选边(A,D)=1：
  合并A,D → {A,D}
  边数=1

选边(B,C)=2：
  合并B,C → {B,C}
  边数=2

选边(A,B)=4：
  A在{A,D}，B在{B,C}
  不同集合，选择
  合并 → {A,D,B,C}
  边数=3

完成！总权值=1+2+4=7
```

## 四、正确性证明

### 4.1 割性质

**定理：**
> 每次选择的最小不形成环的边，必然属于某个最小生成树

**证明思路：**
- 反证法
- 假设该边不在MST中
- 说明如何构造包含该边的更小生成树
- 矛盾

### 4.2 环性质

**定理：**
> 环中权值最大的边不属于任何最小生成树

**应用：**
- Kruskal跳过形成环的边
- 保证选择的边都是必要的

## 五、性能分析

### 5.1 时间复杂度

**时间分解：**
```
排序边：O(E log E)
并查集操作：O(E α(V))
总共：O(E log E)
```

**说明：**
- E为边数，V为顶点数
- α(V)为反阿克曼函数，实际≤5
- 对于稀疏图：O(E log V)

### 5.2 空间复杂度

**空间需求：**
```
存储边：O(E)
并查集：O(V)
总共：O(V + E)
```

## 六、实现要点

### 6.1 边的排序

**排序方法：**
- 快速排序：O(E log E)
- 堆排序：O(E log E)
- 基数排序：O(E × k)，k为最大权值位数

### 6.2 并查集优化

**按秩合并：**
- 将小树合并到大树
- 避免树过高

**路径压缩：**
- 查找时扁平化树结构
- 提高后续查找效率

**时间复杂度：**
- 优化后：接近O(1)

## 七、与Prim算法对比

| 特性 | Prim | Kruskal |
|------|------|----------|
| **策略** | 扩展树 | 合并森林 |
| **适合** | 稠密图 | 稀疏图 |
| **数据结构** | 优先队列 | 排序+并查集 |
| **复杂度** | O(E log V) | O(E log E) |
| **并行性** | 困难 | 容易 |

## 八、应用实例

### 8.1 网络设计

**问题：**
- 用最小成本连接多个城市
- 铺设光缆、管道

**解决方案：**
- 城市作为顶点
- 铺设成本作为权值
- Kruskal求MST

### 8.2 聚类分析

**层次聚类：**
- 每个数据点一个簇
- Kruskal算法思想
- 合并最近的簇

## 九、总结

**Kruskal算法是求解最小生成树的经典算法，通过贪心策略和并查集，简洁高效地解决问题。**
