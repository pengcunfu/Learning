# 剑指Offer题目分类整理

本目录包含剑指Offer的算法题目，按照数据结构和算法类型进行了分类整理。

## 目录结构

### [01_数组](./01_数组/)
包含13道数组相关题目，涉及数组遍历、双指针法、二分查找、快速排序、堆、滑动窗口等知识点。

### [02_链表](./02_链表/)
包含9道链表相关题目，涉及链表遍历、双指针法（快慢指针）、链表反转、链表合并、环检测等知识点。

### [03_二叉树](./03_二叉树/)
包含16道二叉树相关题目，涉及树的遍历、递归、二叉搜索树、平衡树、树的重建、序列化等知识点。

### [04_栈和队列](./04_栈和队列/)
包含3道栈和队列相关题目，涉及栈和队列的基本操作及相互实现。

### [05_字符串](./05_字符串/)
包含10道字符串相关题目，涉及字符串遍历、双指针法、KMP算法、正则表达式、滑动窗口、哈希表等知识点。

### [06_动态规划](./06_动态规划/)
包含11道动态规划相关题目，涉及动态规划基础、状态转移方程、空间优化、贪心算法、数学归纳等知识点。

### [07_搜索和回溯](./07_搜索和回溯/)
包含2道搜索和回溯相关题目，涉及深度优先搜索（DFS）、回溯算法、剪枝、矩阵遍历等知识点。

### [08_位运算](./08_位运算/)
包含2道位运算相关题目，涉及位运算基础、位运算技巧、原码反码补码等知识点。

### [09_数学与数字](./09_数学与数字/)
包含9道数学与数字相关题目，涉及快速幂、大数处理、数学规律、约瑟夫环问题、双指针法等知识点。

### [10_其他](./10_其他/)
包含2道其他类型题目，涉及堆（优先队列）、数据流处理、编程语言基础等知识点。

## 统计信息

- **总题数**: 77 题
- **分类数**: 10 类
- **最多题目的分类**: 二叉树（16题）
- **最少题目的分类**: 搜索和回溯、位运算（各2题）

## 学习建议

1. **按分类学习**: 建议按照数据结构和算法类型分类学习，掌握每类题目的通用解法
2. **注重基础**: 重点掌握数组、链表、二叉树等基础数据结构
3. **理解原理**: 不仅要知道怎么做，更要理解为什么这样做
4. **多练习**: 每道题目都要亲自编码实现，加深理解
5. **总结归纳**: 做完题目后及时总结解题思路和技巧

   - 位运算（08_位运算）
