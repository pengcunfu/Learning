# 字符串（String）

## 一、字符串概述

### 1.1 什么是字符串？

**字符串：**
> 由字符组成的序列，是计算机中最常用的数据类型之一

**核心特点：**
```
1. 字符序列：有序的字符集合
2. 不可变性：很多实现中字符串不可变
3. 特殊编码：需要字符编码方案
4. 丰富操作：匹配、搜索、替换等
```

### 1.2 字符编码

**ASCII编码：**
```
7位编码，表示128个字符
包括：大小写字母、数字、标点、控制字符
```

**Unicode编码：**
```
目标：表示世界上所有字符
编码方式：
- UTF-8：变长1-4字节，兼容ASCII
- UTF-16：变长2-4字节
- UTF-32：固定4字节
```

**中文编码：**
```
GBK：中国国家标准编码
GB2312：简体中文
Big5：繁体中文
```

## 二、字符串的存储

### 2.1 数组存储

**C风格字符串：**
```
以空字符'\0'结尾
连续字符数组

示例：
"Hello" → ['H','e','l','l','o','\0']

特点：
- 简单高效
- 需要手动管理
- 容易出错（缓冲区溢出）
```

**内存布局：**
```
地址：  1000  1001  1002  1003  1004  1005
内容：  'H'   'e'   'l'   'l'   'o'  '\0'
```

### 2.2 动态存储

**描述符方式：**
```
包含信息：
- 字符指针
- 长度
- 容量

优点：
- 记录长度，O(1)获取
- 安全的边界检查
```

**不可变字符串：**
```
字符串创建后不能修改
修改操作创建新字符串

优点：
- 线程安全
- 可以共享
- 便于哈希

缺点：
- 修改开销大
```

### 2.3 链式存储

**链表实现：**
```
每个字符一个节点
适合频繁插入删除
空间开销大
访问效率低
```

## 三、字符串的基本操作

### 3.1 基础操作

**获取长度：**
```
C风格：遍历到'\0'，O(n)
描述符：直接读取，O(1)
```

**连接：**
```
操作：s1 + s2
实现：
- 分配新空间
- 复制s1
- 复制s2

时间：O(n+m)
```

**子串：**
```
操作：substring(start, end)
实现：
- 分配新空间
- 复制指定部分

时间：O(end-start)
```

### 3.2 比较操作

**字典序比较：**
```
从左到右逐字符比较
第一个不同字符决定大小
都相同则长度长的更大

时间：O(min(n,m))
```

**相等性判断：**
```
先比较长度
再逐字符比较

时间：O(n)
```

### 3.3 搜索操作

**查找字符：**
```
线性扫描：O(n)
```

**查找子串：**
```
朴素算法：O(n×m)
KMP算法：O(n+m)
Boyer-Moore：通常O(n/m)
```

**正则表达式：**
```
模式匹配
复杂度高
功能强大
```

## 四、字符串的高级操作

### 4.1 模式匹配

**朴素匹配：**
```
思路：
- 文本串每个位置作为起点
- 尝试匹配模式串

时间：O(n×m)
```

**KMP算法：**
```
优化：
- 利用已匹配信息
- 避免重复比较

时间：O(n+m)
```

**Boyer-Moore：**
```
优化：
- 从右向左匹配
- 坏字符规则
- 好后缀规则

平均：O(n/m)
```

### 4.2 编辑操作

**编辑距离：**
```
定义：
将一个字符串转换成另一个
的最少操作次数

操作：插入、删除、替换

算法：动态规划
时间：O(n×m)
```

**最长公共子串：**
```
找出两个字符串的最长公共连续子串

算法：动态规划
时间：O(n×m)
```

### 4.3 变换操作

**大小写转换：**
```
操作：
- toupper：转大写
- tolower：转小写

注意： locale相关
```

**去除空白：**
```
trim：去除两端空白
strip：类似功能
```

**分割与连接：**
```
split：按分隔符分割
join：连接字符串数组
```

## 五、字符串的实现

### 5.1 C风格实现

**特点：**
```
- 简单字符数组
- 以'\0'结尾
- 需要手动管理内存
```

**问题：**
```
缓冲区溢出
长度计算开销
不安全操作
```

### 5.2 高级语言实现

**Java String：**
```
特点：
- 不可变
- Unicode支持
- 自动内存管理

实现：
- 字符数组
- 哈希缓存
- 字符串常量池
```

**Python String：**
```
特点：
- 不可变
- Unicode原生
- 丰富的字符串方法

实现：
- 变长编码（UTF-8或类似）
- 优化的连接操作
```

**C++ std::string：**
```
特点：
- 可变（通常）
- 引用计数或写时复制
- 动态增长

实现：
- 字符数组
- 容量管理
- 小字符串优化
```

## 七、字符串算法

### 7.1 经型算法

**反转字符串：**
```
双指针法：
- 首尾指针向中间移动
- 交换字符

时间：O(n)
空间：O(1)
```

**回文判断：**
```
双指针法：
- 首尾指针向中间移动
- 比较字符

时间：O(n)
空间：O(1)
```

### 7.2 高级算法

**后缀数组：**
```
字符串的所有后缀排序
应用：模式匹配、最长重复子串
```

**后缀自动机：**
```
所有子串的紧凑表示
线性空间和时间构建
```

## 八、字符串优化

### 8.1 存储优化

**小字符串优化：**
```
短字符串内联在对象中
避免堆分配
```

**字符串驻留：**
```
相同内容的字符串共享
减少内存占用
```

### 8.2 操作优化

**延迟求值：**
```
推迟实际操作
减少复制
```

**Copy-on-Write：**
```
共享底层存储
修改时才复制
```

## 九、字符串vs字符数组

### 9.1 对比

| 特性 | 字符串 | 字符数组 |
|------|--------|----------|
| **抽象** | 高级 | 低级 |
| **管理** | 自动 | 手动 |
| **安全** | 高 | 低 |
| **开销** | 较大 | 最小 |
| **功能** | 丰富 | 基础 |

### 9.2 选择

**使用字符串：**
```
高级应用
重视安全
需要丰富功能
```

**使用字符数组：**
```
系统编程
性能关键
内存受限
```

## 十、总结

**字符串是字符序列的抽象，提供了丰富的文本处理能力，是现代编程的基础数据类型。**

**核心要点：**
1. 字符编码：ASCII、Unicode等
2. 存储方式：数组、描述符、链式
3. 操作丰富：匹配、搜索、替换
4. 实现差异：各语言有特点

**应用场景：**
- 文本处理
- 数据交换
- 用户界面
- 日志记录

**性能考虑：**
- 不可变字符串的复制开销
- 连接操作的特殊处理
- 编码转换成本
- 模式匹配算法选择
