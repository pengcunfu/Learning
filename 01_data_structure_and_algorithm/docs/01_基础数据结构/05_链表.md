# 链表（Linked List）

## 一、链表概述

### 1.1 什么是链表？

**链表：**
> 一种通过指针连接的线性数据结构，每个节点包含数据和指向下一个节点的指针

**核心特点：**
```
1. 非连续内存：元素在内存中不连续存储
2. 动态大小：运行时动态分配节点
3. 指针连接：通过指针将节点串联
4. 灵活增删：插入删除操作高效
```

**与数组对比：**
```
数组：连续内存，固定大小，O(1)访问
链表：分散内存，动态大小，O(n)访问
```

### 1.2 链表的内存模型

**单链表结构：**
```
内存布局（分散）：
地址1000: [数据|指针] → 地址2050
地址1005: [数据|指针] → 地址3100
地址2050: [数据|指针] → 地址1005
地址3100: [数据|指针] → NULL

逻辑结构（线性）：
[数据1] → [数据2] → [数据3] → [数据4] → NULL
```

## 二、链表的分类

### 2.1 单链表

**结构：**
```
节点包含：
- 数据域：存储数据
- 指针域：指向下一个节点

特点：
- 只能单向遍历
- 实现简单
```

**图示：**
```
┌────┐    ┌────┐    ┌────┐    ┌────┐
│Data│    │Data│    │Data│    │Data│
│Next│───→│Next│───→│Next│───→│NULL│
└────┘    └────┘    └────┘    └────┘
 Head
```

### 2.2 双向链表

**结构：**
```
节点包含：
- 数据域：存储数据
- 前驱指针：指向前一个节点
- 后继指针：指向后一个节点

特点：
- 可以双向遍历
- 实现稍复杂
```

**图示：**
```
         ┌────┐    ┌────┐    ┌────┐
         │Data│    │Data│    │Data│
NULL │←──│Prev│    │Prev│    │Prev│
         │Next│───→│Next│───→│Next│───→ NULL
         └────┘    └────┘    └────┘
           ↑
         Head
```

### 2.3 循环链表

**单循环链表：**
```
尾节点的next指向头节点

特点：
- 从任意节点可以遍历整个链表
- 适合循环处理场景
```

**双向循环链表：**
```
头节点prev指向尾节点
尾节点next指向头节点

特点：
- 完全对称
- 可以任意方向循环
```

## 三、链表的操作

### 3.1 基本操作

**遍历：**
```
算法：
从head开始
依次访问每个节点
直到NULL

时间：O(n)
```

**查找：**
```
按值查找：
遍历链表
比较每个节点数据

时间：O(n)

按位置查找：
从头遍历到指定位置

时间：O(n)
```

**获取长度：**
```
遍历整个链表
计数节点数量

时间：O(n)

优化：维护length变量
```

### 3.2 插入操作

**头部插入：**
```
时间：O(1)

步骤：
1. 创建新节点
2. 新节点next指向head
3. 更新head为新节点
```

**尾部插入：**
```
时间：O(n)（无尾指针）
      O(1)（有尾指针）

步骤：
1. 遍历到尾部
2. 尾节点next指向新节点
3. 新节点next设为NULL
```

**指定位置插入：**
```
时间：O(n)

步骤：
1. 找到插入位置的前驱节点
2. 新节点next指向前驱的next
3. 前驱next指向新节点
```

### 3.3 删除操作

**删除头节点：**
```
时间：O(1)

步骤：
1. 保存head的next
2. 释放head节点
3. 更新head为保存的next
```

**删除尾节点：**
```
时间：O(n)

步骤：
1. 找到倒数第二个节点
2. 释放尾节点
3. 倒数第二节点next设为NULL
```

**删除指定节点：**
```
时间：O(n)

步骤：
1. 找到要删除节点的前驱
2. 前驱next指向删除节点的next
3. 释放删除节点
```

## 四、链表的优缺点

### 4.1 优点

**动态大小：**
```
运行时分配
不需要预知大小
按需扩展
```

**高效插入删除：**
```
已知位置：O(1)
不需要移动元素
```

**内存利用：**
```
精确分配
不浪费空间
```

### 4.2 缺点

**访问低效：**
```
随机访问：O(n)
不能直接访问
```

**空间开销：**
```
每个节点需要额外指针空间
单链表：+1个指针
双向链表：+2个指针
```

**缓存不友好：**
```
内存不连续
缓存命中率低
```

## 五、链表vs数组

### 5.1 性能对比

| 操作 | 数组 | 链表 |
|------|------|------|
| **访问** | O(1) | O(n) |
| **头部插入** | O(n) | O(1) |
| **尾部插入** | O(1)* | O(n) |
| **指定位置** | O(n) | O(n) |
| **删除** | O(n) | O(n) |

*假设数组有空间

### 5.2 内存对比

| 特性 | 数组 | 链表 |
|------|------|------|
| **内存** | 连续 | 分散 |
| **开销** | 最小 | 指针空间 |
| **分配** | 一次性 | 按需 |
| **缓存** | 友好 | 不友好 |

### 5.3 选择标准

**选择数组：**
```
需要快速随机访问
数据量相对固定
重视缓存性能
内存空间紧张
```

**选择链表：**
```
频繁插入删除
数据量变化大
不需要随机访问
实现队列栈
```

## 六、链表的应用

### 6.1 基础应用

**实现抽象数据类型：**
```
栈：单链表实现
队列：带尾指针的单链表
双端队列：双向链表
```

**多项式表示：**
```
每个节点一项
按指数排序
便于加减运算
```

### 6.2 高级应用

**内存管理：**
```
空闲链表
内存块分配
```

**文件系统：**
```
FAT表
文件的物理存储
```

**高级数据结构：**
```
邻接表（图的存储）
哈希表的链地址法
跳表的底层结构
```

## 七、链表的高级话题

### 7.1 链表的技巧问题

**快慢指针：**
```
两个指针速度不同
- 快指针每次2步
- 慢指针每次1步

应用：
- 找中点
- 检测环
- 环的起点
```

**反转链表：**
```
迭代法：三指针
递归法：递归栈

时间：O(n)
空间：O(1)迭代，O(n)递归
```

**回文链表：**
```
找到中点
反转后半部分
比较前后半部分
```

### 7.2 链表的优化

**哨兵节点：**
```
哑节点简化边界处理
统一操作逻辑
```

**尾指针：**
```
维护tail指针
O(1)尾部插入
```

**内存池：**
```
预先分配节点
减少malloc调用
提高性能
```

### 7.3 异构链表

**通用链表：**
```
void*数据域
类型标记
灵活但类型不安全
```

**模板链表：**
```
编译时类型检查
类型安全
代码膨胀
```

## 八、链表的实现考虑

### 8.1 节点设计

**基本节点：**
```
struct Node {
    int data;
    Node* next;
};
```

**双向节点：**
```
struct Node {
    int data;
    Node* prev;
    Node* next;
};
```

### 8.2 边界处理

**空链表：**
```
head = NULL
所有操作需检查
```

**单节点链表：**
```
head = tail
特例处理
```

**头尾操作：**
```
更新head/tail指针
注意顺序
```

### 8.3 内存管理

**分配：**
```
动态分配每个节点
检查分配失败
```

**释放：**
```
遍历释放所有节点
避免内存泄漏
```

## 九、总结

**链表是通过指针连接的动态数据结构，以O(1)插入删除著称，是实现复杂数据结构的基础。**

**核心要点：**
1. 非连续内存，动态大小
2. 通过指针串联节点
3. 插入删除高效O(1)
4. 随机访问低效O(n)

**适用场景：**
- 频繁插入删除
- 数据量不确定
- 实现其他数据结构
- 不需要随机访问

**不适用场景：**
- 需要快速随机访问
- 重视缓存性能
- 内存极其紧张

**变体选择：**
- 单向遍历 → 单链表
- 双向遍历 → 双向链表
- 循环处理 → 循环链表
