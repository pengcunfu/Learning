# 队列（Queue）与双端队列（Deque）

队列（Queue）和双端队列（Deque）是常见的数据结构，主要用于顺序存储和操作数据。队列遵循“先进先出”（FIFO，First In First Out）的原则，而双端队列允许在队列的两端进行插入和删除操作。

在 C++ 中，队列和双端队列可以通过链表来实现。下面是基于链表的队列和双端队列的实现示例。

### 1. 队列（Queue）的实现

队列遵循先进先出的原则，常用的操作有：

- **入队（enqueue）**：将元素添加到队列的尾部。
- **出队（dequeue）**：移除队列的头部元素并返回它。
- **查看队头元素（peek）**：返回队头元素但不移除它。
- **检查队列是否为空（isEmpty）**：判断队列是否为空。
- **队列大小（size）**：返回队列中元素的个数。

#### 基于链表的队列实现：

```cpp
#include <iostream>
using namespace std;

// 队列的节点定义
struct Node {
    int data;
    Node* next;

    Node(int value) : data(value), next(nullptr) {}
};

// 队列类
class Queue {
private:
    Node* front;  // 队头指针
    Node* rear;   // 队尾指针
    int count;    // 队列大小

public:
    Queue() : front(nullptr), rear(nullptr), count(0) {}

    // 入队操作
    void enqueue(int value) {
        Node* newNode = new Node(value);
        if (rear) {
            rear->next = newNode;  // 如果队列不为空，将新节点加到队尾
        } else {
            front = newNode;  // 如果队列为空，头尾都指向新节点
        }
        rear = newNode;  // 更新队尾指针
        count++;  // 增加队列大小
    }

    // 出队操作
    int dequeue() {
        if (isEmpty()) {
            cout << "队列为空，无法出队！" << endl;
            return -1;  // 错误值，表示队列为空
        }
        Node* temp = front;  // 暂存队头节点
        int value = temp->data;  // 获取队头元素的值
        front = front->next;  // 将队头指针指向下一个节点
        if (!front) {
            rear = nullptr;  // 如果队列为空，队尾指针置空
        }
        delete temp;  // 释放队头节点的内存
        count--;  // 减少队列大小
        return value;  // 返回队头元素的值
    }

    // 查看队头元素
    int peek() {
        if (isEmpty()) {
            cout << "队列为空！" << endl;
            return -1;  // 错误值，表示队列为空
        }
        return front->data;  // 返回队头元素的值
    }

    // 检查队列是否为空
    bool isEmpty() {
        return front == nullptr;
    }

    // 获取队列的大小
    int size() {
        return count;
    }

    // 打印队列内容
    void print() {
        Node* temp = front;
        while (temp) {
            cout << temp->data << " ";
            temp = temp->next;
        }
        cout << endl;
    }

    // 析构函数，释放队列内存
    ~Queue() {
        while (!isEmpty()) {
            dequeue();  // 逐个出队直到队列为空
        }
    }
};

int main() {
    Queue q;

    // 入队操作
    q.enqueue(10);
    q.enqueue(20);
    q.enqueue(30);
    q.enqueue(40);

    // 打印队列内容
    cout << "队列的内容：";
    q.print();

    // 查看队头元素
    cout << "队头元素： " << q.peek() << endl;

    // 出队操作
    cout << "出队元素： " << q.dequeue() << endl;

    // 打印队列内容
    cout << "出队后的队列内容：";
    q.print();

    // 获取队列大小
    cout << "队列的大小： " << q.size() << endl;

    return 0;
}
```

### 代码说明

1. **节点定义（Node）**：
   - `Node` 结构体定义了队列的每个节点。每个节点包含一个 `data` 字段用于存储数据，还有一个指针 `next` 指向下一个节点。
2. **队列类（Queue）**：
   - `front`：队列的头部指针，指向队列的第一个元素。
   - `rear`：队列的尾部指针，指向队列的最后一个元素。
   - `count`：记录队列的元素个数。
   - `enqueue(int value)`：将一个新的节点添加到队列尾部。
   - `dequeue()`：从队列头部移除一个节点并返回其值。
   - `peek()`：返回队头元素的值但不移除它。
   - `isEmpty()`：检查队列是否为空。
   - `size()`：返回队列中元素的个数。
   - `print()`：打印队列中的所有元素。
   - 析构函数：释放队列中的节点内存，防止内存泄漏。

### 输出示例

```
队列的内容：10 20 30 40 
队头元素： 10
出队元素： 10
出队后的队列内容：20 30 40 
队列的大小： 3
```

### 2. 双端队列（Deque）的实现

双端队列（Deque，Double-Ended Queue）是一个可以从两端进行插入和删除操作的数据结构。它可以在队列的两端进行插入和删除操作，因此有时也被称为双向队列。

双端队列的常见操作：

- **从队头入队（push_front）**
- **从队尾入队（push_back）**
- **从队头出队（pop_front）**
- **从队尾出队（pop_back）**
- **查看队头元素（peek_front）**
- **查看队尾元素（peek_back）**
- **检查队列是否为空（isEmpty）**
- **队列大小（size）**

#### 基于链表的双端队列实现：

```cpp
#include <iostream>
using namespace std;

// 双端队列节点定义
struct Node {
    int data;
    Node* next;
    Node* prev;

    Node(int value) : data(value), next(nullptr), prev(nullptr) {}
};

// 双端队列类
class Deque {
private:
    Node* front;  // 队头指针
    Node* rear;   // 队尾指针
    int count;    // 队列大小

public:
    Deque() : front(nullptr), rear(nullptr), count(0) {}

    // 从队头插入元素
    void push_front(int value) {
        Node* newNode = new Node(value);
        if (front == nullptr) {
            front = rear = newNode;  // 如果队列为空，头尾指针都指向新节点
        } else {
            newNode->next = front;
            front->prev = newNode;
            front = newNode;  // 更新队头指针
        }
        count++;
    }

    // 从队尾插入元素
    void push_back(int value) {
        Node* newNode = new Node(value);
        if (rear == nullptr) {
            front = rear = newNode;  // 如果队列为空，头尾指针都指向新节点
        } else {
            newNode->prev = rear;
            rear->next = newNode;
            rear = newNode;  // 更新队尾指针
        }
        count++;
    }

    // 从队头删除元素
    int pop_front() {
        if (isEmpty()) {
            cout << "队列为空，无法从队头删除元素！" << endl;
            return -1;
        }
        Node* temp = front;
        int value = temp->data;
        front = front->next;
        if (front) front->prev = nullptr;  // 更新队头指针
        else rear = nullptr;  // 如果队列为空，队尾指针置空
        delete temp;
        count--;
        return value;
    }

    // 从队尾删除元素
    int pop_back() {
        if (isEmpty()) {
            cout << "队列为空，无法从队尾删除元素！" << endl;
            return -1;
        }
        Node* temp = rear;
        int value = temp->data;
        rear = rear->prev;
        if (rear) rear->next = nullptr;  // 更新队尾指针
        else front = nullptr;  // 如果队列为空，队头指针置空
        delete temp;
        count--;
        return value;
    }
    // 查看队头元素
    int peek_front() {
        if (isEmpty()) {
            cout << "队列为空！" << endl;
            return -1;
        }
        return front->data;
    }

    // 查看队尾元素
    int peek_back() {
        if (isEmpty()) {
            cout << "队列为空！" << endl;
            return -1;
        }
        return rear->data;
    }

    // 检查队列是否为空
    bool isEmpty() {
        return front == nullptr;
    }

    // 获取队列大小
    int size() {
        return count;
    }

    // 打印队列内容
    void print() {
        Node* temp = front;
        while (temp) {
            cout << temp->data << " ";
            temp = temp->next;
        }
        cout << endl;
    }

    // 析构函数，释放队列内存
    ~Deque() {
        while (!isEmpty()) {
            pop_front();
        }
    }
};

int main() { 
    Deque dq;

    // 从队尾插入元素
    dq.push_back(10);
    dq.push_back(20);
    dq.push_back(30);

    // 从队头插入元素
    dq.push_front(5);
    dq.push_front(1);

    // 打印队列内容
    cout << "双端队列的内容：";
    dq.print();

    // 查看队头和队尾元素
    cout << "队头元素： " << dq.peek_front() << endl;
    cout << "队尾元素： " << dq.peek_back() << endl;

    // 从队头删除元素
    cout << "从队头删除元素： " << dq.pop_front() << endl;

    // 从队尾删除元素
    cout << "从队尾删除元素： " << dq.pop_back() << endl;

    // 打印队列内容
    cout << "删除后的双端队列内容：";
    dq.print();

    return 0;
}

```
### 代码说明

1. **节点定义（Node）**：
   - `Node` 结构体定义了双端队列的每个节点。每个节点包含 `data` 存储数据，`next` 指向下一个节点，`prev` 指向前一个节点。

2. **双端队列类（Deque）**：
   - `front`：队列的头部指针。
   - `rear`：队列的尾部指针。
   - `count`：队列中的元素个数。
   - `push_front(int value)`：从队头插入元素。
   - `push_back(int value)`：从队尾插入元素。
   - `pop_front()`：从队头删除元素。
   - `pop_back()`：从队尾删除元素。
   - `peek_front()`：返回队头元素的值。
   - `peek_back()`：返回队尾元素的值。
   - `isEmpty()`：检查队列是否为空。
   - `size()`：返回队列中元素的个数。
   - `print()`：打印队列中的元素。
   - 析构函数：释放内存。

### 输出示例
```
双端队列的内容：1 5 10 20 30 
队头元素： 1 
队尾元素： 30 
从队头删除元素： 1 
从队尾删除元素： 30 
删除后的双端队列内容：5 10 20
```
这样，我们实现了一个基于链表的队列和双端队列，可以灵活地进行操作并避免静态数组大小限制。



## 队列

下面是队列的链表实现，需要维护 first 和 last 节点指针，分别指向队首和队尾。

这里需要考虑 first 和 last 指针哪个作为链表的开头。因为出队列操作需要让队首元素的下一个元素成为队首，所以需要容易获取下一个元素，而链表的头部节点的 next 指针指向下一个元素，因此可以让 first 指针链表的开头。

```java
public interface MyQueue<Item> extends Iterable<Item> {

    int size();

    boolean isEmpty();

    MyQueue<Item> add(Item item);

    Item remove() throws Exception;
}
```

```java
public class ListQueue<Item> implements MyQueue<Item> {

    private Node first;
    private Node last;
    int N = 0;


    private class Node {
        Item item;
        Node next;
    }


    @Override
    public boolean isEmpty() {
        return N == 0;
    }


    @Override
    public int size() {
        return N;
    }


    @Override
    public MyQueue<Item> add(Item item) {

        Node newNode = new Node();
        newNode.item = item;
        newNode.next = null;

        if (isEmpty()) {
            last = newNode;
            first = newNode;
        } else {
            last.next = newNode;
            last = newNode;
        }

        N++;
        return this;
    }


    @Override
    public Item remove() throws Exception {

        if (isEmpty()) {
            throw new Exception("queue is empty");
        }

        Node node = first;
        first = first.next;
        N--;

        if (isEmpty()) {
            last = null;
        }

        return node.item;
    }


    @Override
    public Iterator<Item> iterator() {

        return new Iterator<Item>() {

            Node cur = first;


            @Override
            public boolean hasNext() {
                return cur != null;
            }


            @Override
            public Item next() {
                Item item = cur.item;
                cur = cur.next;
                return item;
            }
        };
    }
}
```
