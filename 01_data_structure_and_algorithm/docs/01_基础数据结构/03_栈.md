# 数据解构和算法-栈

## 栈的定义

栈（Stack）是一种抽象数据类型，用于存储一系列元素，具有后进先出（LIFO，Last In First Out）的特性。也就是说，最后插入的元素最先删除。栈在计算机科学和编程中有广泛的应用。 



## 实现栈有哪些方式（栈的存储形式）

**基于数组的实现**

- 使用一个固定大小的数组来存储元素。
- 使用一个指针（或索引）来指示栈顶的位置。
- 优点：实现简单，操作速度快（O(1)时间复杂度）。
- 缺点：数组大小固定，栈的容量受限，需要预先定义。

**基于链表的实现**

- 使用链表来存储元素。
- 栈顶元素总是链表的头节点。
- 优点：不受固定大小的限制，可以动态调整栈的大小。
- 缺点：每次操作需要分配或释放内存，性能可能略低于基于数组的实现。



## 栈有哪些方法

**push(int element)**：将元素压入栈顶。

**pop()**：从栈顶弹出元素并返回其值。

**peek()**：获取栈顶元素但不删除它。

**isEmpty()**：检查栈是否为空。

**size()**：返回栈中的元素数量。

## 栈的应用场景

**函数调用的管理**

- 程序调用函数时会将当前的执行环境压入调用栈，函数返回时会弹出栈顶的执行环境。
- 用于递归函数的调用管理。

**表达式求值**

- 后缀表达式（逆波兰表达式）的求值。
- 中缀表达式转后缀表达式。

**括号匹配**

- 检查表达式中的括号是否成对匹配。

**深度优先搜索（DFS）**

- 在图的遍历和搜索中使用栈来实现递归算法。

**撤销操作**

- 应用程序中的撤销操作（如文本编辑器）使用栈来记录历史操作。



栈（Stack）是一种遵循“后进先出”（LIFO，Last In First Out）原则的数据结构。基于链表实现的栈可以通过链表的头节点来模拟栈的操作（压栈和弹栈）。下面是一个基于链表实现栈的示例：

### 栈的链表实现

#### 1. 栈的基本操作

- **压栈（Push）**：将一个元素添加到栈顶。
- **弹栈（Pop）**：移除栈顶元素并返回其值。
- **查看栈顶元素（Peek）**：返回栈顶元素的值，但不移除它。
- **检查栈是否为空（isEmpty）**：判断栈是否为空。
- **栈的大小（size）**：返回栈中元素的个数。

#### 2. 基于链表实现栈

```cpp
#include <iostream>
using namespace std;

// 栈的节点定义
struct Node {
    int data;
    Node* next;

    Node(int value) : data(value), next(nullptr) {}
};

// 栈的类
class Stack {
private:
    Node* top;  // 栈顶指针
    int count;  // 栈的元素个数

public:
    Stack() : top(nullptr), count(0) {}

    // 压栈操作
    void push(int value) {
        Node* newNode = new Node(value);  // 创建新节点
        newNode->next = top;  // 新节点指向当前栈顶
        top = newNode;  // 将新节点设置为栈顶
        count++;  // 增加栈的元素个数
    }

    // 弹栈操作
    int pop() {
        if (isEmpty()) {
            cout << "栈为空，无法弹栈！" << endl;
            return -1;  // 错误值，表示栈为空
        }
        Node* temp = top;  // 暂存栈顶节点
        int value = temp->data;  // 获取栈顶元素的值
        top = top->next;  // 将栈顶指针指向下一个节点
        delete temp;  // 释放栈顶节点的内存
        count--;  // 减少栈的元素个数
        return value;  // 返回栈顶元素的值
    }

    // 查看栈顶元素
    int peek() {
        if (isEmpty()) {
            cout << "栈为空！" << endl;
            return -1;  // 错误值，表示栈为空
        }
        return top->data;  // 返回栈顶元素的值
    }

    // 检查栈是否为空
    bool isEmpty() {
        return top == nullptr;
    }

    // 获取栈的大小
    int size() {
        return count;
    }

    // 打印栈的内容（从栈顶到栈底）
    void print() {
        Node* temp = top;
        while (temp) {
            cout << temp->data << " ";
            temp = temp->next;
        }
        cout << endl;
    }

    // 析构函数，释放栈的内存
    ~Stack() {
        while (!isEmpty()) {
            pop();  // 逐个弹出栈中的元素，直到栈为空
        }
    }
};

int main() {
    Stack stack;

    // 压栈操作
    stack.push(10);
    stack.push(20);
    stack.push(30);
    stack.push(40);

    // 打印栈的内容
    cout << "栈的内容：";
    stack.print();

    // 查看栈顶元素
    cout << "栈顶元素： " << stack.peek() << endl;

    // 弹栈操作
    cout << "弹出栈顶元素： " << stack.pop() << endl;

    // 打印栈的内容
    cout << "弹栈后的栈的内容：";
    stack.print();

    // 获取栈的大小
    cout << "栈的大小： " << stack.size() << endl;

    // 再次弹栈
    cout << "弹出栈顶元素： " << stack.pop() << endl;

    // 再次打印栈的内容
    cout << "弹栈后的栈的内容：";
    stack.print();

    return 0;
}
```

### 代码说明

1. **节点定义（Node）**：
   - `Node` 结构体定义了链表的每个节点。每个节点包含一个 `data` 字段用于存储数据，还有一个指针 `next` 指向下一个节点。
2. **栈类（Stack）**：
   - `top`：栈顶指针，指向栈的顶部元素。
   - `count`：记录栈中元素的个数。
   - `push(int value)`：将一个新的节点添加到栈顶。
   - `pop()`：弹出栈顶元素并返回其值，如果栈为空则返回错误值。
   - `peek()`：返回栈顶元素的值但不移除它，如果栈为空则返回错误值。
   - `isEmpty()`：检查栈是否为空。
   - `size()`：返回栈中元素的个数。
   - `print()`：从栈顶到栈底打印栈的所有元素。
   - 析构函数：释放栈中所有节点的内存，防止内存泄漏。
3. **示例输出**：

```
栈的内容：40 30 20 10 
栈顶元素： 40
弹出栈顶元素： 40
弹栈后的栈的内容：30 20 10 
栈的大小： 3
弹出栈顶元素： 30
弹栈后的栈的内容：20 10 
```

### 总结

- 使用链表实现栈的好处是可以动态扩展栈的大小，无需提前设定大小限制，且不会发生内存浪费。
- 每次 `push` 操作将新节点插入到链表头部，实现 O(1) 时间复杂度。
- 每次 `pop` 操作移除栈顶节点，也实现 O(1) 时间复杂度。

    MyStack<Item> push(Item item);

    Item pop() throws Exception;

    boolean isEmpty();

### 1. 数组实现

```java
public class ArrayStack<Item> implements MyStack<Item> {

    // 栈元素数组，只能通过转型来创建泛型数组
    private Item[] a = (Item[]) new Object[1];

    // 元素数量
    private int N = 0;


    @Override
    public MyStack<Item> push(Item item) {
        check();
        a[N++] = item;
        return this;
    }


    @Override
    public Item pop() throws Exception {

        if (isEmpty()) {
            throw new Exception("stack is empty");
        }

        Item item = a[--N];

        check();

        // 避免对象游离
        a[N] = null;

        return item;
    }


    private void check() {

        if (N >= a.length) {
            resize(2 * a.length);

        } else if (N > 0 && N <= a.length / 4) {
            resize(a.length / 2);
        }
    }


    /**
     * 调整数组大小，使得栈具有伸缩性
     */
    private void resize(int size) {

        Item[] tmp = (Item[]) new Object[size];

        for (int i = 0; i < N; i++) {
            tmp[i] = a[i];
        }

        a = tmp;
    }


    @Override
    public boolean isEmpty() {
        return N == 0;
    }


    @Override
    public int size() {
        return N;
    }


    @Override
    public Iterator<Item> iterator() {

        // 返回逆序遍历的迭代器
        return new Iterator<Item>() {

            private int i = N;

            @Override
            public boolean hasNext() {
                return i > 0;
            }

            @Override
            public Item next() {
                return a[--i];
            }
        };

    }
}
```

### 2. 链表实现

需要使用链表的头插法来实现，因为头插法中最后压入栈的元素在链表的开头，它的 next 指针指向前一个压入栈的元素，在弹出元素时就可以通过 next 指针遍历到前一个压入栈的元素从而让这个元素成为新的栈顶元素。

```java
public class ListStack<Item> implements MyStack<Item> {

    private Node top = null;
    private int N = 0;


    private class Node {
        Item item;
        Node next;
    }


    @Override
    public MyStack<Item> push(Item item) {

        Node newTop = new Node();

        newTop.item = item;
        newTop.next = top;

        top = newTop;

        N++;

        return this;
    }


    @Override
    public Item pop() throws Exception {

        if (isEmpty()) {
            throw new Exception("stack is empty");
        }

        Item item = top.item;

        top = top.next;
        N--;

        return item;
    }


    @Override
    public boolean isEmpty() {
        return N == 0;
    }


    @Override
    public int size() {
        return N;
    }


    @Override
    public Iterator<Item> iterator() {

        return new Iterator<Item>() {

            private Node cur = top;


            @Override
            public boolean hasNext() {
                return cur != null;
            }


            @Override
            public Item next() {
                Item item = cur.item;
                cur = cur.next;
                return item;
            }
        };

    }
}
```
