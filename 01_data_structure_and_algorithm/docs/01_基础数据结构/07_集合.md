# 集合（Set）

## 一、集合概述

### 1.1 什么是集合？

**集合：**
> 不同元素的汇集，不允许重复元素，提供高效的成员检测

**数学定义：**
```
集合是不同对象的汇集
关键特性：
- 确定性：元素明确
- 互异性：元素不重复
- 无序性：元素无顺序
```

### 1.2 数据结构中的集合

**核心操作：**
```
1. 插入：添加元素
2. 删除：移除元素
3. 查找：判断元素是否存在
4. 并集：两个集合合并
5. 交集：共同元素
6. 差集：在一个不在另一个
```

## 二、集合的实现

### 2.1 基于数组的集合

**实现方式：**
```
使用数组存储元素
插入时检查重复

优点：
- 简单直观
- 缓存友好

缺点：
- 插入删除O(n)
- 大小固定
```

**查找优化：**
```
保持数组有序
二分查找：O(log n)
```

### 2.2 基于链表的集合

**实现方式：**
```
使用链表存储元素
插入时遍历检查重复

优点：
- 动态大小
- 插入删除O(1)已知位置

缺点：
- 查找O(n)
- 缓存不友好
```

### 2.3 基于哈希表的集合

**实现方式：**
```
使用哈希表存储
只存储键，不存储值

优点：
- 查找O(1)平均
- 插入删除O(1)平均

缺点：
- 无序
- 最坏O(n)
```

**最常用实现：**
```
HashSet：基于哈希表
```

### 2.4 基于树的集合

**实现方式：**
```
使用平衡搜索树
如红黑树、AVL树

优点：
- 有序
- O(log n)保证

缺点：
- 实现复杂
- 常数较大
```

**TreeSet：**
```
基于红黑树
保持有序
```

## 三、集合的基本操作

### 3.1 核心操作

**添加元素：**
```
add(element):
- 检查是否已存在
- 不存在则添加

时间：取决于实现
```

**删除元素：**
```
remove(element):
- 查找元素
- 删除元素

时间：取决于实现
```

**包含判断：**
```
contains(element):
- 查找元素
- 返回true/false

时间：取决于实现
```

### 3.2 集合运算

**并集（Union）：**
```
A ∪ B = {x | x∈A 或 x∈B}

实现：
遍历一个集合
添加到另一个集合

时间：O(n+m)
```

**交集（Intersection）：**
```
A ∩ B = {x | x∈A 且 x∈B}

实现：
遍历较小集合
检查是否在另一个集合

时间：O(n×m)或O(min(n,m))
```

**差集（Difference）：**
```
A - B = {x | x∈A 且 x∉B}

实现：
遍历A
删除在B中的元素

时间：O(n×m)或O(n)
```

## 四、集合的变体

### 4.1 有序集合

**特点：**
```
元素保持有序
支持范围查询
```

**实现：**
```
TreeSet：基于平衡树
SkipList：跳表
```

**操作：**
```
- 范围查询
- 找前驱后继
- 有序遍历
```

### 4.2 多重集合

**定义：**
```
允许重复元素的集合
也称为包（Bag）
```

**应用：**
```
- 统计词频
- 计数问题
```

### 4.3 不可变集合

**特点：**
```
创建后不能修改
线程安全
可以共享
```

**优势：**
```
- 不变性保证
- 简化并发
- 便于缓存
```

## 五、集合的应用

### 5.1 去重

**数组去重：**
```
问题：移除重复元素

算法：
1. 创建空集合
2. 遍历数组
3. 添加到集合（自动去重）
4. 转回数组

时间：O(n)
```

### 5.2 成员检测

**快速查找：**
```
问题：判断元素是否存在

使用哈希集合：
O(1)平均查找时间

应用：
- 黑名单检查
- 权限验证
```

### 5.3 集合运算

**标签系统：**
```
问题：找具有某些标签的用户

解决：
- 每个标签一个集合
- 交集：同时具有
- 并集：至少一个
```

**权限管理：**
```
问题：用户具有的权限

解决：
- 角色权限集合
- 用户权限 = 角色权限并集
```

## 六、集合vs其他结构

### 6.1 vs 列表

| 特性 | 集合 | 列表 |
|------|------|------|
| **重复** | 不允许 | 允许 |
| **查找** | O(1) | O(n) |
| **顺序** | 无序 | 有序 |
| **索引** | 不支持 | 支持 |

### 6.2 vs 映射

| 特性 | 集合 | 映射 |
|------|------|------|
| **元素** | 单值 | 键值对 |
| **目的** | 去重 | 关联 |
| **操作** | 成员检测 | 键值查找 |

**关系：**
```
集合可以用只有键的映射实现
```

## 七、集合的选择

### 7.1 HashSet

**使用场景：**
```
需要快速查找
不关心顺序
允许哈希冲突
```

**特点：**
```
最快平均性能
无序
不保证顺序
```

### 7.2 TreeSet

**使用场景：**
```
需要有序
需要范围查询
需要最值
```

**特点：**
```
保证O(log n)
有序
功能丰富
```

### 7.3 LinkedHashSet

**使用场景：**
```
需要保持插入顺序
需要快速查找
```

**特点：**
```
哈希表 + 链表
保持插入顺序
```

## 八、集合的性能

### 8.1 时间复杂度

**基于哈希表：**
```
插入：O(1)平均
删除：O(1)平均
查找：O(1)平均

最坏：O(n)
```

**基于平衡树：**
```
插入：O(log n)
删除：O(log n)
查找：O(log n)

保证：最坏也是O(log n)
```

### 8.2 空间复杂度

```
O(n)

哈希表：
- 数组：O(m)
- 链表：O(n)

平衡树：
- 节点：O(n)
- 指针：O(2n)或O(3n)
```

## 九、集合的高级话题

### 9.1 并发集合

**问题：**
```
多线程访问
需要同步
```

**解决：**
```
ConcurrentHashMap
CopyOnWriteArraySet
```

### 9.2 持久化集合

**定义：**
```
修改后保持旧版本
函数式编程常用
```

**实现：**
```
路径复制
结构共享
```

### 9.3 概率数据结构

**布隆过滤器：**
```
空间高效的概率集合
支持插入和查询
可能有假阳性

应用：
- 缓存系统
- 数据库
- 网络爬虫
```

**HyperLogLog：**
```
基数估计
极小空间
概率准确

应用：
- 统计UV
- 大数据去重
```

## 十、总结

**集合是不重复元素的汇集，通过不同的数据结构实现，提供了高效的成员检测和集合运算。**

**核心要点：**
1. 元素唯一性
2. 高效成员检测
3. 丰富集合运算
4. 多种实现选择

**实现选择：**
- 快速查找 → HashSet
- 需要有序 → TreeSet
- 保持顺序 → LinkedHashSet

**典型应用：**
- 去重
- 成员检测
- 集合运算
- 标签系统

**注意事项：**
- 元素需要正确实现equals和hashCode（哈希集合）
- 元素需要可比较（树集合）
- 选择合适的数据结构
