### 简述 Bloom Filter，及它的使用场景是什么

#### 什么是 Bloom Filter

Bloom Filter（布隆过滤器）是一种空间效率非常高的概率型数据结构，它可以判断一个元素是否在一个集合中。其特点是：

1. **快速判断**：可以以常数时间复杂度O(k)判断一个元素是否在集合中，其中k是哈希函数的数量。
2. **可能会误判**：对于一个不在集合中的元素，Bloom Filter 可能误判它在集合中（即产生“假阳性”），但绝不会产生“假阴性”。
3. **不支持删除**：标准的 Bloom Filter 只能添加元素，不能删除元素，但有一些扩展可以支持删除。

#### 工作原理

Bloom Filter 使用一个位数组和多个不同的哈希函数来判断一个元素是否存在。元素通过多个哈希函数映射到位数组的不同位置，将这些位置的位设置为1。判断一个元素是否存在时，检查该元素通过所有哈希函数映射到的位是否都为1，如果是，则认为该元素可能存在；如果有任意一个为0，则该元素一定不存在。

#### 使用场景

1. **Web缓存**：如 Google 的 Bigtable 等分布式系统用 Bloom Filter 判断某个元素是否在缓存中。
2. **数据库查询优化**：用于判断某个数据是否已经在数据库中，减少无意义的查询。
3. **垃圾邮件过滤**：可以用于判断邮件是否属于已知的垃圾邮件。

#### C++ 实现

```cpp
#include <iostream>
#include <vector>
#include <functional>

class BloomFilter {
private:
    std::vector<bool> bitArray;
    std::vector<std::hash<std::string>> hashFunctions;
    int size;

public:
    BloomFilter(int size, int hashCount) : size(size) {
        bitArray.resize(size, false);
        for (int i = 0; i < hashCount; ++i) {
            hashFunctions.push_back(std::hash<std::string>());
        }
    }

    void add(const std::string& value) {
        for (auto& hashFunc : hashFunctions) {
            int index = hashFunc(value) % size;
            bitArray[index] = true;
        }
    }

    bool contains(const std::string& value) {
        for (auto& hashFunc : hashFunctions) {
            int index = hashFunc(value) % size;
            if (!bitArray[index]) {
                return false;
            }
        }
        return true;
    }
};

int main() {
    BloomFilter bloom(1000, 3);  // 位数组大小1000，哈希函数个数3
    bloom.add("apple");
    bloom.add("banana");

    std::cout << "Contains apple: " << bloom.contains("apple") << std::endl;
    std::cout << "Contains banana: " << bloom.contains("banana") << std::endl;
    std::cout << "Contains cherry: " << bloom.contains("cherry") << std::endl;

    return 0;
}
```

### 什么是一致性哈希，可以解决什么问题

#### 一致性哈希

一致性哈希（Consistent Hashing）是一种特殊的哈希算法，用于解决分布式系统中的负载均衡问题。它主要解决在节点动态增减时，如何尽可能地减少数据的迁移和重分布。传统的哈希算法在增加或删除节点时，可能会导致大量的数据迁移，而一致性哈希则通过环形的方式组织节点，避免了这个问题。

#### 工作原理

1. **哈希环**：一致性哈希将所有的节点和数据映射到一个哈希环上。每个节点在哈希环上都有一个位置，数据根据哈希值找到一个位置，并顺时针查找最近的节点来存储数据。
2. **虚拟节点**：为了避免某些节点负载过重，可以使用虚拟节点来提高负载均衡的效果。

#### 使用场景

1. **分布式缓存**：如 Memcached、Redis等系统使用一致性哈希来分布数据。
2. **负载均衡**：在分布式服务器中，可以使用一致性哈希来决定请求发送到哪个服务器。

#### C++ 实现（简化版）

```cpp
#include <iostream>
#include <vector>
#include <map>
#include <string>
#include <functional>

class ConsistentHashing {
private:
    std::map<int, std::string> ring;  // 哈希环，key是哈希值，value是节点名
    int virtualNodes;  // 每个物理节点的虚拟节点数

public:
    ConsistentHashing(int virtualNodes) : virtualNodes(virtualNodes) {}

    // 将节点加入哈希环
    void addNode(const std::string& node) {
        for (int i = 0; i < virtualNodes; ++i) {
            int hashValue = std::hash<std::string>{}(node + std::to_string(i));
            ring[hashValue] = node;
        }
    }

    // 查找存储数据的节点
    std::string getNode(const std::string& data) {
        int hashValue = std::hash<std::string>{}(data);
        auto it = ring.lower_bound(hashValue);
        if (it == ring.end()) {
            return ring.begin()->second;
        }
        return it->second;
    }
};

int main() {
    ConsistentHashing ch(3);  // 每个节点有3个虚拟节点
    ch.addNode("Node1");
    ch.addNode("Node2");
    ch.addNode("Node3");

    std::cout << "Data 'test' is stored at: " << ch.getNode("test") << std::endl;
    std::cout << "Data 'apple' is stored at: " << ch.getNode("apple") << std::endl;

    return 0;
}
```

### 如何查找地图中某个点两公里内的餐厅

#### 问题背景

给定一个地图，其中有多个餐厅，每个餐厅有其经纬度。如何查找某个点（例如用户当前位置）两公里内的餐厅？

#### 解决方案

这个问题可以通过计算两点之间的地理距离来解决。常用的计算地理距离的方法是**哈弗辛公式**（Haversine formula）。哈弗辛公式用于计算地球表面两点之间的最短距离，考虑了地球的曲率。

#### 哈弗辛公式

- RR 是地球的半径，约为 6371 公里。

#### C++ 实现

```cpp
#include <iostream>
#include <vector>
#include <cmath>

const double EARTH_RADIUS = 6371.0;  // 地球半径（单位：公里）

// 计算两点之间的距离，单位为公里
double haversine(double lat1, double lon1, double lat2, double lon2) {
    double lat1Rad = lat1 * M_PI / 180.0;
    double lon1Rad = lon1 * M_PI / 180.0;
    double lat2Rad = lat2 * M_PI / 180.0;
    double lon2Rad = lon2 * M_PI / 180.0;

    double dlat = lat2Rad - lat1Rad;
    double dlon = lon2Rad - lon1Rad;

    double a = std::sin(dlat / 2) * std::sin(dlat / 2) +
               std::cos(lat1Rad) * std::cos(lat2Rad) *
               std::sin(dlon / 2) * std::sin(dlon / 2);

    double c = 2 * std::atan2(std::sqrt(a), std::sqrt(1 - a));

    return EARTH_RADIUS * c;  // 返回公里数
}

struct Restaurant {
    double lat, lon;
    std::string name;
};

std::vector<Restaurant> findNearbyRestaurants(const std::vector<Restaurant>& restaurants, double userLat, double userLon, double radius) {
    std::vector<Restaurant> nearby;
    for (const auto& restaurant : restaurants) {
        double distance = haversine(userLat, userLon, restaurant.lat, restaurant.lon);
        if (distance <= radius) {
            nearby.push_back

(restaurant); } } return nearby; }

int main() { 
    std::vector restaurants = { 
        {40.7128, -74.0060, "Restaurant A"},  // New York City 
        {40.730610, -73.935242, "Restaurant B"},  // Nearby in NYC 
        {34.0522, -118.2437, "Restaurant C"}  // Los Angeles 
    };

    double userLat = 40.730610;
    double userLon = -73.935242;
	double radius = 2.0;  // 2 kilometers

	std::vector<Restaurant> nearby = findNearbyRestaurants(restaurants, userLat, userLon, radius);

	std::cout << "Nearby restaurants within " << radius << " km:" << std::endl;
    for (const auto& r : nearby) {
        std::cout << r.name << std::endl;
    }
    return 0;
}
```
