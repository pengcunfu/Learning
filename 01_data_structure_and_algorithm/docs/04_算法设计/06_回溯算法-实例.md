# 回溯算法实例（Backtracking Examples）

## 一、回溯算法思想回顾

### 1.1 回溯的核心思想

**回溯 = 深度优先搜索 + 状态恢复**

**基本思路：**
```
1. 向深处探索，尝试所有可能的解
2. 当发现当前路径不可行时，回退到上一步
3. 尝试其他可能性
4. 直到找到解或探索完所有可能性
```

**类比：**
```
走迷宫：
- 向前走，记录路径
- 遇到死路，原路返回
- 尝试其他路径
```

### 1.2 回溯的适用问题

**典型特征：**
1. 需要找出**所有解**或**任一解**
2. 问题可以表示为**状态空间树**
3. 需要**试错**和**回退**

## 二、经典回溯问题

### 2.1 N皇后问题

**问题描述：**
> 在N×N的棋盘上放置N个皇后，使得它们互不攻击（同一行、同一列、同一斜线不能有两个皇后）

**思路分析：**
```
状态空间：
- 每一行放置一个皇后
- 第i行的皇后有N种可能位置
- 需要满足约束条件

约束条件：
1. 每列只能有一个皇后
2. 每条主对角线只能有一个皇后
3. 每条副对角线只能有一个皇后
```

**算法步骤：**
```
solve(row):
    if row == N:
        找到一个解，记录
        return

    for col in 1..N:
        if isSafe(row, col):
            放置皇后
            solve(row + 1)
            回溯（移除皇后）
```

**优化技巧：**
- 使用位运算加速判断
- 对称性剪枝
- 预处理对角线信息

### 2.2 全排列问题

**问题描述：**
> 生成1..n的所有排列

**思路分析：**
```
状态空间：
- 位置1可以放n个数
- 位置2可以放n-1个数
- ...
- 位置n只能放1个数

过程：
[ ] → [1] → [1,2] → [1,2,3]
     ↘ [2]    ↘ [1,3,2]
```

**算法步骤：**
```
permute(index):
    if index == n:
        输出当前排列
        return

    for i in index..n:
        if i未使用:
            标记i为已使用
            nums[index] = i
            permute(index + 1)
            标记i为未使用（回溯）
```

**应用：**
- 字典序全排列
- 字符串全排列
- 组合数学

### 2.3 组合问题

**问题描述：**
> 从1..n中选出k个数的所有组合

**思路分析：**
```
组合C(n,k)的特点：
- 不考虑顺序
- 每个元素只能选一次

剪枝条件：
- 已选k个数，停止
- 剩余不足k-n+1个，剪枝
```

**算法步骤：**
```
combine(start, k):
    if k == 0:
        输出当前组合
        return

    for i in start..n:
        选择i
        combine(i + 1, k - 1)
```

**变体问题：**
- 子集（所有大小的组合）
- 组合总和（目标和为target）
- 字母组合（电话号码）

### 2.4 数独问题

**问题描述：**
> 填充9×9的数独，使得每行、每列、每个3×3宫格包含1-9的所有数字

**约束条件：**
- 每行包含1-9且不重复
- 每列包含1-9且不重复
- 每个3×3宫格包含1-9且不重复

**算法思路：**
```
solve(pos):
    找到下一个空格
    for num in 1..9:
        if isValid(pos, num):
            填入num
            solve(next_pos)
            清空num（回溯）
```

## 三、回溯算法的优化技巧

### 3.1 剪枝（Pruning）

**目的：**
> 提前发现不可行的路径，避免无谓的搜索

**常见剪枝策略：**

**1. 约束剪枝**
```
违反问题约束的直接剪掉
```

**2. 界限剪枝**
```
if (剩余元素 < 需要的数量)
    return; // 无法满足要求
```

**3. 最优性剪枝**
```
if (当前解 >= 已知最优解)
    return; // 不可能更优
```

**4. 对称性剪枝**
```
利用问题的对称性减少搜索空间
```

### 3.2 启发式搜索

**思想：**
> 利用问题的特定性质，优先搜索更有希望的分支

**示例：**
```
N皇后问题：
- 优先搜索中间位置
- 更容易找到有效解
```

### 3.3 迭代加深

**思想：**
> 逐步增加搜索深度限制

**应用：**
- 博弈树搜索
- 不确定深度的搜索

## 四、回溯算法的框架

### 4.1 通用模板

```python
def backtrack(path, choices):
    # 终止条件
    if is_complete(path):
        record_solution(path)
        return

    # 选择和约束
    for choice in choices:
        if is_valid(choice):
            # 做选择
            make_choice(choice)
            path.append(choice)

            # 递归
            backtrack(path, remaining_choices)

            # 撤销选择（回溯）
            path.pop()
            undo_choice(choice)
```

### 4.2 参数传递

**常见方式：**
- **start index**：避免重复，记录当前位置
- **path/result**：记录当前路径/解
- **used数组**：记录已使用的元素

## 五、回溯算法的复杂度分析

### 5.1 时间复杂度

**分析方法：**
```
时间复杂度 = 解的个数 × 每个解的平均时间

N皇后：O(N!)
全排列：O(N!)
组合：O(C(N,K))
```

**优化效果：**
- 剪枝可以大幅减少实际搜索空间
- 但最坏情况不变

### 5.2 空间复杂度

**空间来源：**
```
递归栈深度：O(N)
存储解的空间：O(S×L)，S为解的数量，L为解的长度
```

## 六、回溯算法的优化实例

### 6.1 N皇后优化

**优化1：对称性**
```
只需要搜索前半列的位置
其他情况通过对称得到
```

**优化2：位运算**
```
使用整数位记录列和对角线占用
快速判断冲突
```

**优化3：预计算**
```
预处理对角线信息
避免重复计算
```

### 6.2 组合优化

**剪枝优化：**
```
按字典序生成组合
避免重复和遗漏
```

**K层嵌套循环：**
```
某些情况下可以用k层循环代替回溯
```
