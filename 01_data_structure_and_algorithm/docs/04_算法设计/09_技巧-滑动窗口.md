# 滑动窗口技巧（Sliding Window）

## 一、滑动窗口概述

### 1.1 什么是滑动窗口？

**滑动窗口：**
> 在数组/字符串上维护一个可变大小的窗口，通过滑动窗口来高效处理子数组/子串问题

**核心思想：**
```
用两个指针（left和right）定义窗口
通过移动指针调整窗口大小
在窗口移动过程中维护所需信息
```

**窗口类型：**
1. **固定大小窗口**：窗口大小固定k
2. **可变大小窗口**：窗口大小动态调整
   - 最大窗口：尽可能大
   - 最小窗口：尽可能小

### 1.2 为什么使用滑动窗口？

**优势：**
```
1. 时间效率：O(n)单次遍历
2. 空间效率：O(1)或O(k)存储窗口
3. 优雅简洁：避免重复计算
```

**适用场景：**
- 寻找满足条件的子数组/子串
- 求最值（最长、最短、最大、最小）
- 统计满足条件的元素个数

**vs 暴力解法：**
```
暴力：O(n²)或O(n³)
滑动窗口：O(n)
避免重复扫描
```

## 二、固定大小窗口

### 2.1 基本模式

**模板：**
```
窗口大小固定为k
left = 0
for right in 0..n-1:
    将arr[right]加入窗口

    if (right - left + 1 > k):
        移除arr[left]
        left++

    if (right - left + 1 == k):
        处理窗口内容
```

**关键点：**
- 先扩展窗口到大小k
- 维持窗口大小为k
- 每次移动一步

### 2.2 经典示例

**示例1：固定窗口最大值**
```
问题：大小为k的滑动窗口最大值

思路：
1. 维护一个大小为k的窗口
2. 使用双端队列存储窗口内最大值的候选
3. 队首始终是当前窗口最大值

算法：
for right in 0..n-1:
    while队列不为空且arr[队尾] <= arr[right]:
        队尾出队
    right入队

    if 队首索引 < right - k + 1:
        队首出队（超出窗口）

    if right >= k - 1:
        记录队首元素
```

**示例2：固定窗口平均值**
```
问题：大小为k的滑动窗口平均值

思路：
维护窗口内元素和
每次滑动更新和

算法：
sum = 0
for right in 0..n-1:
    sum += arr[right]

    if right >= k - 1:
        记录平均值sum/k
        sum -= arr[right - k + 1]
```

**示例3：固定窗口内元素个数**
```
问题：窗口内有多少个特定元素

思路：
统计窗口内目标元素出现次数

算法：
count = 0
for right in 0..n-1:
    if arr[right] == target:
        count++

    if right >= k:
        if arr[right - k] == target:
            count--

    if right >= k - 1:
        记录count
```

## 三、可变大小窗口

### 3.1 最大窗口

**模式：**
```
寻找满足条件的最长子数组/子串

left = 0
for right in 0..n-1:
    扩展窗口：将arr[right]加入

    while 窗口不满足条件:
        收缩窗口：移除arr[left]
        left++

    # 此时窗口满足条件
    更新最大窗口大小
```

**示例：最长无重复字符子串**
```
问题：最长不含重复字符的子串

思路：
用哈希集合记录窗口内字符
遇到重复字符就收缩窗口

算法：
left = 0, char_set = {}
for right in 0..n-1:
    while s[right] in char_set:
        char_set.remove(s[left])
        left++

    char_set.add(s[right])
    max_len = max(max_len, right - left + 1)
```

**示例：最多K个不同字符**
```
问题：最多包含K个不同字符的最长子串

思路：
用哈希表记录字符出现次数
不同字符数超过K时收缩

算法：
left = 0, char_count = {}
for right in 0..n-1:
    char_count[s[right]]++

    while len(char_count) > K:
        char_count[s[left]]--
        if char_count[s[left]] == 0:
            del char_count[s[left]]
        left++

    max_len = max(max_len, right - left + 1)
```

### 3.2 最小窗口

**模式：**
```
寻找满足条件的最短子数组/子串

left = 0
for right in 0..n-1:
    扩展窗口：将arr[right]加入

    while 窗口满足条件:
        更新最小窗口大小
        收缩窗口：移除arr[left]
        left++
```

**示例：最小覆盖子串**
```
问题：包含T所有字符的最短子串

思路：
用哈希表记录需要的字符
统计窗口内满足条件的字符数

算法：
need = 统计T中各字符需求
window = 记录窗口内字符数量
left = 0, valid = 0

for right in 0..n-1:
    char = S[right]
    if char in need:
        window[char]++
        if window[char] == need[char]:
            valid++

    while valid == len(need):
        # 更新最小窗口
        if right - left + 1 < min_len:
            记录窗口

        # 收缩
        left_char = S[left]
        if left_char in need:
            if window[left_char] == need[left_char]:
                valid--
            window[left_char]--
        left++
```

**示例：和至少为S的最短子数组**
```
问题：和≥S的最短连续子数组

思路：
维护窗口和
和≥S时尝试收缩

算法：
left = 0, sum = 0
for right in 0..n-1:
    sum += arr[right]

    while sum >= S:
        min_len = min(min_len, right - left + 1)
        sum -= arr[left]
        left++
```

## 四、滑动窗口的关键技巧

### 4.1 窗口扩展和收缩

**扩展：**
```
right指针向右移动
将新元素加入窗口
更新窗口统计信息
```

**收缩：**
```
left指针向右移动
移除左侧元素
更新窗口统计信息
```

**平衡：**
```
何时扩展：
- right每次循环都扩展
- 寻找更大的满足条件的窗口

何时收缩：
- 窗口不满足条件（最大窗口问题）
- 窗口满足条件（最小窗口问题）
- 窗口超过固定大小
```

### 4.2 窗口状态维护

**常见维护信息：**
```
1. 窗口和/积
2. 元素计数（哈希表）
3. 特定条件标记
4. 最大值/最小值
```

**高效维护技巧：**
```
增量更新：
- 添加元素时更新
- 移除元素时撤销更新

避免重复计算：
- 不每次重新计算窗口内容
- 只计算变化部分
```

### 4.3 边界处理

**关键边界：**
```
1. right到达数组末尾
2. left超过right
3. 窗口为空
4. 特殊长度（k=0, k=1, k=n）
```

## 六、滑动窗口vs双指针

### 6.1 相似之处

```
都是用两个指针
都是O(n)时间复杂度
都是逐步处理
```

### 6.2 本质区别

**双指针：**
```
两端向中间（对撞指针）
一快一慢（快慢指针）
通常处理有序数组
关注两个元素的关系
```

**滑动窗口：**
```
单向移动（left和right都向右）
窗口大小可变
处理连续子数组/子串
关注整体窗口的状态
```

**选择标准：**
```
需要连续子数组/子串 → 滑动窗口
需要考虑两个元素关系 → 双指针
```

## 八、解题技巧总结

### 8.1 识别滑动窗口问题

**关键词：**
```
连续、子数组、子串
最长、最短
最多、至少
满足条件
```

**特征：**
```
需要在连续元素上操作
需要统计窗口状态
可以通过收缩/扩展优化
```

### 8.2 通用解题步骤

```
1. 确定窗口类型（固定/可变）
2. 初始化left、right指针
3. 确定窗口扩展条件
4. 确定窗口收缩条件
5. 维护窗口状态
6. 更新答案
7. 返回结果
```

### 8.3 常见陷阱

**边界处理：**
```
窗口为空
left超过right
数组长度不足
```

**状态维护：**
```
忘记更新统计信息
收缩时撤销更新不完整
```

**循环终止：**
```
死循环
提前终止
