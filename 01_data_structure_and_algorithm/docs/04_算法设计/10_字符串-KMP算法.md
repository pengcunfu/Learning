# KMP算法（Knuth-Morris-Pratt）

## 一、算法概述

### 1.1 KMP算法简介

**KMP算法**是一种高效的字符串匹配算法，由Donald Knuth、Vaughan Pratt和James Morris三人于1977年共同提出。

**核心思想：**
> 利用已匹配的部分信息，避免从头开始匹配，跳过不可能匹配的位置

**解决的问题：**
```
在文本串T中查找模式串P的出现位置
```

### 1.2 为什么需要KMP？

**暴力匹配的问题：**
```
T = "AAAAABABCD"
P = "ABCD"

暴力过程：
位置0: AAAA vs ABCD → 匹配到第4个字符失败，回退到位置1
位置1: AAAA vs ABCD → 匹配到第4个字符失败，回退到位置2
...

问题：每次失败后，模式串只移动1位
      重复比较已经知道相同的字符
```

**KMP的改进：**
```
利用已匹配信息：
- 知道模式串内部的结构
- 跳过不可能匹配的位置
- 模式串向右滑动尽可能远

时间复杂度：O(m+n)，m为文本长度，n为模式长度
```

## 二、算法核心原理

### 2.1 前缀函数（Next数组）

**前缀函数的定义：**
```
next[i] = P[0...i]的最长相同真前缀和真后缀的长度

真前缀：不包含整个串的前缀
真后缀：不包含整个串的后缀
```

**示例：**
```
P = "ABABC"

计算next数组：
i=0, P[0]="A"
   前缀：{}，后缀：{}
   next[0] = 0

i=1, P[0..1]="AB"
   前缀：{"A"}，后缀：{"B"}
   无相同，next[1] = 0

i=2, P[0..2]="ABA"
   前缀：{"A","AB"}，后缀：{"A","BA"}
   "A"相同，next[2] = 1

i=3, P[0..3]="ABAB"
   前缀：{"A","AB","ABA"}，后缀：{"B","AB","BAB"}
   "AB"相同，next[3] = 2

i=4, P[0..4]="ABABC"
   前缀：{"A","AB","ABA","ABAB"}，后缀：{"C","BC","ABC","BABC"}
   无相同，next[4] = 0

next = [0, 0, 1, 2, 0]
```

### 2.2 Next数组的作用

**匹配失败时的决策：**
```
当P[j]与T[i]匹配失败时：
不需要从P[0]重新开始
根据next[j-1]决定新的j位置

原因：
P[0...j-1]已与T[i-j...i-1]匹配
如果P[0...next[j-1]-1] = P[j-next[j-1]...j-1]
则这部分也不需要重新匹配
```

**直观理解：**
```
T: ...ABABX...
P:    ABABC
        ↑失败

已知："ABAB"已匹配
观察：P中"ABAB"有前缀"AB"=后缀"AB"
结论：P的"AB"肯定匹配T的"AB"
跳过：直接从P的"C"继续匹配
```

## 三、Next数组的构建

### 3.1 构建算法

**递推思路：**
```
已知next[0...i-1]，求next[i]

设j = next[i-1]
表示P[0...j-1] = P[i-j...i-1]

比较P[j]和P[i]：
- 如果P[j] == P[i]：
  next[i] = j + 1

- 如果P[j] != P[i]：
  递归：j = next[j-1]
  继续比较P[j]和P[i]

- 如果j == 0：
  next[i] = 0
```

**构建过程示例：**
```
P = "ABABC"

初始化：next[0] = 0

i=1, j=0:
  P[1]="B" != P[0]="A"
  j=0, next[1] = 0

i=2, j=0:
  P[2]="A" == P[0]="A"
  next[2] = 1, j=1

i=3, j=1:
  P[3]="B" == P[1]="B"
  next[3] = 2, j=2

i=4, j=2:
  P[4]="C" != P[2]="A"
  j = next[1] = 0
  P[4]="C" != P[0]="A"
  next[4] = 0

next = [0, 0, 1, 2, 0]
```

### 3.2 优化Next数组

**问题：**
```
P = "AAAAB"
next = [0, 1, 2, 3, 0]

当i=3, j=3匹配失败时：
j = next[2] = 2
P[2]="A" = P[3]="A"，还是失败
再j = next[1] = 1
P[1]="A" = P[3]="A"，还是失败
再j = next[0] = 0
```

**优化：**
```
如果P[j] == P[i]：
必然失败，直接跳过
next[i] = next[j-1]
```

**优化后：**
```
next = [0, 0, 0, 0, 0]

一次跳到正确的位置
```

## 四、KMP匹配过程

### 4.1 匹配算法

**算法步骤：**
```
i = 0 (文本指针)
j = 0 (模式指针)

while i < m and j < n:
    if j == -1 or T[i] == P[j]:
        i++, j++
    else:
        j = next[j]  // 关键：跳过不可能匹配的位置

if j == n:
    找到匹配，起始位置为i-n
else:
    未找到
```

### 4.2 匹配过程示例

```
T = "ABABAABABCAB"
P = "ABABC"
next = [0, 0, 1, 2, 0]

过程：
i=0, j=0: T[0]="A" = P[0]="A" ✓
i=1, j=1: T[1]="B" = P[1]="B" ✓
i=2, j=2: T[2]="A" = P[2]="A" ✓
i=3, j=3: T[3]="B" = P[3]="B" ✓
i=4, j=4: T[4]="A" ≠ P[4]="C" ✗
          j = next[3] = 2

i=4, j=2: T[4]="A" = P[2]="A" ✓
i=5, j=3: T[5]="A" ≠ P[3]="B" ✗
          j = next[2] = 1

i=5, j=1: T[5]="A" ≠ P[1]="B" ✗
          j = next[1] = 0

i=5, j=0: T[5]="A" ≠ P[0]="A" ✗
          j = -1

i=5, j=-1: j++, i=6

i=6, j=0: T[6]="A" = P[0]="A" ✓
i=7, j=1: T[7]="B" = P[1]="B" ✓
i=8, j=2: T[8]="A" = P[2]="A" ✓
i=9, j=3: T[9]="B" = P[3]="B" ✓
i=10, j=4: T[10]="C" = P[4]="C" ✓

找到匹配！起始位置 = 10-5+1 = 6
```

## 五、复杂度分析

### 5.1 时间复杂度

**构建Next数组：**
```
最坏：O(m)，m为模式串长度

原因：
虽然有两层循环
但j每次最多递增m次
总共O(m)
```

**匹配过程：**
```
最坏：O(n)，n为文本串长度

原因：
i指针只向前移动
j指针通过next回退
每次回退都是基于已匹配信息
总共比较次数不超过2n
```

**总时间复杂度：**
```
O(m + n)
```

### 5.2 空间复杂度

```
Next数组：O(m)
辅助空间：O(1)

总空间：O(m)
```

## 六、KMP算法的优势

### 6.1 vs 暴力匹配

| 特性 | 暴力 | KMP |
|------|------|-----|
| **时间复杂度** | O(m×n) | O(m+n) |
| **最坏情况** | T="AAAA...", P="AAAB" | 相同情况高效 |
| **预处理** | 无 | O(m) |
| **适用** | 短模式 | 长模式，重复匹配 |

### 6.2 vs 其他算法

**Rabin-Karp（哈希）：**
```
优势：适合多模式匹配
劣势：哈希冲突，最坏O(m×n)
```

**Boyer-Moore：**
```
优势：通常比KMP更快
劣势：预处理复杂，最坏O(m×n)
```

**KMP特点：**
```
保证线性时间
适合模式串有重复结构
适合流式数据（边读边匹配）
```

## 八、KMP算法的变体

### 8.1 扩展KMP

**问题：**
```
对于每个位置i，求S[i...]与S的最长公共前缀
```

**应用：**
- 字符串周期检测
- 回文串问题

### 8.2 KMP自动化

**思想：**
```
将Next数组构建为有限状态机
每个状态对应已匹配的长度
转移由输入字符决定
```

**优势：**
```
易于硬件实现
适合流式处理
```

## 九、实现要点

### 9.1 边界处理

**特殊情况：**
```
1. 模式串为空
2. 文本串为空
3. 模式串比文本串长
4. next[0]的处理
```

### 9.2 实现技巧

**Next数组计算：**
```
使用递推避免重复
注意j的更新逻辑
处理j=-1的情况
```

**匹配过程：**
```
统一处理j=-1的情况
避免数组越界
及时返回匹配结果
```

## 十、总结

**KMP算法通过Next数组巧妙地利用已匹配信息，避免了重复比较，是字符串匹配的经典算法。**

**核心要点：**
1. 理解Next数组的含义和构建
2. 掌握匹配时如何跳过不可能位置
3. 注意边界条件和优化
4. 理解时间复杂度为O(m+n)的原因

**适用场景：**
- 大文本中查找模式
- 模式串有较多重复
- 需要保证最坏情况性能
