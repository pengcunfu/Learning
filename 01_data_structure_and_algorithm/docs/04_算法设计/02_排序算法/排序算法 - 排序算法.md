# 10种排序算法详解及其代码实现

排序算法是计算机科学中的经典算法问题之一。排序算法根据不同的排序原理和实现方式有着不同的时间复杂度、空间复杂度和适用场景。以下是常见的10种排序算法的详解和代码实现，涵盖了从简单的交换排序到更高效的归并排序、快速排序等算法。





## 1. **冒泡排序（Bubble Sort）**

冒泡排序通过重复地交换相邻的元素，使得较大的元素逐步“冒泡”到列表的末端。每次遍历未排序部分，都会将最大的元素放到末尾。

**时间复杂度**

- 最优：`O(n)`
- 最差：`O(n^2)`
- 平均：`O(n^2)`

**代码实现**

```cpp
#include <iostream>
using namespace std;

void bubbleSort(int arr[], int n) {
    for (int i = 0; i < n-1; i++) {
        for (int j = 0; j < n-i-1; j++) {
            if (arr[j] > arr[j+1]) {
                swap(arr[j], arr[j+1]);
            }
        }
    }
}

void printArray(int arr[], int n) {
    for (int i = 0; i < n; i++) {
        cout << arr[i] << " ";
    }
    cout << endl;
}

int main() {
    int arr[] = {64, 25, 12, 22, 11};
    int n = sizeof(arr)/sizeof(arr[0]);
    bubbleSort(arr, n);
    printArray(arr, n);
    return 0;
}
```







## 2. **选择排序（Selection Sort）**

**原理**

选择排序每一轮遍历中选择最小的元素与当前未排序部分的第一个元素交换位置，直到整个数组有序。

**时间复杂度**

- 最优：`O(n^2)`
- 最差：`O(n^2)`
- 平均：`O(n^2)`

**代码实现**

```cpp
#include <iostream>
using namespace std;

void selectionSort(int arr[], int n) {
    for (int i = 0; i < n-1; i++) {
        int minIdx = i;
        for (int j = i+1; j < n; j++) {
            if (arr[j] < arr[minIdx]) {
                minIdx = j;
            }
        }
        swap(arr[i], arr[minIdx]);
    }
}

void printArray(int arr[], int n) {
    for (int i = 0; i < n; i++) {
        cout << arr[i] << " ";
    }
    cout << endl;
}

int main() {
    int arr[] = {64, 25, 12, 22, 11};
    int n = sizeof(arr)/sizeof(arr[0]);
    selectionSort(arr, n);
    printArray(arr, n);
    return 0;
}
```

## 3. **插入排序（Insertion Sort）**

**原理**

插入排序从第二个元素开始，将其插入到已排序部分的适当位置。每次插入元素时，通过与前面元素的比较找到合适的插入位置。

**时间复杂度**

- 最优：`O(n)`
- 最差：`O(n^2)`
- 平均：`O(n^2)`

**代码实现**

```cpp
#include <iostream>
using namespace std;

void insertionSort(int arr[], int n) {
    for (int i = 1; i < n; i++) {
        int key = arr[i];
        int j = i - 1;
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j--;
        }
        arr[j + 1] = key;
    }
}

void printArray(int arr[], int n) {
    for (int i = 0; i < n; i++) {
        cout << arr[i] << " ";
    }
    cout << endl;
}

int main() {
    int arr[] = {64, 25, 12, 22, 11};
    int n = sizeof(arr)/sizeof(arr[0]);
    insertionSort(arr, n);
    printArray(arr, n);
    return 0;
}
```

## 4. **归并排序（Merge Sort）**

**原理**

归并排序是分治法的典型应用，将数组分为两部分，分别排序后再合并。每次递归分割数组，直到每个子数组长度为1，然后合并子数组。

**时间复杂度**

- 最优：`O(n log n)`
- 最差：`O(n log n)`
- 平均：`O(n log n)`

**代码实现**

```cpp
#include <iostream>
using namespace std;

void merge(int arr[], int left, int mid, int right) {
    int n1 = mid - left + 1;
    int n2 = right - mid;
    int L[n1], R[n2];

    for (int i = 0; i < n1; i++)
        L[i] = arr[left + i];
    for (int i = 0; i < n2; i++)
        R[i] = arr[mid + 1 + i];

    int i = 0, j = 0, k = left;
    while (i < n1 && j < n2) {
        if (L[i] <= R[j]) {
            arr[k] = L[i];
            i++;
        } else {
            arr[k] = R[j];
            j++;
        }
        k++;
    }

    while (i < n1) {
        arr[k] = L[i];
        i++;
        k++;
    }

    while (j < n2) {
        arr[k] = R[j];
        j++;
        k++;
    }
}

void mergeSort(int arr[], int left, int right) {
    if (left < right) {
        int mid = left + (right - left) / 2;
        mergeSort(arr, left, mid);
        mergeSort(arr, mid + 1, right);
        merge(arr, left, mid, right);
    }
}

void printArray(int arr[], int n) {
    for (int i = 0; i < n; i++) {
        cout << arr[i] << " ";
    }
    cout << endl;
}

int main() {
    int arr[] = {64, 25, 12, 22, 11};
    int n = sizeof(arr)/sizeof(arr[0]);
    mergeSort(arr, 0, n - 1);
    printArray(arr, n);
    return 0;
}
```

## 5. **快速排序（Quick Sort）**

**原理**

快速排序通过选择一个“基准”元素，将数组分为两部分，一部分小于基准，一部分大于基准，然后递归地排序这两部分。

**时间复杂度**

- 最优：`O(n log n)`
- 最差：`O(n^2)`
- 平均：`O(n log n)`

**代码实现**

```cpp
#include <iostream>
using namespace std;

int partition(int arr[], int low, int high) {
    int pivot = arr[high];
    int i = low - 1;
    for (int j = low; j <= high - 1; j++) {
        if (arr[j] < pivot) {
            i++;
            swap(arr[i], arr[j]);
        }
    }
    swap(arr[i + 1], arr[high]);
    return i + 1;
}

void quickSort(int arr[], int low, int high) {
    if (low < high) {
        int pi = partition(arr, low, high);
        quickSort(arr, low, pi - 1);
        quickSort(arr, pi + 1, high);
    }
}

void printArray(int arr[], int n) {
    for (int i = 0; i < n; i++) {
        cout << arr[i] << " ";
    }
    cout << endl;
}

int main() {
    int arr[] = {64, 25, 12, 22, 11};
    int n = sizeof(arr)/sizeof(arr[0]);
    quickSort(arr, 0, n - 1);
    printArray(arr, n);
    return 0;
}
```

## 6. **堆排序（Heap Sort）**

**原理**

堆排序利用堆这种数据结构（通常是二叉堆），首先将数组构建为一个大根堆或小根堆，然后交换堆顶元素与末尾元素，并重新调整堆。

**时间复杂度**

- 最优：`O(n log n)`
- 最差：`O(n log n)`
- 平均：`O(n log n)`

**代码实现**

```cpp
#include <iostream>
using namespace std;

void heapify(int arr[], int n, int i) {
    int largest = i;
    int left = 2 * i + 1;
    int right = 2 * i + 2;

    if (left < n && arr[left] > arr[largest]) {
        largest = left;
    }

    if (right < n && arr[right] > arr[largest]) { largest = right; }

    if (largest != i) {
        swap(arr[i], arr[largest]);
        heapify(arr, n, largest);
    }
}

void heapSort(int arr[], int n) { 
    for (int i = n / 2 - 1; i >= 0; i--) { 
        heapify(arr, n, i); 
    }
    for (int i = n - 1; i >= 0; i--) {
        swap(arr[0], arr[i]);
        heapify(arr, i, 0);
    }
}

void printArray(int arr[], int n) { 
    for (int i = 0; i < n; i++) { 
        cout << arr[i] << " "; 
    } 
    cout << endl; 
}

int main() { 
    int arr[] = {64, 25, 12, 22, 11}; 
    int n = sizeof(arr)/sizeof(arr[0]); 
    heapSort(arr, n); 
    printArray(arr, n); 
    return 0; 
}
```

## 7. **计数排序（Counting Sort）**

**原理**

计数排序通过统计每个元素出现的次数来确定元素的位置。它是一种线性时间排序算法，但仅适用于特定类型的数据（例如，非负整数）。

**时间复杂度**

- 最优：`O(n+k)`
- 最差：`O(n+k)`
- 平均：`O(n+k)`

**代码实现**

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

void countingSort(int arr[], int n, int range) {
    vector<int> count(range, 0);
    vector<int> output(n);

    for (int i = 0; i < n; i++) {
        count[arr[i]]++;
    }
    
    for (int i = 1; i < range; i++) {
        count[i] += count[i - 1];
    }
    
    for (int i = n - 1; i >= 0; i--) {
        output[count[arr[i]] - 1] = arr[i];
        count[arr[i]]--;
    }
    
    for (int i = 0; i < n; i++) {
        arr[i] = output[i];
    }
}

void printArray(int arr[], int n) {
    for (int i = 0; i < n; i++) {
        cout << arr[i] << " ";
    }
    cout << endl;
}

int main() {
    int arr[] = {4, 2, 2, 8, 3, 3, 1};
    int n = sizeof(arr)/sizeof(arr[0]);
    int range = 9;
    countingSort(arr, n, range);
    printArray(arr, n);
    return 0;
}
```

## 8. **桶排序（Bucket Sort）**

### 原理

桶排序将元素分配到不同的桶中，然后对每个桶内部排序，最后合并所有桶的内容。

### 时间复杂度

- 最优：`O(n+k)`
- 最差：`O(n^2)`
- 平均：`O(n+k)`

### 代码实现

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

void bucketSort(int arr[], int n) {
    int maxElement = *max_element(arr, arr + n);
    int bucketCount = maxElement / n + 1;
    vector<vector<int>> buckets(bucketCount);

    for (int i = 0; i < n; i++) {
        int index = arr[i] / n;
        buckets[index].push_back(arr[i]);
    }
    
    for (int i = 0; i < bucketCount; i++) {
        sort(buckets[i].begin(), buckets[i].end());
    }
    
    int idx = 0;
    for (int i = 0; i < bucketCount; i++) {
        for (int j = 0; j < buckets[i].size(); j++) {
            arr[idx++] = buckets[i][j];
        }
    }
}

void printArray(int arr[], int n) {
    for (int i = 0; i < n; i++) {
        cout << arr[i] << " ";
    }
    cout << endl;
}

int main() {
    int arr[] = {0.42, 0.32, 0.23, 0.52, 0.65, 0.75, 0.45};
    int n = sizeof(arr)/sizeof(arr[0]);
    bucketSort(arr, n);
    printArray(arr, n);
    return 0;
}
```

## 9. **基数排序（Radix Sort）**

### 原理

基数排序是一种非比较型排序方法，它从最低位到最高位逐步排序。每一轮排序使用稳定的排序算法。

### 时间复杂度

- 最优：`O(nk)`
- 最差：`O(nk)`
- 平均：`O(nk)`

### 代码实现

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int getMax(int arr[], int n) {
    int maxElement = arr[0];
    for (int i = 1; i < n; i++) {
        if (arr[i] > maxElement)
            maxElement = arr[i];
    }
    return maxElement;
}

void countingSortRadix(int arr[], int n, int exp) {
    int output[n];
    int count[10] = {0};

    for (int i = 0; i < n; i++) {
        count[(arr[i] / exp) % 10]++;
    }
    
    for (int i = 1; i < 10; i++) {
        count[i] += count[i - 1];
    }
    
    for (int i = n - 1; i >= 0; i--) {
        output[count[(arr[i] / exp) % 10] - 1] = arr[i];
        count[(arr[i] / exp) % 10]--;
    }
    
    for (int i = 0; i < n; i++) {
        arr[i] = output[i];
    }
}

void radixSort(int arr[], int n) {
    int maxElement = getMax(arr, n);
    for (int exp = 1; maxElement / exp > 0; exp *= 10) {
        countingSortRadix(arr, n, exp);
    }
}

void printArray(int arr[], int n) {
    for (int i = 0; i < n; i++) {
        cout << arr[i] << " ";
    }
    cout << endl;
}

int main() {
    int arr[] = {170, 45, 75, 90, 802, 24, 2, 66};
    int n = sizeof(arr)/sizeof(arr[0]);
    radixSort(arr, n);
    printArray(arr, n);
    return 0;
}
```

## 10. **希尔排序（Shell Sort）**

### 原理

希尔排序是插入排序的改进版，通过定义步长来进行间隔插入排序。步长逐步减小，最终变为1时，执行普通的插入排序。

### 时间复杂度

- 最优：`O(n log n)`
- 最差：`O(n^2)`
- 平均：`O(n^1.3)`

### 代码实现

```cpp
#include <iostream>
using namespace std;

void shellSort(int arr[], int n) {
    for (int gap = n / 2; gap > 0; gap /= 2) {
        for (int i = gap; i < n; i++) {
            int temp = arr[i];
            int j;
            for (j = i; j >= gap && arr[j - gap] > temp; j -= gap) {
                arr[j] = arr[j - gap];
            }
            arr[j] = temp;
        }
    }
}

void printArray(int arr[], int n) {
    for (int i = 0; i < n; i++) {
        cout << arr[i] << " ";
    }
    cout << endl;
}

int main() {
    int arr[] = {64, 25, 12, 22, 11};
    int n = sizeof(arr)/sizeof(arr[0]);
    shellSort(arr, n);
    printArray(arr, n);
    return 0;
}
```

### 桶排序（Bucket Sort）与基数排序（Radix Sort）

桶排序和基数排序是两种基于分布的排序算法，它们通过将数据分配到不同的桶中进行排序。这些算法通常适用于数据值范围已知且均匀分布的情况，能够在特定条件下达到线性时间复杂度。

#### 1. 桶排序（Bucket Sort）

桶排序是将数据分到有限数量的桶里，每个桶内排序，再将桶内的元素合并，最终得到有序的序列。桶排序的关键点在于如何确定桶的数量以及每个桶的范围。

##### 算法步骤：

1. **分配桶**：根据数据的范围，将数据均匀分配到各个桶中。
2. **桶内排序**：对每个桶内的元素进行排序。通常桶内排序使用其他排序算法，比如插入排序。
3. **合并桶**：将所有桶中的元素按顺序合并起来，得到最终的排序结果。

##### 桶排序的时间复杂度：

- 最好情况下，桶排序的时间复杂度为 `O(n + k)`，其中 `n` 是待排序元素的个数，`k` 是桶的数量。
- 当桶内元素不均匀时，最坏情况下时间复杂度为 `O(n^2)`。

##### C++实现：

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

// 插入排序，用于桶内排序
void insertionSort(vector<int>& arr) {
    for (int i = 1; i < arr.size(); ++i) {
        int key = arr[i];
        int j = i - 1;
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            --j;
        }
        arr[j + 1] = key;
    }
}

// 桶排序
void bucketSort(vector<int>& arr, int bucketCount) {
    if (arr.empty()) return;

    // 找到数据的最大值和最小值
    int minValue = *min_element(arr.begin(), arr.end());
    int maxValue = *max_element(arr.begin(), arr.end());

    // 计算桶的区间
    float bucketRange = (float)(maxValue - minValue + 1) / bucketCount;

    // 初始化桶
    vector<vector<int>> buckets(bucketCount);

    // 将元素分配到对应的桶
    for (int num : arr) {
        int bucketIndex = (num - minValue) / bucketRange;
        buckets[bucketIndex].push_back(num);
    }

    // 对每个桶进行排序
    for (auto& bucket : buckets) {
        insertionSort(bucket);
    }

    // 合并所有桶中的元素
    arr.clear();
    for (auto& bucket : buckets) {
        for (int num : bucket) {
            arr.push_back(num);
        }
    }
}

int main() {
    vector<int> arr = {29, 25, 3, 49, 9, 37, 21, 43};

    // 设置桶的数量
    int bucketCount = 4;
    bucketSort(arr, bucketCount);

    // 输出排序后的数组
    for (int num : arr) {
        cout << num << " ";
    }
    cout << endl;

    return 0;
}
```

#### 2. 基数排序（Radix Sort）

基数排序是一种非比较型排序算法，它通过逐位对数字进行排序（从低位到高位或者从高位到低位）。基数排序通常通过多个稳定的排序方法（如计数排序）对每个位上的元素进行排序，直到排序完成。

##### 算法步骤：

1. **从最低位开始排序**：对每个数字的每一位进行排序。
2. **稳定排序**：使用稳定排序算法（例如计数排序）对每一位的数字进行排序。
3. **继续处理更高位**：依次对每一位进行排序，直到所有位都排序完毕。

##### 基数排序的时间复杂度：

- 假设数据有 `n` 个元素，每个元素的位数为 `d`，那么基数排序的时间复杂度是 `O(d * (n + b))`，其中 `b` 是基数（如数字的范围，10 对应十进制）。通常 `d` 是常数，因此可以认为基数排序是线性时间复杂度 `O(n)`。

##### C++实现：

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

// 计数排序，用于基数排序的某一位排序
void countingSort(vector<int>& arr, int exp) {
    vector<int> output(arr.size());  // 输出数组
    vector<int> count(10, 0);        // 计数数组（假设基数是10）

    // 存储每个数字的出现次数
    for (int i = 0; i < arr.size(); ++i) {
        count[(arr[i] / exp) % 10]++;
    }

    // 累加计数数组的值
    for (int i = 1; i < 10; ++i) {
        count[i] += count[i - 1];
    }

    // 从后往前遍历原数组，保持稳定性
    for (int i = arr.size() - 1; i >= 0; --i) {
        output[count[(arr[i] / exp) % 10] - 1] = arr[i];
        count[(arr[i] / exp) % 10]--;
    }

    // 将输出数组复制回原数组
    for (int i = 0; i < arr.size(); ++i) {
        arr[i] = output[i];
    }
}

// 基数排序
void radixSort(vector<int>& arr) {
    if (arr.empty()) return;

    // 找到数组中的最大值
    int maxValue = *max_element(arr.begin(), arr.end());

    // 对每个位数进行计数排序
    for (int exp = 1; maxValue / exp > 0; exp *= 10) {
        countingSort(arr, exp);
    }
}

int main() {
    vector<int> arr = {170, 45, 75, 90, 802, 24, 2, 66};

    radixSort(arr);

    // 输出排序后的数组
    for (int num : arr) {
        cout << num << " ";
    }
    cout << endl;

    return 0;
}
```

#### 3. 桶排序与基数排序的比较

| 排序算法 | 时间复杂度     | 空间复杂度 | 稳定性 | 优点                         | 缺点                               |
| -------- | -------------- | ---------- | ------ | ---------------------------- | ---------------------------------- |
| 桶排序   | O(n + k)       | O(n + k)   | 稳定   | 适用于数据范围较小或均匀分布 | 空间开销大，不适用于数据范围大     |
| 基数排序 | O(d * (n + b)) | O(n + b)   | 稳定   | 适用于数据比较大但位数较少   | 对数据位数要求较高，空间复杂度较高 |

- **桶排序**：适合均匀分布的数据，通过分桶将数据分布到桶中，桶内使用其他排序算法处理。数据范围较小或均匀分布时，桶排序的性能非常好。
- **基数排序**：通过逐位进行排序，适用于数字数据，特别是位数较少的整数，时间复杂度通常较低，可以视为线性时间排序。

两者在不同的应用场景下各有优势，选择合适的排序算法能够获得更高的性能。
