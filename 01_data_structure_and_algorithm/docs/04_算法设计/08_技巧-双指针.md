# 双指针技巧（Two Pointers）

## 一、双指针概述

### 1.1 什么是双指针？

**双指针：**
> 在算法中使用两个指针来遍历数据结构，通过指针的移动来高效解决问题

**常见类型：**
1. **对撞指针**：从两端向中间移动
2. **快慢指针**：一个快一个慢
3. **滑动窗口**：窗口大小固定或可变

### 1.2 为什么使用双指针？

**优势：**
```
1. 空间效率：通常只需要O(1)额外空间
2. 时间效率：O(n)单次遍历
3. 代码简洁：逻辑清晰
```

**适用场景：**
- 有序数组的两数之和
- 链表中间节点
- 数组去重
- 滑动窗口问题

## 二、对撞指针

### 2.1 基本思想

**模式：**
```
left = 0, right = n-1
while left < right:
    处理 arr[left] 和 arr[right]
    left++
    right--
```

**示例1：两数之和**
```
问题：在有序数组中找和为target的两个数

算法：
left = 0, right = n-1
while left < right:
    sum = arr[left] + arr[right]
    if sum == target:
        return [left, right]
    elif sum < target:
        left++  // 需要更大的数
    else:
        right-- // 需要更小的数
```

**示例2：判断回文**
```
问题：判断字符串是否为回文

算法：
left = 0, right = n-1
while left < right:
    if s[left] != s[right]:
        return false
    left++
    right--
return true
```

## 三、快慢指针

### 3.1 基本思想

**模式：**
```
slow = head
fast = head
while fast && fast.next:
    slow = slow.next
    fast = fast.next.next
```

**速度关系：**
```
fast的速度是slow的2倍
当fast到达终点时，slow在中间
```

### 3.2 应用示例

**示例1：链表中点**
```
问题：找链表的中间节点

算法：
slow = fast = head
while fast && fast.next:
    slow = slow.next
    fast = fast.next.next
return slow
```

**示例2：检测环**
```
问题：判断链表是否有环

算法：
slow = fast = head
while fast && fast.next:
    slow = slow.next
    fast = fast.next.next
    if slow == fast:
        return true  // 有环
return false
```

**示例3：环的起点**
```
问题：找到环的起点

算法：
1. 先用快慢指针判断是否有环
2. 有环后，一个指针回到起点
3. 两个指针同速移动，相遇点即为起点
```

## 四、滑动窗口

### 4.1 固定大小窗口

**模式：**
```
窗口大小固定为k
维护窗口内元素的和/最大/最小
```

**示例：**
```
问题：大小为k的滑动窗口最大值

算法：
max_val = -∞
for i in range(k, n):
    更新窗口内容
    记录最大值
```

### 4.2 可变大小窗口

**模式：**
```
窗口大小动态调整
根据条件收缩或扩展
```

**示例：**
```
问题：最短包含子串

算法：
left = 0
for right in range(n):
    扩展窗口直到满足条件
    收缩窗口直到不满足条件
    记录最小窗口
```

**应用：**
- 最小覆盖子串
- 最长无重复字符子串
- 固定和的子数组

## 五、三指针

### 5.1 基本思想

**模式：**
```
使用三个指针处理更复杂的情况
```

**示例：三数之和**
```
问题：找出和为0的三元组

算法：
for i in range(n-2):
    j = i + 1
    k = n - 1
    while j < k:
        sum = nums[i] + nums[j] + nums[k]
        if sum == 0:
            记录解
        if sum < 0:
            j++
        else:
            k--
```

## 六、双指针技巧总结

### 6.1 使用场景

**适用条件：**
1. 数据是有序的
2. 需要考虑两个元素之间的关系
3. 需要维持窗口或间隔

### 6.2 优势

**vs 暴力搜索：**
```
暴力：O(n²)或O(n³)
双指针：O(n)
空间复杂度：O(1)
```

**vs 哈希表：**
```
哈希表：O(n)时间，O(n)空间
双指针：O(n)时间，O(1)空间
```

### 6.3 编程技巧

**边界处理：**
```
注意指针越界
考虑空数据
处理特殊情况
```

**循环不变式：**
```
维护循环的约束条件
确保指针移动正确
```

## 七、经典题目

### 7.1 盛水容器

**问题：**
```
给定n个非负整数，每个数代表一个坐标高度，
计算能盛多少水
```

**解法：**
```
使用对撞指针
left = 0, right = n-1
while left < right:
    if height[left] < height[right]:
        left++
    else:
        right--
```

### 7.2 接雨水

**问题：**
```
给定n个非负整数表示高度图，
计算下雨后能接多少水
```

**解法：**
```
按列处理
每列维护左右最高点
该列水量 = min(maxLeft, maxRight) - height
```

## 八、总结

**双指针是优雅的算法技巧，能用O(n)时间和O(1)空间解决很多问题。**
