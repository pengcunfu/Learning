# 目标代码生成：从抽象到具体的映射

## 目标代码生成的核心思想

目标代码生成(Code Generation)是编译过程的最后阶段。表面任务是将中间代码转换为特定目标机器的机器语言，深层思想是**将抽象的计算模型映射到具体的硬件资源，在有限资源约束下寻求最优解**。

### 本质挑战：资源映射与优化
```
抽象的IR            具体的机器码
─────────→        ─────────→
无限虚拟寄存器      有限物理寄存器
抽象内存模型        实际内存层次
通用运算符          特定机器指令
```

**核心思想**: 在保证正确性的前提下，充分利用目标机器的资源特性，生成高效的目标代码。

## 代码生成的理论基础

### 2. 指令选择问题
**形式化定义**: 给定中间表示IR和目标机器指令集M，找到从IR到M的最优映射

**复杂度**: 树覆盖问题是NP完全的
```
问题: 最小代价的树覆盖
输入: 表达式树T，指令模式集P
输出: T的覆盖C，最小化 Σ pattern∈C cost(pattern)
```

### 3. 寄存器分配问题
**形式化定义**: 将无限的虚拟寄存器映射到有限的物理寄存器

**图着色问题**: NP完全问题
```
问题: 寄存器分配作为图着色
- 构造干扰图: 节点=虚拟寄存器，边=同时活跃的寄存器对
- k种颜色 = k个可用寄存器
- 找到k着色方案
```

## 指令选择技术

### 1. 基于树匹配的指令选择
```cpp
class TreeBasedInstructionSelector {
private:
    // 指令模式树
    struct PatternNode {
        Opcode opcode;
        std::vector<PatternNode*> children;
        int cost;  // 匹配代价
        Instruction* targetInst;  // 对应的目标指令
    };

    PatternNode* patternRoot_;

public:
    void select(Instruction* inst, TargetMachine* target) {
        // 1. 构建表达式树
        auto* exprTree = buildExpressionTree(inst);

        // 2. 动态规划匹配最优模式
        auto matchResult = matchOptimalPattern(exprTree, target);

        // 3. 生成目标指令
        emitInstructions(matchResult);
    }

private:
    struct MatchResult {
        PatternNode* pattern;
        int cost;
        std::vector<Instruction*> instructions;
    };

    MatchResult matchOptimalPattern(ExprNode* tree, TargetMachine* target) {
        MatchResult best;
        best.cost = INT_MAX;

        // 尝试所有可能的模式
        for (auto* pattern : getMatchingPatterns(tree, target)) {
            int currentCost = pattern->cost;

            // 递归匹配子树
            for (auto* child : tree->getChildren()) {
                auto childMatch = matchOptimalPattern(child, target);
                currentCost += childMatch.cost;
            }

            if (currentCost < best.cost) {
                best.pattern = pattern;
                best.cost = currentCost;
            }
        }

        return best;
    }

    std::vector<PatternNode*> getMatchingPatterns(ExprNode* tree, TargetMachine* target) {
        std::vector<PatternNode*> matches;

        // 根据表达式树的特征查找匹配的模式
        for (auto* pattern : patternRoot_->getChildren()) {
            if (matchesPattern(tree, pattern)) {
                matches.push_back(pattern);
            }
        }

        return matches;
    }
};
```

### 2. 基于DAG的指令选择
```cpp
class DAGBasedInstructionSelector {
private:
    struct DAGNode {
        Instruction* inst;
        std::vector<DAGNode*> operands;
        int cost;  // 最优代价
        Instruction* selectedInst;  // 选中的指令
    };

public:
    void select(Function* func, TargetMachine* target) {
        // 1. 构建DAG
        auto* dag = buildDAG(func);

        // 2. 自底向上匹配模式
        std::map<DAGNode*, MatchResult> memo;
        for (auto* node : dag->getNodesInPostOrder()) {
            memo[node] = matchNode(node, target, memo);
        }

        // 3. 生成指令
        emitInstructions(memo[dag->getRoot()]);
    }

private:
    MatchResult matchNode(
        DAGNode* node,
        TargetMachine* target,
        std::map<DAGNode*, MatchResult>& memo
    ) {
        // 尝试单指令模式
        auto singleMatch = matchSingleInstruction(node, target, memo);

        // 尝试多指令模式
        auto multiMatch = matchMultipleInstructions(node, target, memo);

        // 选择代价较小的
        return (singleMatch.cost < multiMatch.cost) ? singleMatch : multiMatch;
    }
};
```

## 寄存器分配算法

### 1. 图着色寄存器分配
```cpp
class GraphColoringRegisterAllocator {
private:
    struct InterferenceGraph {
        std::map<VirtualRegister*, std::set<VirtualRegister*>> edges;

        void addEdge(VirtualRegister* v1, VirtualRegister* v2) {
            edges[v1].insert(v2);
            edges[v2].insert(v1);
        }

        int getDegree(VirtualRegister* v) {
            return edges[v].size();
        }
    };

    InterferenceGraph igraph_;
    std::set<PhysicalRegister*> availableRegs_;
    std::map<VirtualRegister*, PhysicalRegister*> allocation_;

public:
    bool allocate(Function* func) {
        // 1. 构建干扰图
        buildInterferenceGraph(func);

        // 2. 简化(图着色算法)
        std::stack<VirtualRegister*> stack;
        while (simplify(stack)) {
            // 继续简化
        }

        // 3. 选择(分配颜色)
        while (!stack.empty()) {
            auto* vreg = stack.top();
            stack.pop();

            if (!selectRegister(vreg)) {
                // 分配失败，需要溢出
                return false;
            }
        }

        return true;
    }

private:
    bool simplify(std::stack<VirtualRegister*>& stack) {
        bool simplified = false;

        // 找出度数 < K 的节点(K = 可用寄存器数)
        for (auto& [vreg, neighbors] : igraph_.edges) {
            if (igraph_.getDegree(vreg) < availableRegs_.size()) {
                stack.push(vreg);
                igraph_.edges.erase(vreg);
                simplified = true;
            }
        }

        return simplified;
    }

    bool selectRegister(VirtualRegister* vreg) {
        // 找出可用的物理寄存器
        std::set<PhysicalRegister*> candidates = availableRegs_;

        // 排除已被邻居使用的寄存器
        for (auto* neighbor : igraph_.edges[vreg]) {
            if (allocation_.count(neighbor)) {
                candidates.erase(allocation_[neighbor]);
            }
        }

        if (candidates.empty()) {
            return false;  // 分配失败
        }

        // 选择寄存器(简单的启发式: 第一个可用寄存器)
        PhysicalRegister* selected = *candidates.begin();
        allocation_[vreg] = selected;

        return true;
    }

    void buildInterferenceGraph(Function* func) {
        // 使用活跃变量分析构建干扰图
        LiveVariables liveness;
        liveness.analyze(func);

        for (auto* block : func->getBlocks()) {
            auto live = liveness.getLiveOut(block);

            for (auto* inst : reverse(block->getInstructions())) {
                // 处理指令定义的寄存器
                for (auto* def : inst->getDefs()) {
                    // def与所有活跃的寄存器干扰
                    for (auto* liveReg : live) {
                        igraph_.addEdge(def, liveReg);
                    }
                    live.erase(def);  // def不是活跃的
                }

                // 处理指令使用的寄存器
                for (auto* use : inst->getUses()) {
                    live.insert(use);
                }
            }
        }
    }
};
```

### 2. 线性扫描寄存器分配
```cpp
class LinearScanRegisterAllocator {
public:
    void allocate(Function* func) {
        // 1. 计算每个虚拟寄存器的活跃区间
        auto intervals = computeLiveIntervals(func);

        // 2. 按区间起点排序
        std::sort(intervals.begin(), intervals.end(),
                 [](const auto& a, const auto& b) {
                     return a.start < b.start;
                 });

        // 3. 线性扫描分配
        std::set<LiveInterval*> active;
        std::map<VirtualRegister*, PhysicalRegister*> allocation;

        for (auto* interval : intervals) {
            // 处理已结束的区间
            expireOldIntervals(interval, active);

            // 尝试分配寄存器
            if (active.size() < availableRegs_.size()) {
                // 有空闲寄存器
                PhysicalRegister* reg = getFreeRegister(active, availableRegs_);
                allocation[interval->vreg] = reg;
                active.insert(interval);
            } else {
                // 需要溢出
                spillInterval(interval, active, allocation);
            }
        }
    }

private:
    struct LiveInterval {
        VirtualRegister* vreg;
        int start;  // 第一次使用的位置
        int end;    // 最后一次使用的位置
    };

    void expireOldIntervals(
        LiveInterval* current,
        std::set<LiveInterval*>& active
    ) {
        std::vector<LiveInterval*> expired;
        for (auto* interval : active) {
            if (interval->end >= current->start) {
                expired.push_back(interval);
            }
        }

        for (auto* interval : expired) {
            active.erase(interval);
        }
    }

    void spillInterval(
        LiveInterval* interval,
        std::set<LiveInterval*>& active,
        std::map<VirtualRegister*, PhysicalRegister*>& allocation
    ) {
        // 找出结束最晚的活跃区间
        LiveInterval* spill = *std::max_element(active.begin(), active.end(),
            [](const auto* a, const auto* b) {
                return a->end < b->end;
            });

        if (spill->end > interval->end) {
            // 溢出spill，分配当前区间
            allocation.erase(spill->vreg);
            insertSpillCode(spill);

            PhysicalRegister* reg = allocation[spill->vreg];
            allocation[interval->vreg] = reg;
            active.erase(spill);
            active.insert(interval);
        } else {
            // 溢出当前区间
            insertSpillCode(interval);
        }
    }
};
```

## 栈帧管理

### 1. 栈帧布局
```cpp
class StackFrameLayout {
private:
    struct FrameLayout {
        int returnAddressOffset;
        int savedRegistersOffset;
        int localsOffset;
        int spillAreaOffset;
        int argumentsOffset;
        int totalSize;
    };

public:
    FrameLayout layoutFrame(Function* func) {
        FrameLayout layout;
        int currentOffset = 0;

        // 1. 返回地址
        layout.returnAddressOffset = currentOffset;
        currentOffset += target_->getPointerSize();

        // 2. 保存的被调用者保护寄存器
        layout.savedRegistersOffset = currentOffset;
        for (auto* reg : func->getSavedRegisters()) {
            currentOffset += reg->getSize();
        }

        // 3. 局部变量
        layout.localsOffset = currentOffset;
        for (auto* localVar : func->getLocalVariables()) {
            localVar->setOffset(currentOffset);
            currentOffset += localVar->getSize();
        }

        // 4. 溢出区域
        layout.spillAreaOffset = currentOffset;
        for (auto* spill : func->getSpilledRegisters()) {
            spill->setSpillOffset(currentOffset);
            currentOffset += target_->getPointerSize();
        }

        // 5. 参数区域(用于调用其他函数)
        layout.argumentsOffset = currentOffset;

        // 对齐栈
        layout.totalSize = alignTo(currentOffset, target_->getStackAlignment());

        return layout;
    }
};
```

### 2. 调用约定实现
```cpp
class CallingConventionImpl {
public:
    void emitCall(Function* caller, Function* callee, CallInst* call) {
        auto* conv = target_->getCallingConvention();

        // 1. 在寄存器中传递参数
        int regIndex = 0;
        for (auto* arg : call->getArguments()) {
            if (regIndex < conv->argumentRegs.size()) {
                auto* reg = conv->argumentRegs[regIndex];
                emitMove(reg, arg);
                regIndex++;
            } else {
                // 参数在栈上传递
                int stackOffset = (regIndex - conv->argumentRegs.size()) *
                                 target_->getPointerSize();
                emitStore(arg, StackPointer::get(), stackOffset);
                regIndex++;
            }
        }

        // 2. 发起调用
        emitCall(callee);

        // 3. 处理返回值
        if (!callee->getReturnType()->isVoid()) {
            auto* returnReg = conv->returnRegs[0];
            auto* resultDest = call->getDest();
            emitMove(resultDest, returnReg);
        }
    }

    void emitFunctionPrologue(Function* func) {
        auto* conv = target_->getCallingConvention();

        // 1. 保存帧指针(如果使用)
        if (conv->useFramePointer) {
            emitPush(conv->framePointer);
            emitMove(conv->framePointer, conv->stackPointer);
        }

        // 2. 分配栈帧
        emitAddImmediate(conv->stackPointer, -func->getStackSize());

        // 3. 保存被调用者保护的寄存器
        for (auto* reg : func->getSavedRegisters()) {
            emitPush(reg);
        }
    }

    void emitFunctionEpilogue(Function* func) {
        auto* conv = target_->getCallingConvention();

        // 1. 恢复被调用者保护的寄存器
        for (auto it = func->getSavedRegisters().rbegin();
             it != func->getSavedRegisters().rend(); ++it) {
            emitPop(*it);
        }

        // 2. 释放栈帧
        if (conv->useFramePointer) {
            emitMove(conv->stackPointer, conv->framePointer);
            emitPop(conv->framePointer);
        } else {
            emitAddImmediate(conv->stackPointer, func->getStackSize());
        }

        // 3. 返回
        emitReturn();
    }
};
```

## 机器特定优化

### 1. 分支预测优化
```cpp
class BranchPredictionOptimizer {
public:
    void optimize(Function* func) {
        auto profileData = getProfileData(func);

        for (auto* inst : func->getInstructions()) {
            if (auto* branch = dyn_cast<BranchInst>(inst)) {
                optimizeBranch(branch, profileData);
            }
        }
    }

private:
    void optimizeBranch(BranchInst* branch, const ProfileData& profile) {
        // 根据分支预测信息重新组织基本块
        if (profile.getTakenProbability(branch) > 0.7) {
            // 高概率taken，将then块放在fallthrough位置
            reorderBlocks(branch->getParent(), branch->getSuccessor(0));
        } else {
            // 高概率not taken，将else块放在fallthrough位置
            reorderBlocks(branch->getParent(), branch->getSuccessor(1));
        }

        // 添加分支预测提示
        if (target_->supportsBranchHints()) {
            if (profile.getTakenProbability(branch) > 0.8) {
                branch->setHint(BranchHint::LIKELY_TAKEN);
            } else if (profile.getTakenProbability(branch) < 0.2) {
                branch->setHint(BranchHint::LIKELY_NOT_TAKEN);
            }
        }
    }
};
```

```cpp
            if (isMemoryBoundLoop(loop)) {

                auto* arrayPtr = findArrayAccess(loop);
                if (arrayPtr) {
                    auto* prefetchPoint = loop->getPreheader()->getTerminator();
                    emitPrefetch(prefetchPoint, arrayPtr);
                }
            }
        }
    }
};
```

```cpp
class MachineCodeEmitter {
public:
    std::vector<uint8_t> emit(Function* func) {
        std::vector<uint8_t> code;

        for (auto* block : func->getBlocks()) {
            for (auto* inst : block->getInstructions()) {
                emitInstruction(inst, code);
            }
        }

        return code;
    }

private:
    void emitInstruction(MachineInst* inst, std::vector<uint8_t>& code) {
        switch (inst->getOpcode()) {
            case ADD:
                emitAdd(inst, code);
                break;
            case SUB:
                emitSub(inst, code);
                break;
            // ... 更多指令
            default:
                emitGeneric(inst, code);
                break;
        }
    }

    void emitAdd(MachineInst* inst, std::vector<uint8_t>& code) {
        // 生成具体的机器码
        auto encoding = target_->getEncoding(inst->getOpcode());

        for (auto byte : encoding.prefix) {
            code.push_back(byte);
        }

        // 处理操作数
        for (auto& op : inst->getOperands()) {
            emitOperand(op, code);
        }

        for (auto byte : encoding.suffix) {
            code.push_back(byte);
        }
    }
};
```

## 总结

目标代码生成是编译原理中理论与实践并重的部分：

1. **资源约束**: 在有限资源下寻求最优解
2. **算法设计**: 寄存器分配、指令选择等NP难问题
3. **机器相关**: 充分利用目标机器特性
4. **工程挑战**: 复杂度与性能的平衡

目标代码生成的美妙在于：
- **理论深度**: 基于图论、组合优化等理论
- **实用价值**: 直接影响程序性能
- **复杂性**: 需要考虑多种硬件特性
- **创造性**: 需要创新的算法和启发式

掌握目标代码生成不仅有助于理解编译器工作原理，更能培养对计算机体系结构的深刻理解。这种理解对于编写高性能程序、设计编译器、优化系统具有重要价值。目标代码生成体现了"理论指导实践，实践反哺理论"这一计算机科学的核心原则。
