# 代码优化：在等价变换中追求极致性能

## 代码优化的核心思想

代码优化(Code Optimization)是编译过程中最具挑战性的阶段之一。表面任务是提升代码的执行效率，深层思想是**在保持语义等价的前提下，通过等价变换充分利用目标机器的资源特性**。

### 本质原则：语义保持 + 效率提升
```
原始程序          优化程序
   ↓                ↓
语义相同        执行更高效
   ↓                ↓
正确性保证      性能改进
```

**核心思想**: 编译器比程序员更了解机器特性，能够自动进行程序员难以实现或容易出错的优化。

## 代码优化的理论基础

### 1. 优化正确性原则
**语义等价性**: 优化后的程序必须与原程序语义相同
```
形式化定义:
对于任意输入x，优化后的程序P'与原程序P满足：
P(x) = P'(x)

等价性保证:
- 数据流等价: 变量的使用关系不变
- 控制流等价: 程序的执行路径等价
- 副作用等价: 外部可见行为相同
```

### 2. 优化的理论界限
**Rice 定理**：程序的大多数性质都是不可判定的
```
含义:
- 无法确定任意程序是否会执行某些操作
- 无法确定任意两个程序是否等价
- 优化必须保守，只能处理可分析的情况

实际意义:
- 保守优化: 只在确定安全时才优化
- 局部优化: 限制在可分析的范围内
- 启发式优化: 基于常见模式而非完备算法
```

### 3. 优化的分类维度
**按范围分类**:
- **局部优化**: 基本块内的优化
- **循环优化**: 循环体内的优化
- **过程间优化**: 跨函数边界的优化
- **全局优化**: 整个程序范围的优化

**按时机分类**:
- **机器无关优化**: 不依赖目标机器
- **机器相关优化**: 利用特定机器特性

## 数据流分析框架

### 1. 数据流抽象
```cpp
template<typename Domain>
class DataFlowAnalysis {
public:
    // 数据流值
    using DataFlowValue = Domain;

    // 传递函数
    using TransferFunction = std::function<DataFlowValue(
        const DataFlowValue&, BasicBlock*
    )>;

    // 交汇运算
    using MeetOperator = std::function<DataFlowValue(
        const std::vector<DataFlowValue>&
    )>;

protected:
    TransferFunction transferFn_;
    MeetOperator meetFn_;
    Direction direction_;  // FORWARD or BACKWARD

public:
    void analyze(Function* func) {
        // 初始化
        std::map<BasicBlock*, DataFlowValue> in, out;
        for (auto* block : func->getBlocks()) {
            in[block] = initialize();
            out[block] = initialize();
        }

        // 工表算法
        std::queue<BasicBlock*> worklist;
        initializeWorklist(func, worklist);

        while (!worklist.empty()) {
            auto* block = worklist.front();
            worklist.pop();

            // 计算新的输入
            DataFlowValue newIn = computeIn(block, out);
            // 计算新的输出
            DataFlowValue newOut = transferFn_(newIn, block);

            // 检查变化
            if (newIn != in[block] || newOut != out[block]) {
                in[block] = newIn;
                out[block] = newOut;

                // 添加后继(前向)或前驱(后向)到工作表
                updateWorklist(block, worklist);
            }
        }
    }
};
```

```cpp
class ReachingDefinitions : public DataFlowAnalysis<std::set<Definition*>> {
public:
    ReachingDefinitions() {
        direction_ = FORWARD;
        transferFn_ = [this](const auto& input, BasicBlock* block) {
            auto result = input;

            // kill: 删除块内重新定义的定义
            // gen: 添加块内新生成的定义
            for (auto* inst : block->getInstructions()) {
                result.erase(inst->getKilledDefs());
                result.insert(inst->getGeneratedDefs());
            }

            return result;
        };

        meetFn_ = [](const std::vector<DataFlowValue>& values) {
            std::set<Definition*> result;
            for (const auto& value : values) {
                result.insert(value.begin(), value.end());
            }
            return result;  // 并集
        };
    }

    DataFlowValue initialize() override {
        return {};  // 空集
    }
};
```

**活跃变量分析(Live Variables)**:
```cpp
class LiveVariables : public DataFlowAnalysis<std::set<Variable*>> {
public:
    LiveVariables() {
        direction_ = BACKWARD;
        transferFn_ = [this](const auto& input, BasicBlock* block) {
            auto result = input;

            // use: 块内使用的变量
            // def: 块内定义的变量
            // OUT = use ∪ (IN - def)
            for (auto* inst : reverse(block->getInstructions())) {
                result.insert(inst->getUses());
                result.erase(inst->getDefs());
            }

            return result;
        };

        meetFn_ = [](const std::vector<DataFlowValue>& values) {
            std::set<Variable*> result;
            for (const auto& value : values) {
                result.insert(value.begin(), value.end());
            }
            return result;  // 并集
        };
    }

    DataFlowValue initialize() override {
        return {};  // 空集
    }
};
```

## 局部优化技术

### 1. 常量传播与折叠
```cpp
class ConstantPropagation {
private:
    struct LatticeValue {
        enum { UNDEFINED, CONSTANT, OVERDEFINED } state;
        int constantValue;

        bool isOverdefined() const { return state == OVERDEFINED; }
        bool isConstant() const { return state == CONSTANT; }
        bool isUndefined() const { return state == UNDEFINED; }

        static LatticeValue meet(const LatticeValue& a, const LatticeValue& b) {
            if (a.isOverdefined() || b.isOverdefined()) {
                return LatticeValue::createOverdefined();
            }
            if (a.isUndefined()) return b;
            if (b.isUndefined()) return a;
            if (a.constantValue == b.constantValue) {
                return a;
            }
            return LatticeValue::createOverdefined();
        }
    };

public:
    void optimize(BasicBlock* block) {
        std::map<Value*, LatticeValue> lattice;

        for (auto* inst : block->getInstructions()) {
            if (auto* binOp = dyn_cast<BinaryInst>(inst)) {
                auto leftLattice = lattice[binOp->getLeftOperand()];
                auto rightLattice = lattice[binOp->getRightOperand()];

                if (leftLattice.isConstant() && rightLattice.isConstant()) {
                    // 常量折叠
                    int result = evaluateConstant(binOp->getOpcode(),
                                               leftLattice.constantValue,
                                               rightLattice.constantValue);
                    binOp->replaceAllUsesWith(ConstantInt::get(result));
                    lattice[binOp] = LatticeValue::createConstant(result);
                } else {
                    lattice[binOp] = LatticeValue::meet(leftLattice, rightLattice);
                }
            }
        }
    }

private:
    int evaluateConstant(Opcode op, int left, int right) {
        switch (op) {
            case ADD: return left + right;
            case SUB: return left - right;
            case MUL: return left * right;
            case DIV: return left / right;
            default: return 0;
        }
    }
};
```

### 2. 公共子表达式消除
```cpp
class CommonSubexpressionElimination {
private:
    struct Expression {
        Opcode opcode;
        Value* left;
        Value* right;

        bool operator==(const Expression& other) const {
            return opcode == other.opcode &&
                   left == other.left &&
                   right == other.right;
        }
    };

public:
    void optimize(Function* func) {
        std::map<Expression, Value*> availableExprs;

        for (auto* block : func->getBlocks()) {
            for (auto* inst : block->getInstructions()) {
                if (auto* binOp = dyn_cast<BinaryInst>(inst)) {
                    Expression expr = {
                        binOp->getOpcode(),
                        binOp->getLeftOperand(),
                        binOp->getRightOperand()
                    };

                    auto it = availableExprs.find(expr);
                    if (it != availableExprs.end()) {
                        // 找到相同的表达式，重用结果
                        binOp->replaceAllUsesWith(it->second);
                        binOp->eraseFromParent();
                    } else {
                        // 记录新表达式
                        availableExprs[expr] = binOp;
                    }
                }
            }

            // 块结束时清空（仅局部CSE）
            availableExprs.clear();
        }
    }
};
```

### 3. 死代码消除
```cpp
class DeadCodeElimination {
public:
    void eliminate(Function* func) {
        // 1. 标记活跃指令
        std::set<Instruction*> live;
        markLiveInstructions(func, live);

        // 2. 删除死指令
        std::vector<Instruction*> dead;
        for (auto* block : func->getBlocks()) {
            for (auto* inst : block->getInstructions()) {
                if (!live.count(inst) && isSafeToDelete(inst)) {
                    dead.push_back(inst);
                }
            }
        }

        for (auto* inst : dead) {
            inst->eraseFromParent();
        }
    }

private:
    void markLiveInstructions(Function* func, std::set<Instruction*>& live) {
        std::queue<Instruction*> worklist;

        // 添加所有可能有副作用的指令
        for (auto* block : func->getBlocks()) {
            for (auto* inst : block->getInstructions()) {
                if (hasSideEffects(inst)) {
                    worklist.push(inst);
                    live.insert(inst);
                }
            }
        }

        // 反向工作表算法
        while (!worklist.empty()) {
            auto* inst = worklist.front();
            worklist.pop();

            // 标记操作数为活跃
            for (auto* op : inst->getOperands()) {
                if (auto* opInst = dyn_cast<Instruction>(op)) {
                    if (live.insert(opInst).second) {
                        worklist.push(opInst);
                    }
                }
            }
        }
    }

    bool hasSideEffects(Instruction* inst) {
        // 函数调用、存储操作等有副作用
        return inst->mayHaveSideEffects();
    }

    bool isSafeToDelete(Instruction* inst) {
        return !hasSideEffects(inst) && inst->use_empty();
    }
};
```

### 1. 循环不变代码外提
```cpp
class LoopInvariantCodeMotion {
public:
    void optimize(Loop* loop) {
        // 分析循环不变指令
        auto invariants = analyzeLoopInvariants(loop);

        // 将不变指令移到循环前
        auto* preheader = loop->getLoopPreheader();
        for (auto* inst : invariants) {
            if (isSafeToHoist(inst)) {
                inst->moveBefore(preheader->getTerminator());
            }
        }
    }

private:
    std::vector<Instruction*> analyzeLoopInvariants(Loop* loop) {
        std::set<Instruction*> invariants;
        bool changed = true;

        while (changed) {
            changed = false;

            for (auto* block : loop->getBlocks()) {
                for (auto* inst : block->getInstructions()) {
                    if (invariants.count(inst)) continue;

                    if (isLoopInvariant(inst, loop, invariants)) {
                        invariants.insert(inst);
                        changed = true;
                    }
                }
            }
        }

        return std::vector<Instruction*>(invariants.begin(), invariants.end());
    }

    bool isLoopInvariant(Instruction* inst, Loop* loop,
                        const std::set<Instruction*>& knownInvariants) {
        // 检查所有操作数是否循环不变
        for (auto* op : inst->getOperands()) {
            if (auto* opInst = dyn_cast<Instruction>(op)) {
                // 操作数是指令且在循环内
                if (loop->contains(opInst->getParent())) {
                    // 如果不是已知的不变指令，则inst不是循环不变
                    if (!knownInvariants.count(opInst)) {
                        return false;
                    }
                }
            }
        }

        // 检查指令本身是否可能在循环内被重新定义
        return !mayBeModifiedInLoop(inst, loop);
    }
};
```

```cpp
class LoopUnrolling {
public:
    void optimize(Loop* loop, int unrollFactor = 4) {
        if (!canUnroll(loop, unrollFactor)) {
            return;
        }

        auto* header = loop->getHeader();
        auto* latch = loop->getLoopLatch();

        // 复制循环体
        std::vector<BasicBlock*> unrolledBlocks;
        for (int i = 0; i < unrollFactor - 1; i++) {
            auto* clonedHeader = cloneBasicBlock(header);
            unrolledBlocks.push_back(clonedHeader);
        }

        // 更新控制流
        reconnectControlFlow(loop, unrolledBlocks, unrollFactor);

        // 更新归纳变量
        updateInductionVariables(loop, unrollFactor);
    }

private:
    bool canUnroll(Loop* loop, int factor) {
        // 检查循环是否适合展开
        if (loop->getNumBlocks() != 1) {
            return false;  // 只处理单块循环
        }

        if (!hasKnownTripCount(loop)) {
            return false;  // 需要已知迭代次数
        }

        int tripCount = getTripCount(loop);
        if (tripCount % factor != 0) {
            return false;  // 迭代次数必须能被factor整除
        }

        return true;
    }
};
```

```cpp
class GlobalCSE {
public:
    void optimize(Function* func) {
        // 使用可用表达式分析
        AvailableExpressions analysis;
        analysis.analyze(func);

        // 在每个基本块的入口标记可用表达式
        std::map<BasicBlock*, std::set<Expression>> availableAtEntry;

        // 遍历所有基本块
        for (auto* block : func->getBlocks()) {
            auto available = analysis.getIn(block);

            for (auto* inst : block->getInstructions()) {
                if (auto* binOp = dyn_cast<BinaryInst>(inst)) {
                    Expression expr = {
                        binOp->getOpcode(),
                        binOp->getLeftOperand(),
                        binOp->getRightOperand()
                    };

                    if (available.count(expr)) {
                        // 找到可用的表达式
                        Value* replacement = findAvailableValue(expr, available);
                        if (replacement && replacement != binOp) {
                            binOp->replaceAllUsesWith(replacement);
                            binOp->eraseFromParent();
                        }
                    }

                    // 更新可用表达式集合
                    available.erase(expr.getKilledExpressions());
                    available.insert(expr);
                }
            }
        }
    }
};
```

```cpp
class InterproceduralOptimization {
public:
    void optimize(Module* module) {
        // 1. 构建调用图
        CallGraph cg = buildCallGraph(module);

        // 2. 函数内联
        inlineFunctions(cg);

        // 3. 过程间常量传播
        interproceduralConstantPropagation(cg);

        // 4. 函数特化
        specializeFunctions(cg);
    }

private:
    void inlineFunctions(CallGraph& cg) {
        for (auto* node : cg) {
            auto* caller = node->getFunction();

            for (auto* call : node->getCalls()) {
                auto* callee = call->getCalledFunction();

                if (shouldInline(caller, callee, call)) {
                    inlineFunction(caller, callee, call);
                }
            }
        }
    }

    bool shouldInline(Function* caller, Function* callee, CallInst* call) {
        // 小函数优先内联
        if (callee->size() < 10) {
            return true;
        }

        // 只被调用一次的函数内联
        if (callee->getNumUses() == 1) {
            return true;
        }

        // 热点函数内联
        if (isHotFunction(callee)) {
            return true;
        }

        return false;
    }

    void inlineFunction(Function* caller, Function* callee, CallInst* call) {
        // 1. 克隆被调用函数的代码
        ValueToValueMapTy VMap;
        Function* newCallee = cloneFunction(callee, VMap);

        // 2. 映射参数
        for (auto& arg : newCallee->args()) {
            Value* actualArg = call->getArgOperand(arg.getArgNo());
            VMap[&arg] = actualArg;
        }

        // 3. 将克隆的代码插入到调用点
        newCallee->getBody().insertBefore(call);

        // 4. 替换调用为直接跳转
        call->replaceAllUsesWith(newCallee);
        call->eraseFromParent();
    }
};
```

### 2. 指令调度
```cpp
class InstructionScheduling {
public:
    void schedule(BasicBlock* block, TargetMachine* target) {
        // 1. 构建数据依赖图
        auto depGraph = buildDependencyGraph(block);

        // 2. 列表调度算法
        std::vector<Instruction*> scheduled;
        std::set<Instruction*> ready;

        // 初始化：没有依赖的指令就绪
        for (auto* inst : block->getInstructions()) {
            if (depGraph.getInDegree(inst) == 0) {
                ready.insert(inst);
            }
        }

        while (!ready.empty()) {
            // 选择优先级最高的就绪指令
            Instruction* best = nullptr;
            int bestPriority = -1;

            for (auto* inst : ready) {
                int priority = computePriority(inst, target);
                if (priority > bestPriority) {
                    best = inst;
                    bestPriority = priority;
                }
            }

            // 调度选中的指令
            scheduled.push_back(best);
            ready.erase(best);

            // 更新就绪集合
            for (auto* succ : depGraph.getSuccessors(best)) {
                depGraph.removeEdge(best, succ);
                if (depGraph.getInDegree(succ) == 0) {
                    ready.insert(succ);
                }
            }
        }

        // 3. 重新排列指令
        reorderInstructions(block, scheduled);
    }

private:
    int computePriority(Instruction* inst, TargetMachine* target) {
        int priority = 0;

        // 关键路径优先
        priority += getCriticalPathLength(inst);

        // 使用机器指令延迟
        priority -= target->getLatency(inst);

        // 寄存器压力考虑
        priority += getRegisterPressure(inst);

        return priority;
    }
};
```

## 总结

代码优化是编译原理中最具挑战性和艺术性的部分：

1. **理论基础**: 数据流分析、依赖分析、图论
2. **算法设计**: 各种高效的分析和转换算法
3. **工程权衡**: 在编译时间、优化效果、实现复杂度间权衡
4. **目标敏感**: 充分利用目标机器的特性

代码优化的美妙在于：
- **理论深度**: 基于严格的数学分析
- **实用价值**: 显著提升程序性能
- **创造性**: 需要创造性的算法设计
- **持续发展**: 随着硬件和应用的演进而进步

掌握代码优化不仅有助于理解编译器工作原理，更能培养对程序性能的深刻理解。这种理解对于编写高性能软件、设计高效算法具有重要价值。代码优化体现了"在约束条件下追求最优"这一工程设计的核心理念。
