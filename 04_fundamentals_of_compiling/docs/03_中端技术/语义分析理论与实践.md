# 语义分析：赋予程序含义的艺术

## 语义分析的核心思想

语义分析(Semantic Analysis)是编译过程中的关键阶段，它位于语法分析之后，代码生成之前。表面任务是检查程序的语义正确性，深层思想是**将语法结构赋予具体的含义，确保程序在语义上是合法和有意义的**。

### 本质问题：从语法到语义
```
语法树:      语义分析后:
if (x > 0)    if (x: int > 0: int)
    return x;     return x: int;

检查内容:
- 变量x是否已声明
- x的类型是否支持>运算
- return语句的返回值类型是否匹配函数声明
```

**核心思想**: 在语法正确的基础上，进一步确保程序的含义合理，为后续优化和代码生成奠定基础。

## 语义分析的理论基础

### 1. 语义的层次
**静态语义**: 编译时可检查的语义
- 类型检查
- 变量声明检查
- 函数调用匹配
- 控制流检查

**动态语义**: 运行时才能确定的语义
- 数组越界检查
- 空指针检查
- 除零检查
- 内存泄漏

**深刻意义**: 静态语义分析将尽可能多的错误在编译时发现，提高程序的可靠性和性能。

### 2. 形式化语义描述
**操作语义**: 通过抽象机描述程序含义
```
while (b) do S
的执行语义:
repeat:
  evaluate b
  if b is false then goto exit
  execute S
  goto repeat
exit:
```

**指称语义**: 通过数学函数描述程序含义
```
E[[while b do S]] = fix (λf. λs.
  if B[[b]] s then f (C[[S]] s) else s)
```

**公理语义**: 通过逻辑公式描述程序性质
```
{P} S {Q}
```
表示如果在执行S前断言P成立，执行S后断言Q成立。

## 类型系统理论

### 1. 类型的基础概念
**定义**: 类型是对数据值集合及其上操作的抽象描述

**类型的基本组成**:
```
Type = (Values, Operations, Properties)

示例:
int = (整数集合, {+, -, *, /}, 有序类型)
bool = ({true, false}, {&&, ||, !}, 比较运算)
```

### 2. 类型系统设计原则
**安全性**: 类型系统应该保证程序的安全性
```
安全性的重要方面:
- 内存安全: 无非法内存访问
- 类型安全: 类型错误在编译时捕获
- 行为安全: 避免未定义行为
```

**表达性**: 类型系统应该能够表达丰富的程序性质
```rust
// Rust的类型系统既安全又表达性强
fn process<T: Display>(value: T) -> String {
    format!("{}", value)
}
```

**实用性**: 类型系统应该对程序员友好
```python
# Python的动态类型提高了灵活性
def process(value):
    return str(value)
```

### 3. 类型推导算法
**Hindley-Milner类型推导**:
```ml
(* 示例: Standard ML *)
let rec map f lst =
    match lst with
    | [] -> []
    | x :: xs -> f x :: map f xs

(* 推导出类型: ('a -> 'b) -> 'a list -> 'b list *)
```

**算法步骤**:
1. 为每个表达式生成类型变量
2. 根据语言规则生成约束
3. 统一化约束求解
4. 得到最一般的类型

**实现**:
```cpp
class TypeInference {
private:
    struct TypeScheme {
        std::vector<TypeVariable> typeVars;
        Type type;
    };

    struct Substitution {
        std::map<TypeVariable, Type> mapping;

        Type apply(const Type& type) const {
            // 应用替换到类型
        }

        Subposition compose(const Substitution& other) const {
            // 复合替换
        }
    };

public:
    TypeScheme infer(const Expr& expr) {
        // 1. 生成约束
        auto constraints = generateConstraints(expr);

        // 2. 统一化
        auto substitution = unify(constraints);

        // 3. 应用替换
        Type type = substitution.apply(expr.getType());

        // 4. 泛化
        return generalize(type, substitution);
    }

private:
    Substitution unify(const std::vector<Constraint>& constraints) {
        Substitution subst;

        for (const auto& constraint : constraints) {
            subst = unifyOne(constraint, subst);
            if (!subst.isValid()) {
                throw TypeError("Type unification failed");
            }
        }

        return subst;
    }

    Substitution unifyOne(const Constraint& constraint, const Substitution& subst) {
        Type left = subst.apply(constraint.left);
        Type right = subst.apply(constraint.right);

        if (left == right) {
            return subst;
        }

        if (left.isTypeVariable()) {
            return bind(left, right, subst);
        }

        if (right.isTypeVariable()) {
            return bind(right, left, subst);
        }

        if (left.isFunctionType() && right.isFunctionType()) {
            // 递归统一化函数类型的参数和返回值
            auto s1 = unify({left.getArgType(), right.getArgType()}, subst);
            auto s2 = unify({s1.apply(left.getReturnType()),
                           s1.apply(right.getReturnType())}, s1);
            return s2;
        }

        throw TypeError("Cannot unify types");
    }
};
```

## 符号表管理

### 1. 符号表的结构
**符号表的层次结构**:
```
Global Scope
├── Function: main
│   └── Local Scope
│       ├── Variable: x
│       └── Variable: y
└── Function: helper
    └── Local Scope

```

### 2. 符号表实现
```cpp
class SymbolTable {
private:
    struct Symbol {
        std::string name;
        Type type;
        SymbolKind kind;  // VARIABLE, FUNCTION, TYPE, etc.
        Scope* scope;
        DeclNode* declaration;  // 指向声明节点的指针

        // 附加属性
        bool isConst;
        bool isStatic;
        int offset;  // 在栈帧中的偏移
    };

    struct Scope {
        Scope* parent;
        int level;
        std::map<std::string, Symbol*> symbols;

        Symbol* lookup(const std::string& name) {
            auto it = symbols.find(name);
            if (it != symbols.end()) {
                return it->second;
            }
            return nullptr;
        }

        bool insert(const std::string& name, Symbol* symbol) {
            if (symbols.find(name) != symbols.end()) {
                return false;  // 重复定义
            }
            symbols[name] = symbol;
            return true;
        }
    };

    Scope* currentScope_;
    Scope* globalScope_;

public:
    void enterScope(Scope* scope) {
        scope->parent = currentScope_;
        scope->level = currentScope_ ? currentScope_->level + 1 : 0;
        currentScope_ = scope;
    }

    void exitScope() {
        currentScope_ = currentScope_->parent;
    }

    Symbol* lookup(const std::string& name) {
        Scope* scope = currentScope_;
        while (scope) {
            Symbol* symbol = scope->lookup(name);
            if (symbol) {
                return symbol;
            }
            scope = scope->parent;
        }
        return nullptr;
    }

    bool insert(const std::string& name, Symbol* symbol) {
        symbol->scope = currentScope_;
        return currentScope_->insert(name, symbol);
    }
};
```

## 类型检查实现

### 1. 类型检查器架构
```cpp
class TypeChecker {
private:
    SymbolTable* symbolTable_;
    ErrorHandler* errorHandler_;

public:
    void check(ASTNode* root) {
        root->accept(*this);
    }

    // 语句检查
    void visit(IfStmt* stmt) {
        // 检查条件表达式
        checkExpression(stmt->getCondition());

        Type condType = stmt->getCondition()->getType();
        if (!isBooleanType(condType)) {
            errorHandler_->error(
                stmt->getCondition()->getLocation(),
                "if condition must be boolean"
            );
        }

        // 检查then和else分支
        checkStatement(stmt->getThenBranch());
        if (stmt->getElseBranch()) {
            checkStatement(stmt->getElseBranch());
        }
    }

    void visit(WhileStmt* stmt) {
        // 检查条件表达式
        checkExpression(stmt->getCondition());

        Type condType = stmt->getCondition()->getType();
        if (!isBooleanType(condType)) {
            errorHandler_->error(
                stmt->getCondition()->getLocation(),
                "while condition must be boolean"
            );
        }

        // 检查循环体
        checkStatement(stmt->getBody());
    }

    void visit(ReturnStmt* stmt) {
        FunctionDecl* currentFunc = getCurrentFunction();
        if (!currentFunc) {
            errorHandler_->error(
                stmt->getLocation(),
                "return statement outside function"
            );
            return;
        }

        Type returnType = currentFunc->getReturnType();

        if (stmt->getValue()) {
            // 检查返回值表达式
            checkExpression(stmt->getValue());
            Type valueType = stmt->getValue()->getType();

            if (!isCompatible(returnType, valueType)) {
                errorHandler_->error(
                    stmt->getValue()->getLocation(),
                    fmt::format("return type mismatch: expected {}, got {}",
                              returnType, valueType)
                );
            }
        } else {
            if (!isVoidType(returnType)) {
                errorHandler_->error(
                    stmt->getLocation(),
                    "empty return in non-void function"
                );
            }
        }
    }

    // 表达式检查
    void visit(BinaryExpr* expr) {
        checkExpression(expr->getLeft());
        checkExpression(expr->getRight());

        Type leftType = expr->getLeft()->getType();
        Type rightType = expr->getRight()->getType();
        TokenType op = expr->getOperator();

        // 根据运算符检查类型
        switch (op) {
            case TokenType::PLUS:
            case TokenType::MINUS:
            case TokenType::MULTIPLY:
            case TokenType::DIVIDE:
                if (!isNumericType(leftType) || !isNumericType(rightType)) {
                    errorHandler_->error(
                        expr->getLocation(),
                        "arithmetic operands must be numeric"
                    );
                }
                expr->setType(promoteType(leftType, rightType));
                break;

            case TokenType::LESS:
            case TokenType::GREATER:
            case TokenType::LESS_EQUAL:
            case TokenType::GREATER_EQUAL:
                if (!isOrderedType(leftType) || !isOrderedType(rightType)) {
                    errorHandler_->error(
                        expr->getLocation(),
                        "comparison operands must be ordered"
                    );
                }
                expr->setType(Type::BOOL);
                break;

            case TokenType::EQUAL:
            case TokenType::NOT_EQUAL:
                if (!isCompatible(leftType, rightType)) {
                    errorHandler_->error(
                        expr->getLocation(),
                        "comparison operands must be compatible"
                    );
                }
                expr->setType(Type::BOOL);
                break;

            default:
                break;
        }
    }

    void visit(CallExpr* expr) {
        // 查找函数声明
        Symbol* symbol = symbolTable_->lookup(expr->getFuncName());
        if (!symbol || symbol->kind != SymbolKind::FUNCTION) {
            errorHandler_->error(
                expr->getLocation(),
                fmt::format("undefined function: {}", expr->getFuncName())
            );
            return;
        }

        FunctionDecl* func = symbol->declaration;
        std::vector<Type> paramTypes = func->getParamTypes();
        std::vector<Expr*> args = expr->getArguments();

        // 检查参数数量
        if (args.size() != paramTypes.size()) {
            errorHandler_->error(
                expr->getLocation(),
                fmt::format("argument count mismatch: expected {}, got {}",
                          paramTypes.size(), args.size())
            );
            return;
        }

        // 检查每个参数的类型
        for (size_t i = 0; i < args.size(); i++) {
            checkExpression(args[i]);
            Type argType = args[i]->getType();

            if (!isCompatible(paramTypes[i], argType)) {
                errorHandler_->error(
                    args[i]->getLocation(),
                    fmt::format("argument {} type mismatch: expected {}, got {}",
                              i + 1, paramTypes[i], argType)
                );
            }
        }

        expr->setType(func->getReturnType());
    }
};
```

## 控制流分析

### 1. 控制流图(CFG)构建
```cpp
class ControlFlowGraph {
private:
    struct BasicBlock {
        int id;
        std::vector<Stmt*> statements;
        std::vector<BasicBlock*> successors;
        std::vector<BasicBlock*> predecessors;
        bool isExit;
    };

    std::vector<BasicBlock*> blocks_;
    BasicBlock* entry_;

public:
    void build(FunctionDecl* func) {
        // 创建入口块
        entry_ = createBlock();

        // 构建控制流图
        buildBlock(func->getBody(), entry_);

        // 优化CFG
        optimize();
    }

private:
    void buildBlock(Stmt* stmt, BasicBlock* currentBlock) {
        switch (stmt->getKind()) {
            case StmtKind::IF: {
                IfStmt* ifStmt = cast<IfStmt>(stmt);

                // 创建条件判断块
                BasicBlock* thenBlock = createBlock();
                BasicBlock* elseBlock = ifStmt->getElseBranch()
                                       ? createBlock() : nullptr;
                BasicBlock* mergeBlock = createBlock();

                // 添加控制流边
                currentBlock->successors.push_back(thenBlock);
                if (elseBlock) {
                    currentBlock->successors.push_back(elseBlock);
                }
                thenBlock->successors.push_back(mergeBlock);
                if (elseBlock) {
                    elseBlock->successors.push_back(mergeBlock);
                }

                // 递归构建子块
                buildBlock(ifStmt->getThenBranch(), thenBlock);
                if (elseBlock) {
                    buildBlock(ifStmt->getElseBranch(), elseBlock);
                }

                break;
            }

            case StmtKind::WHILE: {
                WhileStmt* whileStmt = cast<WhileStmt>(stmt);

                // 创建循环块
                BasicBlock* condBlock = createBlock();
                BasicBlock* bodyBlock = createBlock();
                BasicBlock* exitBlock = createBlock();

                // 添加控制流边
                currentBlock->successors.push_back(condBlock);
                condBlock->successors.push_back(bodyBlock);
                condBlock->successors.push_back(exitBlock);
                bodyBlock->successors.push_back(condBlock);

                // 递归构建循环体
                buildBlock(whileStmt->getBody(), bodyBlock);

                break;
            }

            default:
                // 其他语句添加到当前块
                currentBlock->statements.push_back(stmt);
                break;
        }
    }
};
```

### 2. 数据流分析框架
```cpp
template<typename T>
class DataFlowAnalysis {
public:
    // 前向数据流分析
    void analyzeForward(ControlFlowGraph& cfg) {
        std::map<BasicBlock*, T> in;
        std::map<BasicBlock*, T> out;

        // 初始化
        for (auto block : cfg.getBlocks()) {
            in[block] = initialize();
            out[block] = initialize();
        }

        // 迭代直到不动点
        bool changed = true;
        while (changed) {
            changed = false;

            for (auto block : cfg.getBlocks()) {
                // IN[BLOCK] = ∧ OUT[PREDECESSOR]
                T newIn = meet(block->predecessors, out);
                if (newIn != in[block]) {
                    in[block] = newIn;
                    changed = true;
                }

                // OUT[BLOCK] = transfer(IN[BLOCK])
                T newOut = transfer(block, in[block]);
                if (newOut != out[block]) {
                    out[block] = newOut;
                    changed = true;
                }
            }
        }
    }

    // 后向数据流分析
    void analyzeBackward(ControlFlowGraph& cfg) {
        // 类似前向分析，但是逆序处理
    }

protected:
    virtual T initialize() = 0;
    virtual T meet(const std::vector<BasicBlock*>& blocks,
                   const std::map<BasicBlock*, T>& out) = 0;
    virtual T transfer(BasicBlock* block, const T& input) = 0;
};

// 到达定义分析
class ReachingDefinitions : public DataFlowAnalysis<std::set<Definition*>> {
protected:
    std::set<Definition*> initialize() override {
        return {};  // 初始为空集
    }

    std::set<Definition*> meet(
        const std::vector<BasicBlock*>& blocks,
        const std::map<BasicBlock*, std::set<Definition*>>& out
    ) override {
        std::set<Definition*> result;
        for (auto block : blocks) {
            result.insert(out.at(block).begin(), out.at(block).end());
        }
        return result;  // 并集
    }

    std::set<Definition*> transfer(
        BasicBlock* block,
        const std::set<Definition*>& input
    ) override {
        std::set<Definition*> result = input;

        // kill: 删除块内重新定义的定义
        // gen: 添加块内新生成的定义
        for (auto stmt : block->statements) {
            auto defs = getDefinitions(stmt);
            for (auto def : defs) {
                result.erase(def);  // kill
                result.insert(def);  // gen
            }
        }

        return result;
    }
};
```

## 总结

语义分析是编译原理中理论与实践结合最为紧密的部分之一：

1. **理论基础**: 类型理论、语义学、形式化方法
2. **工程实践**: 类型检查、符号表管理、错误诊断
3. **系统设计**: 模块化架构、可扩展性、性能优化
4. **现代发展**: 依赖类型、线性类型、渐进类型

语义分析的美妙在于：
- **理论深度**: 基于严格的数学理论
- **实用价值**: 捕获大量程序错误
- **设计艺术**: 平衡安全性、表达性和易用性
- **持续演进**: 随着编程语言的发展而进步

掌握语义分析不仅有助于理解编译器工作原理，更能培养对程序性质的深刻理解，这种理解对于编写高质量、可靠的软件至关重要。语义分析体现了形式化方法在软件工程中的巨大价值。
